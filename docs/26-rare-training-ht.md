# 26. レア訓練とハーフタイムの指示の作り直し(2026-11-26。合意して実装)

オーナーの要望をもとにした設計。26.6 の問いはすべて案どおりで合意(イベントの訓練は ★ を付けず育ちを強く・割り当ては表どおり・出来事 10%・★3 で身につく・強さの数字はテストで調整・前に覚えた指示は忘れてよい)。

## 26.1 今の仕組みと困っていること

| | 今 | 困っていること |
|---|---|---|
| レア訓練(特殊練習) | 48種。チーム練習の6つの枠それぞれが、12% × 監督ランクの率でレア訓練に差し替わる。セットした称号の系統に合うものは出やすい(重み)だけ | 種類が多すぎて、狙って育てられない |
| ハーフタイムの指示 | レア訓練を2回すると、その訓練の指示を覚える。任期をまたいで残る(監督が覚え続ける)。基本の3つは初めから使える | 指示の強さに明らかな差がある。上がるだけで下がらない指示が多い(下がる軸なしが8種、基本の3つも同じ)。監督能力・称号の効き目と区別がつかない。何回やったか分からない |

## 26.2 方針

1. **称号のレア訓練**: セットした監督称号ごとに、得意なレア訓練が **2〜3種類だけ** 出る。称号ごとに「得意なチームスタイル」が生まれる
2. **イベントのレア訓練**: 残りのレア訓練は、HOME の出来事(秘書の知らせ)で **1回だけ** 出る。スタジアムと施設が育っているほど、良い出来事が起きる
3. **ハーフタイムの指示**: 任期の中だけの「一期一会」にする。レア訓練を選ぶたびに ★ が1つ埋まり、★★★ で使えるようになる。どの指示にも「代わりに失うもの」を付けて、強さをそろえる

3つの仕組みの役割は、次のように分ける。

| | 続く長さ | 何を決めるか |
|---|---|---|
| 監督能力 | 監督に残る(任期をまたぐ) | 試合中の采配の力 |
| 監督称号(セット) | 監督に残る。任期の始めに1つ選ぶ | **どのレア訓練が出るか**(チームスタイルの方向) |
| ハーフタイムの指示 | **その任期の中だけ** | レア訓練を3回やって身につけた、後半の作戦 |

## 26.3 称号のレア訓練

- セットした称号の訓練だけが、チーム練習の枠に差し替わって出る(出る率は今の 12% × 監督ランクのまま)
- 同じ任期の中で同じ訓練を何度も選べるので、狙って ★ を埋められる
- 称号をセットしていない(新米監督・迷将だけ、または未選択)ときは「称号なし」の2種

| 称号 | チームスタイル | レア訓練(上がる軸 / 下がる軸) |
|---|---|---|
| レジェンド | トータルフットボール | トータルフットボール(全軸)、ムービングフットボール(OFE TEC SPE / POW DEF STA)、攻守の切り替え(OFE DEF / STA) |
| 皇帝 | 王者の圧力 | ゲルマン魂(POW DEF STA / OFE TEC SPE)、ハイインテンシティー(TEC以外)、ビルドアップ(OFE TEC POW / DEF SPE) |

| 魔術師 | ファンタジスタ | シャンパンサッカー(OFE TEC SPE / DEF POW STA)、セクシーフットボール(OFE TEC POW / DEF STA SPE)、サインプレイ(TEC POW SPE / OFE DEF) |
| 伝承者 | 連動 | 1タッチゲーム(TEC STA SPE / OFE POW DEF)、オフ・ザ・ボールの動き(OFE SPE / POW DEF STA)、パス&ラン(OFE TEC SPE / POW STA) |

## 26.4 イベントのレア訓練(1回だけ)

- 称号に割り当てなかった残り(15種)は、HOME の出来事でだけ出る
- 秘書が EVENT として知らせ、「受ける」と次のチーム練習の枠の1つがその訓練になる(1回だけ。選ばなければ消える)
- 出来事は試合のあとにごくまれに起きる(案: 10%)。出られる出来事は、スタジアムと施設の段で決まる。**段が高いほど、良い訓練の出来事が選ばれやすい**(候補のうち段の高いものほど重みを大きく)

| 出来事(秘書の知らせ) | 条件 | レア訓練 |
|---|---|---|
| 「メディアが練習を取材に来ています。非公開にしましょうか」 | スタジアム Lv5 | 非公開練習 |
| 「サポーターが練習を見に来ています。見せる練習をしませんか」 | スタジアム Lv3 以上 | フルコート3対3 |
| 「地元のクラブから、練習試合の申し込みです」 | だれでも | サイドアタック / 中央突破 / クロスボール / ロングカウンター のどれか |
| 「練習場に新しいミニピッチができました」 | 練習場 Lv1 / Lv2 以上 | 3vs1とりかご / 4VS4パスゲーム |
| 「フィジカルコーチが来てくれるそうです」 | メディカル Lv1 / Lv3 | シャトルラン / オーバーラップ |
| 「戦術室で、相手の映像を分析しました」 | 戦術室 Lv1 / Lv2 / Lv3 | セットプレイ / 特殊セットプレイ / ストップ・ザ・ゲーム |
| 「クラブの OB が顔を出してくれました」 | ラウンジ Lv1 / Lv3 | ダイレクトプレイ / カバーリング |

- イベントの訓練は1回きりなので、ハーフタイムの ★ は付かない(代わりに、育ちを通常のレア訓練より少し強くする。案: 経験 ×1.3)→ 26.6 の問い

## 26.5 ハーフタイムの指示

### 身につけ方
- **任期の中だけ**: 任期が終わると全部消える(次の任期は基本の3つから)
- **★☆☆**: 称号のレア訓練を選ぶたびに、その訓練の指示の ★ が1つ埋まる。★★★ で使えるようになる
- チーム練習の札に、その訓練の指示の名前と ★ を出す(例:「ハイプレス ★★☆」)。何回選んだかがひと目で分かる
- 登録できるのは今までどおり3つまで(戦略方針の画面)

### 強さのそろえ方
どの指示も、次の3つの型のどれか1つで「代わりに失うもの」を持つ。上がる量は、型ごとに同じ物差しで決める(下の数字は案)。

| 型 | 上がる | 代わりに | 例 |
|---|---|---|---|
| 振り分け | 2軸を大きく | 1〜2軸が下がる | 攻めの姿勢を見せろ(OFE SPE ↑ / DEF ↓) |
| 消耗 | 全軸を少し、または3〜4軸を中くらい | 後半のスタミナの減りが 1.5倍 | 気合いを入れ直せ(全軸 ↑ / スタミナ消耗) |
| 限定 | 1つの役割の選手だけ大きく | ほかの選手には効かない | クロスボール(SB・WG の OFE POW ↑↑) |

- 上がる量の物差し: 「上がる軸の数 × 量 − 下がる軸の数 × 量 × 0.6」がどの指示でもほぼ同じになるようにする。消耗型・限定型は、その代わりの重さを軸 1.5 本ぶんとして数える
- 今のレア訓練の上がる / 下がる軸は、指示ではそのまま使わない。指示ごとに上の型で作り直す(例: トータルフットボール =「全軸 ↑ + 消耗」、ゲーゲンプレス =「OFE STA SPE ↑ + 消耗」、カテナチオ =「DEF STA ↑↑ / OFE ↓」)
- 基本の3つにも代わりを付ける:
  - 気合いを入れ直せ … 全軸 ↑(小)/ スタミナ消耗
  - 集中を切らすな … DEF STA ↑ / OFE ↓
  - 攻めの姿勢を見せろ … OFE SPE ↑ / DEF ↓

### 今のセーブデータ
- 今まで覚えた指示(任期をまたいで残っていたもの)は、この変更で消える。最初に開いたとき、秘書が一言で知らせる

## 26.6 決めてほしいこと

1. **イベントの訓練とハーフタイム**: 1回きりなので ★ を付けない(代わりに育ちを強くする)案でよいか。それとも、イベントの訓練は1回で ★★★ になる「特別な指示」にするか
2. **称号の割り当て**: 26.3 の表の組み合わせでよいか(差し替えたい訓練があれば)。浮気者・生え抜きは2種、ほかは3種
3. **イベントの頻度**: 試合ごとに 10% でよいか(今の出来事 EVENT とは別に数える案)
4. **★の数**: 3回で使えるでよいか(称号の訓練は2〜3種に絞るので、任期の中で2〜3個の指示を身につけられる見込み)
5. **指示の強さの数字**: 型の物差し(下がる軸 0.6、代わりの重さ 1.5 本ぶん)は試合のテストで調整してよいか

## 26.7 実装(2026-11-26)

- 称号のレア訓練: term.js `TITLE_TRAIN` / `titleTrainPool`。チーム練習の枠が差し替わる率は今のまま(12% × 監督ランク)で、選ばれるのは称号の訓練だけ。同じ回に同じ訓練は2つ出さない。`TITLE_FX` の説明は「(スタイル)のレア訓練 ・ …」に
- イベントのレア訓練: data.js `TAG_EVENTS` の `tr` 付きの出来事(12件)。試合のあと `TUNING.grow.trainEvP`(10%)で起き(grow.js `trainEventRoll`)、条件(`need`)を満たす候補から重み `w` で選ぶ。受けると `S.g.evTrain` に入り、次のチーム練習の枠の1つ(基本の練習)に差し込む。練習するか休むと消える。経験は ×`evTrainK`(1.3)。秘書のリアクションは口調ごとの共通の言葉(`TAG_EV_RX.train`)
- ハーフタイムの指示: 回数は任期ごとの `S.g.htc`(称号の訓練だけ数える)。3回で身につく。任期の始めに登録も基本の3つに戻す。前のセーブの覚えた指示は読み込みで消し、一度だけ秘書が知らせる(`S.htV2` / `S.htNotice`)
- 指示の中身: data.js `HT_SPEC`(称号の33種)と `HT_BASIC`。強さは `htK`: budget(1.2)÷(上がる軸の数 − 下がる軸の数 × 0.6)、消耗は ×1.25、限定は ×1.6(上限 2)。結果の得は 振り分け 1.2 / 消耗 1.5 / 限定 1.9(代わりの重さのぶん)
- 試合: 消耗の指示は後半のスタミナの減りが `TUNING.ht.stamK`(1.5)倍、限定の指示はその役割(FW・MF・DF)の選手にだけ効き、チームのグラフには足さない
- 画面: チーム練習の札は2段(練習名 / 「HT ★★☆」または「EVENT ・ 1回だけ」。イベントは赤い枠)。試合のハーフタイムの吹き出しは「FW の 攻速↑」「… スタミナ消耗」のように代わりも出す

## 26.8 札の色で分ける(2026-11-26)

- オーナーの指摘: 称号(監督)のレア訓練は今の金、イベントは銀のように、ボタンの色で分ける。「EVENT ・ 1回だけ」は不要。「HT」の文字も不要で、星だけでよい
- 称号のレア訓練: 金の札の下に ★☆☆ だけ。イベントのレア訓練: 銀の札(字は濃い灰)で、下の文字は出さない。選んだときはどちらも同じ赤い選択の表示
