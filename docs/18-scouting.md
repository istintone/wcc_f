# 18. 視察(相手の SQUAD を秘書が伝える)

オーナーの要望(2026-11-21): 相手の対戦チームを参照する機能。手はじめに、コミュニケーションと戦略方針のあいだに「視察」のステップを加え、相手の SQUAD を秘書が整理して伝える。

## 18.1 流れ

準備は4段: チーム練習 → コミュニケーション → **視察** → 戦略方針 → キックオフ。
視察の下に「戦略方針へ」と「‹ コミュニケーションに戻る」(残りがあるとき)。戦略方針の下は「‹ 視察に戻る」。

## 18.2 画面(`clubui.js` の `scoutStepHtml`)

- **秘書の報告**(`scoutReport`): 相手の強さ(★)・陣形・監督の型と傾向 / KP とスタイルとランク(レアKP のおそれ)/ 要注意の選手(攻め・守り1人ずつ)/ 強い軸と手薄な軸(こちらが上回る軸)/ 総合力の比べ(相手 / こちら)とひとこと
- **上部**(SQUAD と同じ形): 左にレーダー(相手の戦力と自軍の戦力を重ねる)、右に相手のエンブレム・名前・★・陣形・監督の型・OVR・KP
- **盤面**(SQUAD と同じ札): 相手の先発11人を陣形どおりに、細かいポジションと適性の色、KP の札、能力の合計。右に控え
- 札を押すと、その選手のカードの裏をフロートで(`oppCardModalHtml`)

## 18.3 相手の CAP とセットプレー(2026-11-21)

- 試合と同じ決め方で出す(`oppRoles`): CAP はキャプテンの適性が一番高い選手(同じなら年長)、PK・FK・CK は指名が無いので一番うまい選手(試合前の能力で)
- 盤面の札の左上に CAP・KP・PK・FK・CK(SQUAD と同じ)。秘書の報告にも1行(同じ選手が蹴るものはまとめる)
- 連携線は出さない(オーナーの決定)。相手の調子は無い(いつも普通)
