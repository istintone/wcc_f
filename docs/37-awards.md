# 37. 長い期間の賞

2026-11-28。オーナーの課題(次の課題の6番)「MVP・バロンドール・ゴールデンブーツなどのロングスパンイベントを作りたい」。2026-11-28 にオーナーと合意(37.6)。

## 37.1 ねらい

- 1試合ごとの勝ち負けとは別に、リーグの1周・任期の100試合をまたいで追いかける目標を作る
- 「うちの FW が得点王争いに絡んでいる」「GK が年間最優秀に選ばれた」という長い物語を、新聞・秘書・授賞式で見せる
- 受賞はカードに残る(任期をまたいで残る数少ないもの)。集めて育てる遊びに、もう1つの勲章を足す

## 37.2 賞の一覧と区切り

実在の賞の名前(バロンドールなど)は使わない。英字の見出しと日本語の名前にする。

| 区切り | 賞 | 決め方 |
|---|---|---|
| リーグの1周(14節)の終わり | **得点王**(TOP SCORER) | リーグ戦の得点がいちばん多い選手 |
|  | **アシスト王**(TOP ASSIST) | リーグ戦のアシスト |
|  | **リーグ ベストイレブン**(BEST XI) | 自分の選手から、ポジションごとに採点の平均の上位(出場が少ない選手は外す) |
| 任期の終わり(100試合) | **年間最優秀選手**(PLAYER OF THE YEAR) | 得点・アシスト・MVP・採点・取ったタイトルの点数で、ライバル候補と比べる |
|  | **ゴールデンシュー**(GOLDEN SHOE) | 任期の全試合の得点 |
|  | **最優秀GK**(BEST KEEPER) | GK の無失点の試合と採点 |
|  | **最優秀若手**(YOUNG PLAYER) | 23歳以下で、年間最優秀と同じ点数 |
|  | **最優秀監督**(MANAGER OF THE YEAR) | 監督の評価(任期の成績・タイトル)。監督が受ける |

## 37.3 ライバル候補(相手のクラブの選手)

- 自分の選手と競うのは、同じリーグのクラブのエース(KP の選手か、カードの数字がいちばん高い FW)
- ライバルの成績は、そのクラブの**実際の記録から作る**: リーグの順位表の得点 gf × そのクラブのエースの取り分(30〜40%。カードの数字で上下)。アシスト・採点も同じように、順位とカードの数字から
- 同じ試合の中では変わらないたね(遊ぶたびに同じ)で決める。自分が強ければ勝てる、ライバルのクラブが勝ち進めば手強い

## 37.4 見せ方

- **賞レースの表**(SEASON に「AWARDS」の欄): 得点王・アシスト王の上位5人(自分の選手とライバルが混ざる)。試合のたびに動く
- **秘書・新聞**: レースが動いたとき(首位に立った・抜かれた)に、秘書の一言とクラブ新聞の記事
- **授賞式の場面**: リーグの1周の終わり・任期の終わりに、候補3人 → 受賞者の発表(トロフィーの場面と同じ作り)
- **カードの受賞歴**: 受賞した選手のカードの裏に「受賞歴」(第◯任期 得点王 など)。CARDS で受賞したカードに小さな印
- MANAGER の CAREER RECORD に、監督の受賞(最優秀監督)を足す

## 37.5 ごほうび

- **リーグの得点王・アシスト王: ごほうびは「スター選手」のタグだけ**(オーナーの決め。2026-11-28)
- 任期の終わりの賞を受けた選手: 次の任期の初めから「◯◯の受賞者」のタグ(調子が落ちにくい・スター選手と同じく入場料に効く。任期の終わりで消える)
- 年間最優秀選手は、その選手に「スター選手」を付ける(もう付いていれば何もしない)
- 賞金(1賞につき数億)とファン
- 最優秀監督: 監督の称号の手帳(COACHING NOTE)に記録

## 37.8 実装(2026-11-28)

- 仕組みは `awards.js`(DOM に触らない): `awLeagueAdd`(リーグ戦の成績 `S.lstat`)/ `awRace`(得点王・アシスト王のレース)/ `awCycleEnd`(リーグの1周の終わり。`endCycle` の初め)/ `awTermEnd`(任期の終わり。`endTerm` の初め)/ `awNextTerm`(次の任期の初めに受賞者のタグ。`startNextTerm`)
- ライバル: 同じリーグのクラブのエース(FW で OFE・TEC が高い)・GK(先発の1人目)・若手(23歳以下)。成績は順位表の得点 × 取り分(`TUNING.award.share`)。任期の賞は、周ごとの積み上げ(`S.awAcc`)を任期の試合数に引き伸ばす
- GK の無失点は `applyResult` で `S.tstat[GK].cs` に数える。アシストは `finishFixture` から `applyResult` に渡す
- 記録: `S.awards`(全部の受賞)・`S.honors`(カードの受賞歴。任期をまたいで残る)・`S.mgrAwards`(監督の受賞の数)
- 画面: SEASON の「AWARDS」(順位表の下。TOP SCORER・TOP ASSIST・GOLDEN SHOE の上位5人)/ 任期の最後の試合のあと、カードの排出の次に授賞式(`scenes.js` の `sceneAwards`。賞ごとに1場面)/ カードの裏の「AWARDS」(受賞歴)/ 得点王レースの首位に立ったら知らせの行(👟)/ リーグの1周の賞は知らせの行(🏅)
- 新しいタグ: 受賞者(laureate。調子が落ちにくい・入場料 ×1.3)
