# 11. レアKP(選手固有のキープレーヤースタイル)(2026-11-19)

D18 の設計。docs/04 §4.7 の「汎用スタイル1つ + 固有名 + 効きの上乗せ」を、本家の仕様を伺って具体にする。

## 11.1 伺った本家の仕様

- 固有名のレアKP を持つのは、**基本的にキラ以上**(wcc_f では WORLD CLASS と LEGENDS)。黒・白にもまれに例外がいたが、**今回は対象外**
- **特殊能力が★5のときに KP にすると発動**する
- 効き目は**汎用の上位互換**。選手ごとの伸びしろは分からない
- **特別な動き**ができるようになるものもあった(ルーレット、ロングシュートなど)
- (ユーザーの案)pftb のスキル発動のカットインのように、**KP に設定したときにカットイン**が入るとかっこいい

## 11.2 対象と発動

- 対象: WORLD CLASS 48枚 + LEGENDS 16枚 = **64枚**。1枚に1つの固有のレアKP
- 元になる汎用スキルは、そのカードがいま持っているもの(ファンタジスタ、ストッパーなど)
- **発動の条件: ★5 かつ KP**。★4以下で KP にしたときは、いまと同じ汎用のスキルとスタイル
- 相手チームも同じ規則(相手の KP が WORLD CLASS 以上で★5なら発動)。プレイヤーだけが得をする形にしない(touchline P4)

## 11.3 効き目(汎用の上位互換)

| | 汎用(★5で KP) | レアKP |
|---|---|---|
| スキルのバフ | いまの値(★1つごと +5%) | **上乗せ分を ×1.5**(例: シュート ×1.06 → ×1.09) |
| スタイルの軸 | ★×0.2 + 進化 0.5 | **さらに +0.3** |
| 特別な動き | なし | **カードによって1つ**(§11.4。64枚のうち半分ほど) |

数値は `TUNING.rare` にまとめ、enginetest で「レアKP の有無で得失点差がどれだけ動くか」を測る(目安 +0.1〜0.2。強すぎると★5の WORLD CLASS 以外を使わなくなる)。

## 11.4 特別な動き(技)

選手の手札(CHANNELS)に**技の札が1枚増える**。使うとモニターに技の名前が大きく出る。

| 技 | 持つ役割 | 何が起きるか |
|---|---|---|
| ルーレット | 中盤・FW | ドリブルの手。1人をかわしやすい(成功率が高く、運ぶ距離は短い) |
| ロングシュート | 中盤・FW | 遠目(奥行き 0.55 より手前)からでも撃てる強いシュート |
| ノールックパス | 中盤 | ラストパス。相手に読まれにくい |
| ヒールパス | FW | 前線で背負って落とす手。味方の次の手が強くなる |
| オーバーヘッド | FW | 浮き球(クロス)からのシュートが強い |
| 鉄壁のスライディング | DF | 相手の運ぶ手を止めやすい(守備の手) |
| 神セーブ | GK | 1試合に1回だけ、決まるはずのシュートを止める |

技はスキルの系統から選ぶ(ドリブラー・ファンタジスタ → ルーレット、ミドル・エース → ロングシュート など)。

## 11.5 名前

- 64枚に**架空の固有名**を付ける(例:「黄金の左足」「夜明けの稲妻」「鉄壁の番人」)。**実在選手の愛称や実名は使わない**
- 名前と技の割り当ては `tools/rarekp_source.txt` に書き、`gen_rarekp.py` で `src/js/rarekp.js`(生成物)に出す。キーはカードの No.(MCB01 など)

## 11.6 見せ方

- **KP に設定したときのカットイン**(SQUAD と試合中の両方): 画面を斜めの帯が横切り、選手の絵(play)・固有名・元のスキル名・★5 が出る。約1.2秒、タッチで飛ばせる。LEGENDS は金、WORLD CLASS は紫
- キックオフのときにも、両チームの KP が発動していれば短いカットインを出す
- 技を使ったら、モニターに技の名前(「ルーレット！」)と字幕
- カードの裏面(詳細)にレアKP の名前と技を出す。★4以下のあいだは「★5 で解放」と伏せ字

## 11.7 作る順番

1. 名前・技の表(64枚)と `TUNING.rare`、発動の判定(engine)→ enginetest で効きを測る
2. 技の札(CHANNELS に足す)と、モニターの技の名前
3. カットイン(KP の設定・キックオフ)とカードの表示

## 11.8 決まったこと(2026-11-19)

- この設計で進める。技は**まずこの7種**。あとで増やしていく
- 名前は架空(実在選手の愛称・実名は使わない)

## 11.9 作った(2026-11-19)

- 表: `tools/rarekp_source.txt`(64枚・技は31枚)→ `python tools/gen_rarekp.py` → `src/js/rarekp.js`(生成物)。技を増やすときは `data.js` の `RARE_MOVES` に足し、`gen_rarekp.py` の `MOVES` にも足す
- 発動: `engine.js` の `rareOfCard` / `rareOf`(KP・★5、相手は強さの段 5 以上)。`refreshFx` でバフの上乗せ・軸・技の効果を載せ、名前(`fxName`)を固有名にする
- 数値(`TUNING.rare`): バフの上乗せ分 ×2.0、軸 +0.6、技の札の選ばれやすさ ×1.6、カットイン 1.3秒、技の名前 0.65秒
  (§11.3 の ×1.5 / +0.3 では得失点差 +0.05 だったので強めた)
- **実測**(enginetest ⑫、1000試合): ★5 の汎用 KP 0.91 → レアKP 0.96(**+0.06**)。技は1試合に約1.5回
  (ルーレット・ノールックパス・ヒールパスが多く、ロングシュート・オーバーヘッドは少ない)。目安の +0.1〜0.2 には届かないが、上位互換で控えめな効きとした
- 相手の上位クラブにもレアKP が付いた。clubtest の「段5対段1でも番狂わせは起きる」は、もともと実測がおよそ 2.90 で境目(2.9)に乗っていた
  (1200試合で レアKP あり 2.904 / なし 2.897)。試合数を 600 にし、境目を 2.95 にした
- 見せ方: カットインは `scenes.js` の `cutIn`(SQUAD で KP にしたとき・試合で KP を替えたとき・試合の初めのキックオフ)。
  技の名前は `main.js` の `mvFlash`(ロングシュート・オーバーヘッドは撃つ前、ほかは成功したあと、神セーブは止めたあと)。
  カードの詳細の行は `clubui.js` の `rareRowHtml`(★4以下は「？？？」)

> **2026-11-21 の変更**: 発動の条件は自分も相手も「特殊能力 ★5 かつ KP のランク G」(→docs/15 §15.6・docs/21 §21.5)。相手は強さの段5か Premier Div のリーグ戦を ★5 相当とみなす。
