## 28.1 目標(オーナー)

- 実在のトップクラスの監督で年俸 30〜50億。10〜20任期で 50億を目指せる程度の報酬に
- 年俸が上がるほど求められる成績が厳しくなり、20億前後から上がり方が緩やかに
- 100億あたりからは下がる量が増え、それ以上はかなり上がりにくい
- 監督称号に影響するなら、称号も合わせて見直す

## 28.2 今の作り

- 任期ごとに **ゼロから計算**: 年俸 = 20億 + 稼いだ資金 × 0.15 + 称号の上乗せ(新米 0 〜 レジェンド 120億)+ クラブの目標の上乗せ + オーナーの指令の増減
- 1任期目からおよそ 65〜90億(テストの通しのプレーで 65〜92億)。実在のトップ監督を大きく超える
- 年俸の **累計** で監督ランク(1〜5。レア訓練の出やすさ・クラブオファーの格)とレアオファーの出やすさが決まる(累計 80・200・380・640億で上がる)

## 28.3 新しい作り: 「今の年俸」を持ち続け、任期の評価で上げ下げする

### 年俸の動き
- 監督は **今の年俸** を持つ(新しい監督は 1億から)。任期が終わるたびに、その任期の **評価 P** と、今の年俸で **求められる評価 R** を比べて上げ下げする
- 求められる評価 R は年俸が高いほど上がる: R = 0.40 + 0.30 × log10(1 + 年俸 / 8)
  - 1億 0.42 / 10億 0.51 / 20億 0.56 / 50億 0.66 / 100億 0.74 / 150億 0.79
- P ≥ R(求められた以上): 年俸 × (1 + 上がる係数 × (P − R)) + 少しの底上げ(最大 1億。安い年俸から抜け出せるように)
  - 上がる係数 = 1.1 ÷ (1 + (年俸 / 14)^1.15) → 20億前後から緩やかに
- P < R(求められた未満): 年俸 × (1 − 下がる係数 × (R − P))
  - 下がる係数 = 0.35 × (1 + (年俸 / 90)^2.2) → 100億あたりから下がる量が大きく
- 下限は 1億

### 試算(毎任期が同じ評価のとき)

| 毎任期の評価 P | 5任期 | 10任期 | 15任期 | 20任期 | 30任期 |
|---|---|---|---|---|---|
| 並(0.50) | 3億 | 5億 | 6億 | 7億 | 8億 |
| 良(0.65) | 8億 | 15億 | 21億 | 26億 | 33億 |
| とても良い(0.80) | 12億 | 27億 | 40億 | 51億 | 69億 |
| 最高(0.95) | 16億 | 37億 | 58億 | 76億 | 108億 |

- 評価が任期ごとに ±0.15 ゆらいでも、「とても良い」で 20任期 44〜54億、「最高」で 20任期 76〜81億
- 100億を超えるのは、最高の評価を 25〜30任期続けたときだけ。100億で「良」の任期があると下がる

### 任期の評価 P(0 〜 1.3 くらい)

| 中身 | 重み | 例 |
|---|---|---|
| クラブの目標(獲得賞金 ÷ 目標) | 0.40 × min(1.25, 達成率) | ちょうど達成で 0.40 |
| 監督称号の格(1〜3) | 0.25 × 格 ÷ 3 | 新米・迷将 0.08 / 名将・皇帝・レジェンド 0.25 |
| 勝率 | 0.20 × min(1, 勝率 ÷ 0.65) | 勝率 65% で 0.20 |
| 大会の優勝 | 1つ 0.03(最大 0.15) | |
| オーナーの指令 | 達成 +0.05 / 失敗 −0.05 | |

- 例: 目標を達成・格2の称号・勝率 60%・優勝2つ → 0.40 + 0.17 + 0.18 + 0.06 = 0.81(とても良い)
- 例: 目標の7割・新米監督・勝率 50% → 0.28 + 0.08 + 0.15 = 0.51(並)

## 28.4 ほかの仕組みへの影響

| 仕組み | 今 | 新しく |
|---|---|---|
| 監督ランク(1〜5) | 年俸の累計(80・200・380・640億) | **今の年俸**(5・15・35・70億)。評価の高い監督ほどランクが高い |
| レアオファーの率 | 累計 1億ごとに +0.03% | 今の年俸 1億ごとに +0.3%(上限 25% は同じ) |

| 累計の年俸 | 監督ランクの元 | 歴代の記録として残す(生涯の稼ぎ) |

## 28.6 今のセーブデータ

- 今の「累計の年俸」から、今の年俸を一度だけ見積もる: 累計 ÷ 20(1〜40億)。例: 累計 475億 → 24億
- 監督ランクは見積もった年俸から付け直す(下がることがある)

## 28.7 決めてほしいこと

2. 試算の伸び方(とても良いで 20任期 50億、最高で 12〜15任期 50億、100億は 25〜30任期)でよいか

4. 監督ランクを今の年俸で決める(下がることもある)でよいか
5. 称号の年俸の上乗せ(億)をやめ、称号の格を評価に入れる形でよいか
