## 2. 試合エンジン

pftb の試合エンジン(→`pftb/docs/07-match-engine.md`)の**考え方**を引き継ぎ、
WCCF の「試合中にカードを動かす」に合わせて2点を変えた。コードは写していない。

| | pftb | wcc_f |
|---|---|---|
| 解く単位 | 1ティック = 3分(1攻撃ぶんの連鎖) | **1ステップ = 1アクション**(約25秒) |
| 選手の位置 | 陣形の枠(固定) | **カードの座標そのもの**(自由) |
| ボール | 攻撃のたびに起点を抽選 | **ステップをまたいで持ち続ける** |

### 2.1 柱

1. **勝敗に関わるロジックが正で、見かけはその結果に追従する。**
   エンジンが1ステップ解いてから描画に渡す。描画は読むだけで書かない
2. **指示は演出ではなく、シミュレーションの引数。**
   カード移動・交代・シュートは `orderMatch()` で積まれ、次のステップの頭で効く
3. **同じたねなら必ず同じ試合。** ステップごとに独立したたね
   (`seed ^ hash("s:"+ix)`)なので、指示を出しても以降の乱数列がずれない。
   「同じ試合・同じ流れで、采配だけが違いを生む」比較ができる
4. **能力に掛かる修正は `eff()` に集約する。** いまは 適性 × スタミナ

```js
const M = createMatch(homeDef, awayDef, seed);
stepMatch(M)                  // 1ステップ解いて、そのイベントを返す
orderMatch(M, side, order)    // 指示を積む。いつ呼んでもよい
finishMatch(M)                // 残りを一気に解く
```

### 2.2 時計

前後半それぞれ 110ステップ + アディショナルタイム(前半1〜5 / 後半3〜9)。1試合 224〜234ステップ。
アディショナルタイムの長さはキックオフ時点で確定する。

再生は1ステップ 0.62秒(等速)なので、**カードを動かしてから効くまで最長0.6秒**。
1試合は等速で3分弱。

### 2.3 座標と役割

座標は**自軍フレーム**: `h` = 0(自陣ゴール)〜1(敵陣ゴール) / `x` = 0〜100(左右)。
相手から見た位置は `(1-h, 100-x)`。

**役割はカードの置き場所で決まる。**

```
           x<27 または x>73      中央
 h<0.36         SB               CB
 0.36〜0.68     SMF              DMF(〜0.47) / CMF / OMF(0.58〜)
 h≧0.68         WG               CF
```

GK は**ペナルティエリアの中だけ**動かせる(→§2.3a)。役割は常に GK。

**適性**はカードのポジションと得意な役割から出て、全能力に掛かる。

| 置いた役割が | 倍率 |
|---|---|
| 得意な役割 | 1.00 |
| 同じポジション(DF/MF/FW) | 0.90 |
| 隣のポジション | 0.76 |
| DF ↔ FW | 0.62 |
| GK とフィールドの取り違え | 0.35 |

### 2.3a GK の立ち位置

本家と同じく、GK のカードはペナルティエリアの中で動かせる(`h` 0.03〜0.15 / `x` 28〜72)。
**定位置(中央・ライン上)が基準で、そこでは何も変わらない。** 動かすと得と損の両方が出る。

| 動かし方 | 得 | 損 |
|---|---|---|
| ボールのある側へ寄る | その側からのシュートに強い | 逆側から撃たれると弱い |
| 前へ出る | 近距離のシュートに強い(+12%まで)。**裏へのボールやドリブルに守備者として対応する** | 遠目のシュートに弱い(−30%まで) |

- 左右は「寄るべき位置からのずれ」で数える。定位置よりずれが小さければ得、大きければ損
- 飛び出した GK が競り勝つと、その場で GK がボールを持つ
- GK は隊列と一緒には動かない(`blockH` の対象外)。置いた場所に居る
- 相手の GK は定位置のまま(相手監督がカードを動かす段で扱う)

実測(1000試合): 前に出しっぱなし 失点 1.28 → 1.22(得失点差 +0.05 = ノイズ内) /
片側に寄せたまま 失点 1.28 → **1.72**。**置きっぱなしでは得をせず、ボールに合わせて動かすと効く。**

### 2.4 隊列はボールに合わせて動く

```js
blockH(p, ballH) = p.h + (ballH - 0.5) × 0.34     // GK は動かない
```

カードの配置は**隊列の形**で、隊列全体がボールの高さに合わせて上下する。
判定と描画が同じ式を使うので、映像に見えている位置がそのまま判定に使われる。

### 2.5 1ステップ — 持っている選手が1つ動く

```
 ① 撃つか(→§2.6)
 ② 手札を選ぶ    役割ごとに3枚。得意な能力の手ほど選ばれやすい
 ③ 行き先        前進は「残り距離に対する割合」。ロングボール・クロスは to で届く高さを保証
 ④ パスなら受け手 行き先に近い味方。近くに居なければパスの質が落ちる
 ⑤ 競り合い      近い守備者と勝負。勝てばボールが進み、負ければ相手ボール
```

手札は `CHANNELS`(9役割 × 3枚 = 27種)。`carry`(自分で運ぶ)と `pass`(味方へ渡す)。

**競り合いの形**(pftb §7.4 と同じ: 攻撃側スコア > 守備側スコア × 閾値):

```js
攻 = (off×0.30 + 手札の能力×0.70) × risk × 受け手の質 × ぶれ
守 = (def×0.60 + 手札の能力×0.40) × 圧 × 厚み × ぶれ
成功 = 攻 > 守 × 0.40
```

- **圧**: 対応する守備者が近いほど強い(0.30〜1.0)。誰も居ない場所は素通りになる
- **厚み**: 周りの守備者の数(スタミナ込み)。人を集めた場所は堅い
- **ゴール側に立つ守備者は遠くても間に合い、裏を取られた守備者は近くても届かない**
  (距離を ×0.55 / ×1.35 で数える)
- **守備の隊列は「いまボールがある高さ」で決まる**。届け先ではない。
  だからラインが高いと裏へのボールに戻りきれない
- 自分の持ち場から離れるほど運ぶ手を選ばなくなり、パスに寄る(独走を防ぐ)

負けたら、競った相手がその場でボールを持つ(座標を反転して相手の攻撃が始まる)。
**高い位置で失えば高い位置から攻められる。**

### 2.6 シュート

(セットプレーからのシュートは §2.10、スキルとスタイルの乗り方は §2.12)

撃つ判断: 深いほど・中央ほど・`off` が高いほど。`h<0.62` では撃たない。
**SHOOT ボタン**を押すと、`h≧0.55` で持っていれば次のプレーで必ず撃つ(3ステップ有効)。

```
 シュート
   ├ ① ブロック   近い守備者(圧 × 厚み)が身体を入れる
   ├ ② 枠外       技術・距離・角度で決まる
   └ ③ 枠内 → GK  (撃つ側/GK)^0.45 で競る(能力差をそのまま決定率にしない)
        ├ ゴール → 失点した側のキックオフ
        └ セーブ → 25% でこぼれ球(詰め合い)。それ以外は GK から再開
```

### 2.7 スタミナ

全員が毎ステップ減り(役割ごとに走行量が違う)、プレーに関わるとさらに減る。`sta` が高いほど緩やか。
ハーフタイムに 8pt 戻る。下限 20%。交代で入った選手は 100% から始まる(交代は3人まで)。

**減り始めは軽く、半分を切ると急に重くなる。**

```js
響く量 = min(0.75, (1 − スタミナ)^1.5 × 1.3)
eff = 素の能力 × 適性 × (1 − 響く量 × 能力ごとの重さ)     // spd 0.9 / tec 0.7 / off・def 0.5 / pow 0.3
```

| スタミナ | spd | tec | off・def | pow |
|---|---|---|---|---|
| 80% | ×0.90 | ×0.92 | ×0.94 | ×0.97 |
| 60% | ×0.70 | ×0.77 | ×0.84 | ×0.90 |
| 40% | ×0.46 | ×0.58 | ×0.70 | ×0.82 |
| 20% | ×0.33 | ×0.48 | ×0.63 | ×0.78 |

**40% を切ると「足が止まった」と実況に出る**(1人1回)。盤面のカードは色がくすみ、
映像の選手の下に赤い残量が出る。カードをタップすると体力の数字が見える。

#### 実測(1000試合)

| | |
|---|---|
| 60分の平均 | **68%** |
| 終了時の平均 | **46%**(最も消耗 24% / 最も余力 59%) |
| 足が止まる選手 | **3.1人/試合**(両チーム計) |
| 60分に消耗した3人を替える | 得失点差 **+0.47 → +0.65**(勝率 49% → 53%) |
| プレスを90分続ける | 終了時 49% → **39%**。得失点差 +0.47 → +0.23 |

> **最初の版は消耗が見えなかった。** 終了時の平均が 66% で、効き方も線形だったので、
> 両チームが同じように少しずつ落ちて相殺されていた(→touchline P1・P5)。
> 減る量を約1.7倍にし、半分を切ると急に落ちる形にして、知らせる合図を足した。

### 2.8 相手監督

**相手監督にできるのは、プレイヤーと同じ「カードを動かす」「KP を替える」「指示を出す」「交代する」だけ。**
専用の補正は持たない(→touchline P4 の対称性)。乱数も使わないので、同じ試合なら同じ手を打つ。

| | 中身 |
|---|---|
| **構え** | 負けていて60分以降 → 前がかり(ラインを上げる指示。80分以降はプレスも)。勝っていて70分以降 → 固める(ラインを下げる指示 + カードを中央へ寄せる ×0.65)。同点に戻れば構えも戻す |
| **KP** | 構えに合わせて替える。前がかり → 攻撃のスタイルを持つカード / 固める → 守備のスタイルを持つカード / 戻す → クラブの既定。候補の中ではランクの高いもの(→§2.12) |
| **マーク** | 相手の前線(`h≧0.62`)の左右に、最終ラインが付いていく(差の4割・最大10)。**前線のカードを動かすと相手の守備が釣られる** |
| **GK** | ボールのある側へ寄る(→§2.3a) |
| **交代** | 55分以降、スタミナが 50% を切った選手を同じポジションの控えと替える |

- カードは**少しずつ**寄る(1ステップに縦 0.012 / 横 1.5 まで)。人の手で動かす速さを模している。
  だから動かした直後には隙がある
- 適性が落ちる場所へは動かさない(寄せる量を減らす。それでも落ちるなら基準の位置に留まる)
- 構えが変わると `posture` イベントが出て、実況に「前がかりになった」などと出る

#### 実測(1000試合・ホームは何も動かさない)

| 相手監督 | 得点 - 失点 |
|---|---|
| 交代だけ | 1.66 - 1.31 |
| マーク無し | 1.68 - 1.31 |
| GKの追従無し | 1.24 - 1.35(マーク 0.6 のとき) |
| **全部あり(マーク 0.4 / 最大10)** | **1.37 - 1.36** |
| 全部あり(マーク 0.6 / 最大14) | 1.22 - 1.35 |

- **効いているのはほぼマークだけ**。得点を 0.3 削る。0.6 だと削りすぎ(−0.46)なので 0.4 にした。
  いまの2クラブでは「何も動かさなければ五分、動かせば上回れる」位置になっている
- 構えは平均の得失点をほとんど動かさない(負けている側が取りに行き、取られもする)。
  試合の終わり方は変わる(300試合の終了時: 前がかり 107 / 固める 119)
- **GK をボールに合わせ続ける得は小さい**(自分でやっても失点 1.35 → 1.29)。
  寄せ損ねの損(片側に置きっぱなしで +0.44)に比べて釣り合っていない(→§2.9 の歪み)

#### いま分かっている歪み

- **ラインを上げる損が小さい**(失点 1.21 → 1.33、得点 1.68 → 1.87)。オフサイドが入って、
  高いラインが裏へのボールを反則で消せるようになったため。得失点差では +0.07 で、ほぼ相殺
- **ラインを下げても失点が減らない**(1.21 → 1.22)。守備的に戦うなら
  「中央を固める」か戦術の「リトリート」(→§2.11)
- **「動かすと得」がまだ数字で確かめられていない**。相手のマークを前線で釣って空いた所を突く、
  という動かし方は時間差を使う操作なので自動では測れていない(人が触って確かめる)
- GK を合わせ続ける得は小さい(→§2.8)。**これは歪みではなく仕様**(原則動かさないが動かせる →docs/03)
- シュートが現実より多い(29.1本)。セットプレーのぶんが上乗せされている
- パス成功率が現実より低い。後ろでの安全な横パス・バックパスの手札が無いため
- 退場がやや多い(0.31人/試合・退場者の出る試合が 28%)
- 2クラブの力が揃っていない(同じ条件でホームが +0.46)。陣形・カード・スキルの差で、ホームの利ではない

### 2.10 反則とセットプレー

**反則は独立に抽選しない。入口は「守備側が競り勝った瞬間」だけ**(pftb §7.11 と同じ考え方)。

ペナルティエリアは**実寸**(`h≧0.843`・中央 ±29.6)。映像と盤面の線も同じ値から引き、盤面には敵陣のエリアも出す。
何も起きていない所で笛が鳴ると、それは見せかけのロジックになる。

```
競り合いで守備側が勝つ ─┬─ 反則(持ち運びを止めた 62% / パスを止めた 43%。エリア内は ×0.08)
                        │     ├ エリア内 → PK
                        │     ├ h≧0.60  → フリーキック(次のステップで蹴る)
                        │     └ 手前    → その場で再開(攻撃側のボールのまま)
                        ├─ 深い位置(h≧0.85)なら 40% でコーナーへ逃げる
                        └─ それ以外は守備側のボール

シュートをブロック ─── エリア内なら 3% で反則(PK) / 55% でコーナー
GK がセーブ ────────── 40% でコーナー / 25% でこぼれ球 / 残りはキャッチ
枠外 ───────────────── ゴールキック
パスが通らずタッチ際 ── 相手ボール(実況に「タッチを割る」)
```

| | 中身 |
|---|---|
| **警告・退場** | 反則のたびに引く。警告 21% / 一発退場 0.3%(PKになる反則は ×2.5)。警告2枚で退場。**退場すると人数が減ったまま続く**。GK は退場させない。8人を割る退場は起こさない |
| **PK** | 蹴るのは `off×1.2 + tec` の最良。壁もブロックも無い。枠内 90% → GK と勝負(圧縮なし・閾値 `thPk`) |
| **直接FK** | `h≧0.68` で中央寄りなら 55% で直接狙う。蹴るのは `tec×1.2 + off×0.8` の最良。24% で壁に当たる |
| **FK(クロス)・CK** | ボックスへ入れて**空中戦**(`pow×0.65 + off/def×0.35`)。勝てば 55% でヘディング、残りはこぼれて続く。負ければ相手ボール |
| **オフサイド** | パスの届け先が**相手の最終ライン**(GKを除いていちばん後ろ)より前なら、出すぎた幅に応じて最大 30% で取られる。相手のフリーキック(その場で再開) |

セットプレーからのシュートも通常と同じ経路(枠 → GK → こぼれ球)を通る。別経路にはしない。

**ラインの高さがオフサイドに効く。** 最終ラインのカードを上げるほど相手のオフサイドが増え、
裏を取られたときは戻れない(→§2.5)。

#### 実測(1000試合・1試合あたり・両チーム計)

| | 実測 | 現実の水準 |
|---|---|---|
| 反則 | **10.3** | 約22 |
| 警告 / 退場 | **2.3枚 / 0.31人** | 3〜4枚 / 0.15人 |
| フリーキック(蹴るもの) | 6.7 | — |
| コーナー | **9.0** | 約10 |
| PK | **0.34本**(決定率 **75.1%**) | 約0.25本(約76%) |
| オフサイド | **4.3** | 約4 |
| セットプレーからの得点 | 全得点の **18.2%** | 約25〜30% |

> **反則が現実の半分なのは、試合を約225アクションに圧縮しているため。** 競り合いの回数そのものが
> 現実より少ない。率を上げて数を合わせると、守備側が勝つたびに笛が鳴る試合になる。

### 2.11 監督の指示

設計は [docs/04 §4.9](04-kp-style-design.md)。筐体のボタンにあたるもので、**スタイル(§2.12)とは独立**。
同じボタンをもう一度押すと解除。上げる/下げる、左/右はどちらか一方だけ。

| 指示 | 仕組み |
|---|---|
| ラインを上げる / 下げる | 隊列全体を ±0.05 ずらす(`blockH` に加算。カードは動かない)。上げると敵陣の競り合いに人数が掛かり(+12%)、自陣の守備は薄く(−8%)、裏を取られると戻れない(+15%)。下げるとその逆 |
| 左サイド / 右サイド重視 | そのサイドの選手が受け手に選ばれやすく(×1.6)、逆サイドは選ばれにくい(×0.6)。外へ開く手がそちらを向く。左 = 画面の上側 |
| プレス | ボールが敵陣にあるとき守備 ×1.12 / 自陣で ×0.97 / スタミナ消費 ×1.12 |
| シュート | `h≧0.55` で持っていれば次のプレーで撃つ(3ステップ有効) |

#### 実測(1000試合・ホームだけ出し続ける)

| | 得点 - 失点 | 目立つ変化 |
|---|---|---|
| 指示なし | 1.75 - 1.20 | — |
| ラインを上げる | **1.94 - 1.31** | 相手のオフサイド 1.0 → 3.1。得点も失点も増える |
| ラインを下げる | 1.45 - 1.15 | 相手のオフサイド 1.0 → 0.2。シュートが減る |
| 左サイド重視 | 1.89 - 1.17 | ボールの通る位置(x の平均)53 → 43 |
| 右サイド重視 | 1.71 - 1.16 | 53 → 62 |
| プレス | 1.63 - 1.23 | 相手のパス成功 74.7 → 73.8%。出し続けると消耗で損 |

出しっぱなしで得をする指示は無い(上積みは最大 +0.17)。左サイドが右より良いのは、
このクラブの左(11番)の線とスキルのため。

> **ラインを下げても失点はほとんど減らない**(1.20 → 1.15)。守るなら全体スタイルの
> リトリートやオーガナイズドディフェンスのほうが効く。指示は「形を寄せる」もので、守備の主役ではない。

### 2.12 スキル → スタイル + バフ

設計は [docs/04](04-kp-style-design.md)。**カードはスキルを1つ持ち、スキルがスタイルとバフを引き当てる。**

```
 カード ─▶ スキル ─┬─▶ バフ      本人に常時。決まった場面だけに効く(×1.05〜1.10 が中心)
                   └─▶ スタイル  **KP にしたときだけ**発動。全体 17種 / 個人 24種
```

- **KP は1クラブ1人、試合中いつでも替えられる。替えるとスタイルが替わる**(同時に有効なのは1つ)
- 替え方は2つ: 指示ボタンの並びの **KP ボタン → カードをタップ** / カードをタップして開く詳細の「KP にする」
- KP を交代で下げる・退場すると、スタイルは消える(別のカードを KP にし直す)
- どのスタイルでも、KP にはボールが少し集まる(受け手 ×1.25)
- 効いたときはイベントに名前が残り、実況に「★」で出る。KP の個人スタイルが乗っているときはスタイル名で出る
- 映像の下の帯に、両チームの KP・スタイル・ランクが常に出る

#### 実装の形

| | |
|---|---|
| `SKILLS[id]` | `{ label, desc, style, buff }` |
| `STYLES[id]` | 全体: `{ scope:"team", axis, gain, cost }` / 個人: `{ scope:"solo", axis, fx }` |
| `p.fx` | 選手ごとの効果。バフ + (KP で個人スタイルなら)`fx × ランク` を合成したもの |
| `T.fx` | チームの効果。全体スタイルの `gain × ランク` と `cost`(満額)を合成したもの |
| `refreshFx()` | 毎ステップの頭で両方を組み直す |

判定の側は `p.fx.shot` や `T.fx.highK` を掛けるだけで、スタイルの id を見ない。
**スタイルやスキルを足すときは `data.js` だけを触る**(新しい語彙が要るときだけ判定に1行足す)。

#### ランク — 戦力グラフの6軸

```js
軸の値 = その能力の上位6人の平均(適性込み) + 連携の上乗せ(最大 +1.0)
ランク = 16.4以上 S / 15.0以上 A / 13.6以上 B / それ未満 C      倍率 S 1.25 / A 1.0 / B 0.8 / C 0.5
```

| 軸 | 能力 |
|---|---|
| O オフェンス / D ディフェンス / R 支配 / S スピード / P パワー | `off` / `def` / `tec` / `spd` / `pow` |
| C 奪取 | `def`・`spd`・`sta` の平均 |

- **倍率は「得るもの」にだけ掛かる。「失うもの」は満額**。実測(ショートパスワーク):
  パス成功 C 79.5% / A 81.5% / S 82.4%。シュートの減りは C でも同じ
- 値は**いま盤面に居る11人**で出す。交代・退場・カードの置き場所(適性)で変わる
- いまの2クラブ: アズーロ O・D・R・S・P が A、C が B / ロッソ S が S、ほかは A、C が B。
  **ほとんど A に揃っていて、差が出ていない**(下の歪み)

### 2.13 連携

設計は [docs/04 §4.6](04-kp-style-design.md)。カード同士の線で、段は 1〜3。盤面に線で見える(段が高いほど太く、3は金色)。

| | |
|---|---|
| ペア間のパス | 線で結ばれた2人のパスの競り合い ×(1 + 0.04 × 段)。段3で ×1.12 |
| ランク | 盤面に居る線の段の合計 ÷ 16 が、軸の値に最大 +1.0 乗る |
| スタイルとの絡み | コンビネーションプレイ(ペア間の効きが倍・線の無い相手へは ×0.95)/ フォアザチーム(KP と線のある味方の全能力 +3% × 段) |
| 持ち方 | いまは `TEAMS[].links` の固定値(両クラブ9本・合計18)。段階3で育つようにする |

### 2.14 いま分かっている歪み(スタイルまわり)

- **全体スタイルの多くが、得失点差では「KP なし」より良くならない**。試合の形は変わる(上の表)が、
  勝ちやすさでは ゴールハンティングなどの個人スタイルのほうが上。
  **「全体スタイルを選ぶ理由」がまだ数字に出ていない**。失うものが満額で、得るものが控えめなため
- **ショートカウンター・コンビネーションプレイ・マンツーマンは、目立つ変化が測れていない**
- **ランクがほとんど A に揃う**。2クラブの能力が似ているためで、クラブが増える段階4で開く見込み。
  練習でグラフを伸ばす仕組み(段階3)もまだ無い
- 個人スタイルの半分は ±0.1 以内。KP にする選手の役割と噛み合うかで決まるはずだが、
  この測り方(1人に固定)では噛み合いの差を見ていない
- 相手監督の KP 選びは「構えに合う種類の中でランクが高いもの」だけ。こちらのスタイルは見ていない
