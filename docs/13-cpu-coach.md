# 13. 相手監督の采配(陣形の変更と性格)(2026-11-19)

D2 の残り(「相手の布陣に応じて陣形そのものを変える」)の設計。

## 13.1 伺った本家の仕様

1. **手薄なスペースを狙う**: プレイヤーのカード配置を見て、守備が手薄なサイドやバイタルエリアへボールを集める。極端な攻撃的布陣・偏った配置には、その裏を突く
2. **時間と点差でスタイルを切り替える**: リード時は守備、ビハインド時は攻撃のスタイルへ。終盤は**パワープレー(前線に人数をかける)**か**守備固め(逃げ切り)**
3. 強いCPUは、士気が溜まるとレアなスタイルやスペシャルコマンドで攻勢をかける
4. **交代と配置**: 後半15〜30分以降、疲れた選手を替える。**リード時は守備的な選手を入れてラインを下げ、ビハインド時は FW や攻撃的MF を入れて前線の枚数を増やす**(カードの配置そのものを動かす)
- pftb では監督に**性格**をランダムに与えた(自分の戦略を貫くタイプ、相手に合わせてすぐ動くタイプなど)

## 13.2 いまの相手監督と、足すもの

| | いま | 足すもの |
|---|---|---|
| 構え(点差) | 負けていれば前がかり、勝っていれば固める。KP と指示も替える | 性格で切り替える時間が変わる |
| **陣形** | 変えない(マークで左右に寄るだけ) | **パワープレー / 守備固め**で、カードの基準の位置を動かす(§13.3) |
| **狙う場所** | 指示は中央突破・カウンター・プレスだけ | **プレイヤーの配置を見て、手薄なサイドへ「左/右サイド」の指示**。前がかりの布陣には裏を突く(§13.4) |
| **交代** | 疲れた選手を同じポジションの控えと | **点差で入れる選手を変える**(負け: FW・攻撃的MF / 勝ち: DF・守備的MF)。入れた選手を攻め・守りの位置に置く |
| レアKP | 強さの段5なら発動(docs/11) | (済) |
| 性格 | なし | **5つの性格**(§13.5) |

士気ゲージとスペシャルコマンド(③)は、本作に士気の仕組みがないので今回は入れない。

## 13.3 陣形の変更

構えが変わったときに、相手のカードの**基準の位置**(監督が戻ってくる場所)を動かす。実況と盤面の上に「[相手] 3トップにしてきた」などを出す。

- **パワープレー**(負けていて終盤): 攻撃的な MF 2人を前線(FW の列)へ、SB を高く、最終ラインも少し上げる。守りは薄くなる
- **守備固め**(勝っていて終盤): FW 1人を残して中盤へ下げ、SMF・WG を低く、最終ラインを下げる。攻めは細くなる
- 構えが戻ったら、元の位置に戻す
- 位置が変わると適性が下がることがある(本家と同じく、無理な配置には代償がある)

## 13.4 手薄なスペースを狙う

数ステップごとに、プレイヤーの配置(相手から見た左右)を数える。

- 片方のサイドの守備の人数が、もう片方より2人以上少なければ、そのサイドへ「左サイド」か「右サイド」の指示
- プレイヤーの最終ラインが高い・前線に人数をかけている(敵陣に6人以上)なら「カウンター」の指示(裏を突く)
- プレイヤーがカードを動かすと、相手もそれに合わせて変わる。**読み合いが生まれる**

## 13.5 性格(5つ)

クラブごとに決まった性格を持つ(試合ごとに変わらない)。対戦カードの画面に「相手監督: 即応型」と出す。

| 性格 | 動き |
|---|---|
| 堅実 | いまの標準 |
| 即応 | すぐ動く。構えの切り替えが15分早く、手薄なスペースを試合の初めから狙う。交代も早い |
| 頑固 | 自分の戦略を貫く。構えの切り替えが15分遅く、スペースを狙わない。陣形も変えにくい |
| 攻撃的 | 同点でも終盤は前がかり。パワープレーが早い |
| 慎重 | リードしたらすぐ固める。パワープレーをしない |

数値は `TUNING.coach` に性格ごとの表として持つ。enginetest で「性格で勝ち負けが大きく偏らない」「手薄なサイドを突くと、プレイヤーが偏った配置にしたとき失点が増える」を確かめる。

## 13.6 決まったこと(2026-11-19)

- 性格はこの5つ。陣形の変更は**実況の1行**で知らせる(字幕は出さない)

## 13.7 作った(2026-11-19)

- `engine.js`: `persOfClub`(クラブごとの性格)、`setShape`(パワープレー / 守備固め。元の位置は `p.b0`)、`coachAim`(手薄なサイド)、
  `coachTacSub`(点差で選ぶ交代。1試合1回)。`coachMove` が構え・陣形・狙いをまとめて決める。数値と性格の表は `TUNING.coach`
- 実況: 「パワープレー！ 前線に人数をかけてきた」「守備固め。前の選手を下げて逃げ切りを図る」(`main.js` の `shape`)
- 対戦カードの画面に「相手監督: ○○型」(`scenes.js` の `sideHtml`)
- 前がかりのときは、サイドの狙いがあっても中央突破を残す(サイドだけに切り替えると点が減った)
- 裏を突く(カウンター)のは、プレイヤーが敵陣に**8人以上**かけたとき(6人では普段の攻めでも出てしまい、点が減った)
- **実測**(enginetest ⑭、各300〜600試合)
  - 性格ごとの得失点差(段の同じ相手に): 堅実 0.15 / 即応 0.27 / 頑固 0.25 / 攻撃的 0.19 / 慎重 0.20。陣形を変える回数は1試合に 0.6〜0.9 回(頑固は 0)
  - プレイヤーが片側に寄せた配置は、それだけで失点が 1.19 → 1.61 に増える(空いたスペースはエンジンの中で突かれる)
  - サイドの指示そのものの効きは小さい(空いた側 +0.04 / 混んだ側 −0.16)。相手監督は空いた側を選ぶが、指示による上積みはわずか。
    サイドの指示を強めるとプレイヤーの指示の釣り合い(docs/02 §2.11)も変わるので、今回は触らない
