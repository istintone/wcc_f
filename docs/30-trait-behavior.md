# 30. 特性タグの動き(2026-11-27)

オーナーの希望: 選手タグの特性(アンカー・No.9.5 など)を付けた選手が、試合中にその特性に合った動きやプレーをする。見た目(映像)とゲームロジック(試合の処理)の両方で。例: アンカーはボールを奪ったらすぐパス、9.5番は低い位置までボールをもらいに来る。

## 30.1 いつ効くか

- 特性タグ(`TAGS` の kind:"trait")を持つ選手が、そのタグのポジション(`pos`)で先発したときだけ
- `grow.js` の `applyTagStats` が、カードの写しに `trait`(例 "anchor")を付ける。試合の処理と映像は `p.c.trait` を見る
- 能力の上乗せ(タグの `stat`)は今まで通り。動きはそれに加えて
- 数値はすべて `TUNING.trait`

## 30.3 釣り合い

- 特性は能力の上乗せと合わせて「得なもの」なので、**動きだけでは損も大きな得もしない**ように合わせた
- 測り方: 自分のチームのそのポジションの全員に特性を付け(能力の上乗せは無し)、400試合の得失点差を特性なしと比べる。誤差は ±0.1 くらい

| 特性 | 得失点差の変化 |
|---|---|
| ストッパー | +0.02 |
| ウイングバック | −0.01 |
| スイーパー | −0.03 |
| ファンタジスタ | +0.04 |
| No.10 | +0.01 |
| ターゲットマン | +0.10 |
| ドリブラー | +0.06 |
| スイーパーキーパー | −0.09 |

- 60試合の目安(誤差 ±0.3): 守護神 +0.12・壁 +0.12・リベロ +0.08・クロッサー +0.13・番犬 +0.10・アンカー +0.20・ボックス・トゥ・ボックス +0.13・No.9.5 +0.18
- アンカー: 奪ってすぐのパスの割合 67% → 94%
- No.9.5: CF が受ける高さの平均 0.849 → 0.816
