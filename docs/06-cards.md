## 6. カード(段階4)

本家はカードが筐体から出てくる「現実の体験」だった。本作では**試合のあとに1枚払い出され、
コレクションに入り、登録選手と入れ替えて次の試合から使える**形にする(後継の Footista に近い。ある程度オリジナル)。
実装は `src/js/pool.js`。

### 6.1 カードの一覧 — 実在の16クラブ

**16クラブ × 16人(先発11 + 控え5)= 256枚。** 時点は **2025-26 シーズン終盤の主力**(2026年夏の移籍は入っていない)。

**このリポジトリ(公開)には実名を書かない。** 本体での呼び名(偽名)で書く。

| リーグ | クラブ(本体での呼び名) |
|---|---|
| イングランド | マンチェスター・ブルー / マンチェスター・レッド / ノースロンドン・レッド / マージーサイド・レッド / ロンドン・ブルー |
| スペイン | カタルーニャ・グラナ / マドリード・ブランコ / マドリード・ロホ |
| イタリア | ミラノ・ロッソ / ミラノ・ネロ / トリノ・ゼブラ / ローマ・チェレステ / ローマ・ジャッロ |

#### データの流れと、実名の置き場所

```
tools/squads.local.txt        実名入りの元データ(Git管理外)。1行1人で直せる
        │  python tools/gen_cards.py
        ├─▶ src/js/realcards.js     本体に入る。**名前もクラブ名も偽名**
        └─▶ packs/real.local.json   実名パック(Git管理外)
                │  python build.py --real
                └─▶ index.local.html  実名で遊べる手元用(Git管理外。公開しない)
```

- **偽名は実名から機械的に作る**: 名前の最後の音の母音をずらす(ア段 → オ段、イ段 → エ段 など。ン で終わる名前は ル に替える)。
  クラブ名は手で付けた偽名(マンチェスター・ブルー など)
- 本体の `index.html` と `realcards.js` に実名が入っていないことは、ビルドのたびに確かめる
  (実名パックは段階5で、ゲーム内の「データ読み込み」からも入れられるようにする)

#### 能力の付け方

元データには能力の数値を書かない。**役割・格・特徴**だけを書き、ゲーム側で作る。

```
能力 = 役割のひな形 + (格 − 0.9) × 0.8 + 特徴(+ で +1.5 / − で −1.5)
       (低い能力(6以下)には格のずれの半分だけ乗る)
```

| 格 | 目安 | 例 |
|---|---|---|
| 3.0〜3.4 | 世界最高峰 | 各リーグの得点王級・バロンドール候補 |
| 2.5〜2.9 | 各クラブの中心 | 代表の主力 |
| 1.8〜2.4 | 主力 | |
| 1.0〜1.7 | 控え・若手・ベテラン | |
| 0.6〜0.9 | 第2・第3 GK | |

能力の付け方は私(Claude)の判断。**誰が強すぎる・弱すぎるは、格の数字1つを直せば変わる。**

#### 相手クラブとして

16クラブは**相手としても登場する**。先発11人の格の平均で上位8クラブが**段5**、残り8クラブが**段4**。
段1〜3は今までどおり架空のクラブ(15クラブ + ロッソ・ユナイテッド)。陣形と KP は元データで決める。

### 6.2 レアリティ

**格で決まる。**

| | 格 | 枚数 | 払い出しの率 | 能力の平均 |
|---|---|---|---|---|
| 白 | 1.6 未満 | 101 | 60% | 12.1 |
| 黒 | 1.6〜2.2 | 91 | 30% | 13.1 |
| キラ | 2.2〜2.8 | 48 | 8.5% | 13.4 |
| レジェンド | 2.8 以上 | 16 | 1.5% | 14.4 |

- 最初のチーム(アズーロFC の16枚)は**黒**として扱う
- 払い出しは「レアリティを抽選 → その段から1枚」。たねは任期と試合数で決まるので、**読み込み直しても同じカードが出る**
- 同じカードが重なったら枚数が増えるだけ(いまは使い道が無い)

### 6.3 コレクションと登録

| | |
|---|---|
| コレクション | `S.coll {カードid: 枚数}`。**任期をまたいでも消えない** |
| 登録選手 | `S.sq`(16枚)。先頭11枚が先発で、並びは陣形の枠の順。12〜16枚目が控え |
| 登録の入れ替え | コレクションのカードを選び、入れ替える登録選手を選ぶ。**入った選手は外れた選手の位置に入る**。次の試合から使える |
| 育成 | **外した選手の育成(★・能力・やる気・連携)は消える**。入った選手は初めから |
| 先発と控えの入れ替え | 登録選手の一覧で2行タップ。育成は消えない |

- 試合中の交代は、その試合だけのもの。次の試合はまた登録の並び(と前の試合の最後の配置)から始まる
- 任期の終わりについてくる選手(→docs/05 §5.8)は、登録を外していればついてこない
