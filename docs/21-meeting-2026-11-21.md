# 21. 3回目のブラッシュアップ会議(2026-11-21)

オーナーの依頼: 全体をプレーして、品質や矛盾がないか、より面白くできそうな要素・できなそうな要素、ゲーム体験の質について、もう一度ミーティングを開く。

## 21.1 やったこと

- **通しのプレー**: 1任期(100試合)を、次の流れで自動で回した(7通りのたね)。
  - オファー: いちばん大きいクラブを選ぶ。
  - 練習: KP の軸を狙う。疲れたら休憩。
  - コミュニケーション: 調子の落ちた選手のケア、★突破の話が出たらミーティング、それ以外は個人練習。
  - 試合: 監督まかせ。
- **画面**: この2日で作った画面を、390×800 で一通り見直した。
- **コード**: 仕組みのつなぎ目を読み直した(任期・周・リーグ・カップ・指令・称号)。

## 21.2 不具合・矛盾(直すべきもの)

| # | 内容 | 重さ | 直し方の案 |
|---|---|---|---|
| 1 | **任期の最後の周が途中で終わる**。1周は43試合なので、100試合目は3周目の14試合目。3周目のリーグは4節しか無く、最終節(昇格・降格・優勝)が来ない | 中 | 3周目の扱いを決める(下の §21.5 で伺う) |
| 2 | 3周目にリーグの指令(「N位以内」)が出ると、決着しないまま任期が終わる(年俸に入らず、記録にも残らない) | 小 | 任期の最後の周ではリーグの指令を出さない。決着しない指令は任期の終わりに「時間切れ」として記録 |
| 3 | 特殊能力 ★5 が出ないので、**レアKP(★5 かつランク G)にほぼ届かない**。成長グラフの改修で、条件が「★5 のみ」から「★5 かつ G」に重くなった | 中 | ミーティングの導線を見直す(★突破の話が出やすい・兆しの見える化)か、レアKP の条件を「★5 かつランク S 以上」に下げる |
| 4 | 称号がほぼ「覚醒工場」になる(覚醒8人は普通に届く)。ほかの称号が取れず、称号のセットや監督の格の変化が単調 | 中 | 覚醒工場の条件を引き上げる(例 12人)か、条件の判定順を見直す |
| 5 | 相手のレアKP は「段5なら発動」、自分は「★5 かつ G」。Premier では相手が毎試合レアKP を持つことになり、差が大きい | 小〜中 | 相手も「ランク G の KP のときだけ」に合わせる(Premier の相手は G なので、Premier では発動し、1st Div 以下では発動しない) |
| 6 | カップを棄権すると、その大会のトーナメント表が途中のまま残る | 小 | 棄権したら残りの試合を計算で埋める |
| 7 | 1st Div・Premier の残留の知らせ(🛡・➡)が、昇格・降格と同じ大きさで毎周出る | 小 | 残留は控えめな表示に(結果の画面の帯を小さく) |

## 21.3 体験の質(観点ごとの総評)

### ゲーム体験(流れ・手触り)

- **良い**: 準備の4段(チーム練習 → コミュニケーション → 視察 → 戦略方針)で、「練習の効果が見える」「相手が分かってから采配を決める」流れができた。どの画面も盤面とカードの見た目がそろい、迷いにくい
- **課題**: 1試合ごとのタップが多い(練習の選択と決定・コミュニケーション3回・視察・戦略方針・キックオフ)。100試合の任期では作業になりやすい
  - 案: 「前回と同じ」ボタン(練習の強度と候補・戦略方針をそのまま)、視察を読み飛ばせる「そのまま戦略方針へ」、コミュニケーションの「おまかせ」(秘書が選ぶ)

### 数字の釣り合い(バランス)

- **良い**: 黄金期の時期、獲得賞金の期待、Div ごとの相手の強さは、狙いどおりに動いている
- **課題**: §21.2 の 3・4・5(レアKP・称号・相手のレアKP)。Premier は相手が「育成最大 + レアKP」なので、届いたときの壁が厚すぎるおそれ(1任期では届かないので未計測)

### 画面(見た目・分かりやすさ)

- **良い**: カードの形・役割の札・調子の〇・★の列が全画面でそろった。フロート(カード・選手・相手・トーナメント・視察レポート)で、縦スクロールが減った
- **課題**:
  - SQUAD の盤面で、センターバックとキーパーの札が少し重なる(★の2段を出すとき)
  - 窓(フロート)が5種類に増え、閉じ方は同じだが見た目(地の色)が少しずつ違う(暗い地 / 明るい地)
  - 視察レポート・秘書の言葉は、秘書ごとの口調(元気・クール・おっとり)を使っていない

### 本家らしさ

- **良い**: 成長グラフ(対角・限界突破・黄金期)、KP のランク B〜G、クラブオファー、Div 制、トーナメント表が入り、本家の「育てて勝つ・上を目指す」骨格がそろってきた
- **課題**: 任期と周の切れ目(§21.2 の 1)。本家の1任期の区切りとリーグの周がどう重なっていたかを確かめたい

## 21.4 面白くできそうな要素 / できなそうな要素

### できそう(手間が小〜中)

| 案 | 中身 | 手間 |
|---|---|---|
| チームのタグ | 黄金期・連敗中のスランプ・連勝中の勢いなど。HOME とクラブ新聞に出し、調子の上がり下がりに効く(積み残し) | 中 |
| 準備のおまかせ | 「前回と同じ」「秘書におまかせ」で、1試合の操作を短くする | 小 |
| ライバルクラブ | 同じ Div で何度も当たるクラブを「ライバル」として新聞・視察で取り上げる。勝つとファンが増える | 小〜中 |
| 昇格の演出 | 昇格・降格・Div の優勝を、優勝の撮影のような場面にする | 小 |
| 秘書の口調で視察レポート | 秘書ごとの言い回しの型を足す | 小 |
| ハーフタイムの指示の効きの調整 | 矢印の3段階が出るように(積み残し) | 小 |
| 称号で成長グラフの伸びしろ | 積み残し | 小 |

### できるが大きい(設計から)

| 案 | 中身 |
|---|---|
| 任期をまたぐ Premier への道 | 2任期目以降のオファーで、前の任期の Div を引き継ぐか、昇格した Div のクラブが届きやすくする |
| 移籍・スカウト | 相手クラブの選手を獲る。カードの払い出しとの関係を決める必要がある |
| 他クラブの育成 | 相手も任期の中で育つ(今は段で固定) |

### できなそう / 入れないほうがよい

- **対人戦・オンライン**: 前提(CPU戦のみ)から外れる
- **相手の調子(やる気)の再現**: 視察で見せる情報が増えすぎ、運の要素が強くなる。今のまま「相手は常に普通」がよい
- **試合中の実況を音声で**: 端末の差が大きく、品質を保てない

## 21.5 オーナーに伺うこと(1つずつ)

1. **任期の最後の周**(§21.2 の 1)→ **決定(2026-11-21)**: 本家の日程の考え方を応用。出ないカップの枠は休んで節を進められ(任期は減らない)、リーグは飛ばせない。100試合で途中のリーグ・カップは打ち切り(→docs/22)。§21.2 の 2(決着しない指令)もここで直した。元の選択肢:
   - (a) 任期を 86試合(2周ちょうど)にする
   - (b) 任期を 129試合(3周)にする
   - (c) 100試合のまま、最後の周はリーグを除いてカップだけにする
   - (d) 本家どおり(本家の区切りを教えてもらう)
2. **レアKP の条件**(§21.2 の 3): ★5 かつ G のまま、ミーティングの導線を良くするか / 条件を「★5 かつ S 以上」に下げるか
3. **覚醒工場の条件**(§21.2 の 4): 8人 → 12人に上げてよいか
4. **相手のレアKP**(§21.2 の 5): 「相手も KP がランク G のときだけ」に合わせてよいか
5. **準備のおまかせ**(§21.3): 入れるならどの形か(前回と同じ / 秘書におまかせ / 視察を飛ばす)
