# 14. ブラッシュアップ会議(第2回・2026-11-19)

レアKP・任命・相手監督・暗い地・選手の動きを入れたあとの見直し。4つの観点(ブランドとビジュアル / 情報の配置 / 操作感と不自然さ / 本家らしさ)の担当が、
幅390の画面19枚とコードを読んで意見を出した。

## 14.1 オーナーの要望

- トップページなどに、ゲームの**かっこいいロゴ**がない(本家は伝統的に**ボールを描いたスタイリッシュなロゴ**)
- HOME の**秘書やスポンサーが次の試合(マッチアップ)とかぶって**、マッチアップの枠が圧迫されている。**直近の試合ではなく Weekly News のワンライナー**でよい。開いたらゴシップで参照できる
- 全体のイメージ・デザインを**本製品レベルにクール**に
- **不自然なデザインや操作感をつぶしたい**

## 14.2 総評

- 場面の流れと試合の画面は筐体に近い。足りないのは「**カードの絵が場面の主役として出る瞬間**」(試合前・ゴール・MVP・優勝)と、**ロゴ**
- HOME は「毎回同じ形で出る情報」(秘書の定型の一言・スポンサー)が主役を押し下げている。**変化・判断・期限があるときだけ前に出す**
- 暗い地にそろえた結果、**白を前提にした部品が残っている**(試合の盤面の札の文字が白地に白でほぼ読めない、など)
- 操作で損をする所がある(盤面のカードが指ブレで動いて試合に効く、練習が1回押すと即決まる、残りのコミュニケーションが確認なしで消える)
- 縦に余った場面(タイトル・対戦カード・結果・優勝)の**下の空き**が共通の弱点

## 14.3 進め方(4段)

### 第1弾 不具合と操作の誤り(すぐ直す)
| | 直すこと | 重要度 |
|---|---|---|
| 1 | 試合の盤面と控えの札の文字が、暗いテーマで白地に白(`.th-wr .cd` が `--t-ink` を使う)→ 札の文字は固定の濃い色 | 高 |
| 2 | 盤面のカードが7px の指ブレでドラッグになり、34px 跳ねて位置が変わる → しきい値を12px、持ち上げは動いた量に合わせて、元から10px 以内なら戻して送らない | 高 |
| 3 | 練習を押すと即決まる(強さを選ぶ前に押すと「普通」で決まる)→ 選んでから「この練習で決定」の2段 | 高 |
| 4 | コミュニケーションが残っているのに「試合へ」で確認なく消える → 2度押しで確認 | 中 |
| 5 | カード排出: なぞった後の印が残り、次の正しいタップが1回捨てられる → 押すたびに印を消す | 中 |
| 6 | ハーフタイムの指示に残り時間が出ない → 残り秒のバー | 中 |
| 7 | KEEPER が「点けっぱなし」なのに SHOOT と見た目が同じ / 十字の中央(プレス)が普段から赤で点灯と区別できない → 点灯は全ボタン共通の「白い縁+点」 | 中 |
| 8 | TOUCH の表示が最下部の暗い赤で小さい → 白か金・14px 以上・点滅。ロック中は薄く | 中 |
| 9 | 対戦カードが4.2秒で勝手に進む → TOUCH だけで進む | 低 |
| 10 | 新聞の見出しで長音が1字だけ次の行に落ちる → 行頭の禁則 | 低 |

### 第2弾 HOME の再構成と Weekly News(オーナーの要望)
```
┌ ヘッダ: エンブレム クラブ名  チーム力 | 試合 | 資金 | ファン   (監督・格・ランクは CLUB へ。1行)
├ ■ 次の試合(主役。1画面目の半分以上)
│   大会・第N試合  煽り文
│   [自]  VS  [相手]  相手名 ★★★ ・ KP・陣形
│   直近 [L][W][W][W][D]   ← 5つの印。押すとその試合の新聞
│   ［ 準備をはじめる ］ 全幅の主ボタン
├ 📰 WEEKLY NEWS │【速報】○○が負傷 全治は未定か…  +3 ›   ← 固定の1行。未読は赤い点
├ (何かあるときだけ) 要対応の帯: 秘書の相談 / スタジアム改修の打診 / スポンサーの更新・ミッション達成
└
```
- Weekly News の1行は、最新号のゴシップから優先度の高い1件(速報 > 独占 > 話題 > スポンサー > クラブ > うわさ)。押すと最新号の新聞をゴシップ欄で開き、紙面の上で「‹前の号 / 次の号›」をめくれる
- 秘書の定型の一言は HOME から外す(相談・打診・警告のときだけ帯で出す)。スポンサーは普段 CLUB に置き、達成・更新のときだけ帯かニュースで
- 「この試合のカード」のサムネは HOME から外す(結果の場面と新聞で見せる)
- あわせて: SEASON の「S の大会への道」と大会表の重複をまとめる、順位表は自チームの前後に畳む、SQUAD の凡例とハーフタイムを畳む、CARDS の絞り込みを1段に、CLUB の施設をスタジアムの上へ

### 第3弾 ロゴとデザイン言語
- **ロゴ「スラッシュ・ボール」**(独自の意匠。本家のロゴは写さず、ボールのモチーフの方向性だけ):
  円の中の五角形と放射線の抽象的なボールに、斜めの切れ込み2本。「WCC + ボール + F」(いまの `_` をボールに)、ボールから金の弧(軌跡)を文字の下へ。
  Oswald 700 斜体 −8°。白の文字・黒い落ち影・赤の切れ込み・金の弧。ボールが弧の上を転がって入り(約0.6秒)、文字に光沢が走る
- 置き場所: タイトル(大きく)・HOME のヘッダの右上(マークだけ小さく)・試合の広告看板・結果の背後の透かし・カードの裏面・PWA のアイコン
- **デザイン言語の統一**: 斜めは −8° に1本化 / 角丸は 2px 以下(丸は SHOOT・KEEPER・エンブレムだけ)/ 余白は 8 の倍数 /
  光沢とグラデは報酬(カード・トロフィー・レア・ロゴ)だけ、操作の部品は平面 / 入りは 200ms の斜めのスライド
- 試合の操作の台: ベージュの立体ボタンをやめ、暗い平面の平行四辺形に(選んだものだけ赤)
- 対戦カード・結果・優勝の下の空きを、選手の絵で埋める(対戦カードは KP の絵、結果は MVP の絵を大きく、優勝は11人の絵の集合写真)
- CLUB のスタジアムの絵: 夜空・照明塔の光・斜めの段のスタンド(Lv で段が増える)

### 第4弾 高揚の瞬間(本家の仕様を伺ってから)
試合前のスタメン発表、ゴールの得点者のアップ、MVP の大写し、優勝の撮影の構図。**どれも本家でどうだったかをオーナーに1つずつ確かめてから**作る。

## 14.7 第2弾でやったこと(2026-11-19)

- **HOME**: 上から「ヘッダ(1行)→ 次の試合の札 → WEEKLY NEWS の1行 → 答えが要るときだけの帯」
  - 次の試合の札に、直近5試合の W/D/L の印(押すとその試合の新聞。いちばん新しいものに金の縁)と、全幅の「準備をはじめる」
  - **WEEKLY NEWS**: 最新号のゴシップから大事な順(速報 > 独占 > 話題 > 分析 > スポンサー > クラブ > うわさ)に1件を固定の1行で。
    未読は赤い点(最後に見た号を `S.paperSeen` に「任期:試合」で残す)。押すと最新号をゴシップ欄で開き、紙面の上の「‹前の号 / 次の号›」でめくれる
  - 秘書は、会話・ケガ・兆し・決勝・保存の異常・最初のあいさつのときだけ(`secNeeded`)。定型の一言は出さない
  - スポンサーの小札・直近の試合の一覧・「この試合のカード」は HOME から外した(スポンサーは CLUB、試合は新聞)。スポンサーの更新とスタジアム改修の打診は帯で残す
  - ヘッダの2行目は「第N任期・監督 名前」だけ。格・監督ランク・称号は CLUB の「この任期」へ
- **SEASON**: 「S の大会への道」を大会表にまとめた(条件は名前の下の小さな行、出場できるものは緑)。順位表は首位・自分の前後・最下位に畳み、「全部見る」で広げる
- **SQUAD**: 連携の凡例とハーフタイムの指示を、押して開く1行に(`details`)
- **CARDS**: 絞り込みと並べ替えを1段に。並べ替えは押すたびに レア → No. → 合計
- **CLUB**: 施設(お金を使う唯一の操作)をスタジアムの絵の上へ
