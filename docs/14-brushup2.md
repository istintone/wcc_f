レアKP・任命・相手監督・暗い地・選手の動きを入れたあとの見直し。4つの観点(ブランドとビジュアル / 情報の配置 / 操作感と不自然さ / 本家らしさ)の担当が、

## 14.1 オーナーの要望

- 全体のイメージ・デザインを**本製品レベルにクール**に
- **不自然なデザインや操作感をつぶしたい**

## 14.2 総評

- 場面の流れと試合の画面は筐体に近い。足りないのは「**カードの絵が場面の主役として出る瞬間**」(試合前・ゴール・MVP・優勝)と、**ロゴ**
- HOME は「毎回同じ形で出る情報」(秘書の定型の一言・スポンサー)が主役を押し下げている。**変化・判断・期限があるときだけ前に出す**
- 暗い地にそろえた結果、**白を前提にした部品が残っている**(試合の盤面の札の文字が白地に白でほぼ読めない、など)
- 操作で損をする所がある(盤面のカードが指ブレで動いて試合に効く、練習が1回押すと即決まる、残りのコミュニケーションが確認なしで消える)
- 縦に余った場面(タイトル・対戦カード・結果・優勝)の**下の空き**が共通の弱点

  光沢とグラデは報酬(カード・トロフィー・レア・ロゴ)だけ、操作の部品は平面 / 入りは 200ms の斜めのスライド
- 試合の操作の台: ベージュの立体ボタンをやめ、暗い平面の平行四辺形に(選んだものだけ赤)

## 14.12 SQUAD: 引っ張って入れ替え・OVR とプルダウン・最適配置(2026-11-19)

オーナーの指摘: 入れ替えの操作が試合中の「カードを引っ張る」形と違って違和感がある。チーム力を OVR として SQUAD の上部に。
フォーメーションの4つのボタンは右寄せのプルダウンにして、左端に OVR。1人ずつの入れ替えは操作性が悪いので、最大 OVR になる自動配置が欲しい。

- **入れ替えは引っ張る操作に統一**: ピッチのカードを別の選手(ピッチでも控えでも)に重ねて離すと入れ替え。控えのカードも引っ張ってピッチの選手に重ねられる(重なる相手に金の縁)。
  空いた所で離せば、いままでどおり位置の移動。**タップは選ぶだけ**(選手の詳細と KP)。2回タップでの入れ替えはやめた
- **上部**: 左に **OVR**(いままでのチーム力。HOME のヘッダの表記も OVR に)、右にフォーメーションのプルダウンと「最適配置」
- **最適配置**(`pool.js` の `autoSquad` / `slotValue`): いまの陣形の枠ごとに、その役割で重く見る能力(`ROLE_W`)× 適性 の値を出し、
  いちばん値の高い組から埋める。登録16人が対象で、ケガの選手はほとんど選ばない。並びの位置は陣形の既定に戻す。KP は先発に残れば引き継ぐ
- 確かめ: clubtest(崩した並びから強さが戻り、GK が枠の先頭)、SQUAD のブラウザのテスト(控えを引っ張って入れ替え・KP を控えに重ねると入った人が引き継ぐ)

## 14.65 BGM をベースの効いたハイテンポでスポーティーに(2026-11-22)

- テンポ: クラブの曲 128 → **140 BPM**、試合の曲 150 → **172 BPM**
- ベース: 8分ごとにオクターブで弾むライン(`bassPat`。クラブ = 根音とオクターブを交互、試合 = 根音を刻んで5度・短7度へ)。のこぎり波を少し明るく(ローパス 750Hz)
- 重低音: ベースの1オクターブ下にサイン波を重ねる(`sub`。`bgmSub`)
- キック: 160Hz から 36Hz まで落とす太い音に、頭に小さなクリック。試合の曲は手数を増やす(8分の 0・2・3・4・6)
- スネアに手拍子(クラップ。少しずつずらした3つ)を重ねて、スタジアムの手拍子らしく
- ギターのパワーコードとリードのリフはそのまま

## 14.66 BGM のメロディを増やす(2026-11-22)

- 曲の形: **4小節ずつ バースとサビを交互**(8小節で1周)。8小節の終わりにドラムのフィル(スネアの連打)
  - バース: ギターのリフ(2小節に1回)+ **アルペジオ**(三角波の粒。和音の音を上下に。クラブは8分、試合は16分で細かく)
  - サビ: **シンセのリードのメロディ**(のこぎり波と矩形波を重ね、ビブラート。`bgmLead`)+ 2拍ごとの和音の刻み
- 和音の進行: クラブ = ホ短調 Em → C → D → B、試合 = ニ短調 Dm → B♭ → C → A(最後の小節は長調にして、頭へ戻る勢いを出す)
- メロディは `BGM_TRACKS` の `mel`([MIDI の音, 8分の長さ] を4小節ぶん)。書き換えれば曲を変えられる
- 音の既定はオフ(2026-11-22。外で遊ぶため): 効果音・BGM とも、MANAGER の設定で「あり」にしたときだけ鳴る(選んだ状態は端末に残る)

- **成否(確実な正解をなくす)**: ★突破の成功率 = 合う言い方 70% / 合わない 30% + 信頼度の段(+0 / +5 / +10 / +15%)+ 監督と選手の動物の相性(悪い −5% / ふつう 0 / 良い +8%)+ 名将、× 反抗期・成長期、10〜95% に収める(`TUNING.grow.sp` の `qOk` / `qNg` / `qTrust` / `qAni` / `qMin` / `qMax`)。ラウンジは2人の信頼度の段(平均)1つごとに、失敗の 4% が成功に回る(`TUNING.grow.link.trustK`)
- 実測(clubtest、信頼なし): 合う言い方 70.5% / 合わない 28.0%、信頼が深いと合わない言い方でも 39.5%

## 14.109 信頼度は選手の言葉から察する(2026-11-23)

- チャットの「信頼度: まだ遠い」の注記をやめる。代わりに、選手の最初の言葉の後ろに**監督との距離感の一言**を添える(`grow.js` の `TRUST_SAY` / `trustSay`。性格3種 × 信頼の4段 × 2通り)。例: 負けず嫌い「……まだあんたを認めたわけじゃない。」→「最後まであんたについていく。」

## 14.110 戦力の表記を OVR に統一(2026-11-23)

## 14.111 OVR の窓をグラフ1つに(2026-11-23)

- オーナーの指摘: 中段の数値の表はグラフに収める。OVR はグラフの右下、内訳(任期の始め + 育成)はその下にグラフの色で。KP の表示・「向かい合う〜」の説明・成長グラフはこの窓から消す

- 任期の始めの6軸を覚えるため `S.ts.ax0` を足した(OVR の `pow0` と同じときに記録。無い古いセーブは比で戻す)

## 14.113 LEGENDS だけの特別な演出(2026-11-23、オーナーと決めた案)

- ① **縁を走る光**(どこでも): 金の二重線の上を、光の粒が 7秒おきに一周する(約3秒で一周して消える)。一覧で何枚も並んでも同時に光らないよう、カードごとに時間をずらす(`cardHtml` の `k-run`、`--rd`)

## 14.114 メタリックの輝き・大きなカードをぐりぐり動かし、はじくと裏返る(2026-11-23)

- オーナーの指摘: §14.113 の「縁を走る光」と「後光」は微妙 → 外す。代わりに、オーナーが見せたサンプル(Claude.ai で作った画面のトップのカード)の**メタリックな輝き**を
- 輝き(`k-holo`): 虹色の帯(白・水色・赤・金)を color-dodge で重ねる。WORLD CLASS は虹、LEGENDS は金を強めたメタリック。一覧ではゆっくり流れる(カードごとに時間をずらす)
- **カードをタップすると大きなカード**(`k3dHtml` / `k3dBind`): 表はカード、裏は今までの情報(能力・適性・スキル・KP・持っている枚数)
  - 指でぐりぐりすると立体的に傾き(縦 ±28°・横 ±40°)、輝きと白い光沢(`k-glare`。どのレアリティにも)が指の位置に付いてくる。離すとふわっと戻る
  - **横にピン！とはじく**(速さ 0.6px/ms 以上・30px 以上)と、くるっと裏返る。もう一度はじくと表へ
  - ‹ › の前後送り・×・「SQUAD と交代」はそのまま。前後送りすると表に戻る
- 端末の「視差効果を減らす」設定では、一覧の輝きは流さない
- **2026-11-23 直し**(オーナー: ぐりぐりできない): 選手の画像を押してずらすと、ブラウザが画像のドラッグを始めて操作が打ち切られていた → 画像のドラッグ・長押しのメニュー・文字の選択を止めた。マウスは押さずに上を動かすだけでも傾く(サンプルと同じ)

## 14.115 大きなカードの裏面を、カードの裏の形に(2026-11-23)

- オーナーの指摘: 裏面に表のデザイン(小さなカード)は要らない。カードの形に情報を整理して、実際のカードの裏に表記があるように
- 裏面(`kBackHtml`)は表と同じ形・大きさ(5:7)。紙の地にドットとクラブの色の斜めの帯、縁はレアリティと同じ(WORLD CLASS 紫・LEGENDS 金の二重線、SPECIAL は黒い紙)

  - 中: 左に適性マップ(ポジション名)、右に6能力のバーと数値・TOTAL
  - 下: スキル・KP(全体/個人・軸)・RARE KP(★5 まで ？？？)・キャプテンシーと★
  - いちばん下: レアリティ・カード番号・持っている枚数(重なり)

## 14.116 大きなカードは選手を中央にやや大きく(2026-11-23)

## 14.117 カードにシーズン・レアカードの刻印(2026-11-23)

- オーナーの依頼: カードの活躍した年が分かるよう、右上のカテゴリの後ろに **25-26**(「LEGENDS 25-26」)。データは 2025-26 シーズン終盤(→docs/06)。シーズンは `clubui.js` の `CARD_SEASON` 1か所で持つ(のちにシーズンを足すとき)。カードの裏面のいちばん下にも
