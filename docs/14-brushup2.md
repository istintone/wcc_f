レアKP・任命・相手監督・暗い地・選手の動きを入れたあとの見直し。4つの観点(ブランドとビジュアル / 情報の配置 / 操作感と不自然さ / 本家らしさ)の担当が、

## 14.1 オーナーの要望

- 全体のイメージ・デザインを**本製品レベルにクール**に
- **不自然なデザインや操作感をつぶしたい**

## 14.2 総評

- 場面の流れと試合の画面は筐体に近い。足りないのは「**カードの絵が場面の主役として出る瞬間**」(試合前・ゴール・MVP・優勝)と、**ロゴ**
- HOME は「毎回同じ形で出る情報」(秘書の定型の一言・スポンサー)が主役を押し下げている。**変化・判断・期限があるときだけ前に出す**
- 暗い地にそろえた結果、**白を前提にした部品が残っている**(試合の盤面の札の文字が白地に白でほぼ読めない、など)
- 操作で損をする所がある(盤面のカードが指ブレで動いて試合に効く、練習が1回押すと即決まる、残りのコミュニケーションが確認なしで消える)
- 縦に余った場面(タイトル・対戦カード・結果・優勝)の**下の空き**が共通の弱点

  光沢とグラデは報酬(カード・トロフィー・レア・ロゴ)だけ、操作の部品は平面 / 入りは 200ms の斜めのスライド
- 試合の操作の台: ベージュの立体ボタンをやめ、暗い平面の平行四辺形に(選んだものだけ赤)

## 14.12 SQUAD: 引っ張って入れ替え・OVR とプルダウン・最適配置(2026-11-19)

オーナーの指摘: 入れ替えの操作が試合中の「カードを引っ張る」形と違って違和感がある。チーム力を OVR として SQUAD の上部に。
フォーメーションの4つのボタンは右寄せのプルダウンにして、左端に OVR。1人ずつの入れ替えは操作性が悪いので、最大 OVR になる自動配置が欲しい。

- **入れ替えは引っ張る操作に統一**: ピッチのカードを別の選手(ピッチでも控えでも)に重ねて離すと入れ替え。控えのカードも引っ張ってピッチの選手に重ねられる(重なる相手に金の縁)。
  空いた所で離せば、いままでどおり位置の移動。**タップは選ぶだけ**(選手の詳細と KP)。2回タップでの入れ替えはやめた
- **上部**: 左に **OVR**(いままでのチーム力。HOME のヘッダの表記も OVR に)、右にフォーメーションのプルダウンと「最適配置」
- **最適配置**(`pool.js` の `autoSquad` / `slotValue`): いまの陣形の枠ごとに、その役割で重く見る能力(`ROLE_W`)× 適性 の値を出し、
  いちばん値の高い組から埋める。登録16人が対象で、ケガの選手はほとんど選ばない。並びの位置は陣形の既定に戻す。KP は先発に残れば引き継ぐ
- 確かめ: clubtest(崩した並びから強さが戻り、GK が枠の先頭)、SQUAD のブラウザのテスト(控えを引っ張って入れ替え・KP を控えに重ねると入った人が引き継ぐ)

## 14.65 BGM をベースの効いたハイテンポでスポーティーに(2026-11-22)

- テンポ: クラブの曲 128 → **140 BPM**、試合の曲 150 → **172 BPM**
- ベース: 8分ごとにオクターブで弾むライン(`bassPat`。クラブ = 根音とオクターブを交互、試合 = 根音を刻んで5度・短7度へ)。のこぎり波を少し明るく(ローパス 750Hz)
- 重低音: ベースの1オクターブ下にサイン波を重ねる(`sub`。`bgmSub`)
- キック: 160Hz から 36Hz まで落とす太い音に、頭に小さなクリック。試合の曲は手数を増やす(8分の 0・2・3・4・6)
- スネアに手拍子(クラップ。少しずつずらした3つ)を重ねて、スタジアムの手拍子らしく
- ギターのパワーコードとリードのリフはそのまま

## 14.66 BGM のメロディを増やす(2026-11-22)

- 曲の形: **4小節ずつ バースとサビを交互**(8小節で1周)。8小節の終わりにドラムのフィル(スネアの連打)
  - バース: ギターのリフ(2小節に1回)+ **アルペジオ**(三角波の粒。和音の音を上下に。クラブは8分、試合は16分で細かく)
  - サビ: **シンセのリードのメロディ**(のこぎり波と矩形波を重ね、ビブラート。`bgmLead`)+ 2拍ごとの和音の刻み
- 和音の進行: クラブ = ホ短調 Em → C → D → B、試合 = ニ短調 Dm → B♭ → C → A(最後の小節は長調にして、頭へ戻る勢いを出す)
- メロディは `BGM_TRACKS` の `mel`([MIDI の音, 8分の長さ] を4小節ぶん)。書き換えれば曲を変えられる
- 音の既定はオフ(2026-11-22。外で遊ぶため): 効果音・BGM とも、MANAGER の設定で「あり」にしたときだけ鳴る(選んだ状態は端末に残る)
