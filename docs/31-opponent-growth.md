# 31. 相手を強くする仕組み: 自分と同じ仕組みの結果を相手も持つ(2026-11-27 設計)

オーナーの相談: 任期の初めの −1.4 をやめた(docs/14 §14.208)ので、実在の16クラブ(段4・5)が前より弱く感じられる。相手を強くする仕組みのアイデアは？ **対称性を崩さない方法**がいい。→ 3案とも入れる(オーナー)。

## 31.1 原則

- 相手だけの上乗せ(見えない倍率・能力の底上げ)は作らない。**自分のチームにある仕組みの結果を、相手も持っている**
- 数の意味は両チームで同じ。自分の側の上限(★5・覚醒の最大 +3・調子5段・監督能力3つ・ランク マスター)を超えない
- 相手の状態はたね(任期・節・クラブ)から決まる。同じ試合なら毎回同じ(リプレイ・読み込みでずれない)
- 見えるものは視察(docs/18)で見せる。見せ方は自分の札と同じ(+n・光る★・調子のタグ)

## 31.2 案1: 相手も「育成済みのチーム」(選手の★・覚醒・KP の特殊能力)

- 相手の選手に、自分の選手と同じ育成の結果を持たせる
  - 個人能力の★(0〜5)。★1つごとに、その選手の得意な能力 +0.5(自分の個人練習の3択の正解と同じ能力。§14.201)
  - ★5 は覚醒: `awaken` と同じ割り振り(ポイント 1〜3 を1〜3つの能力に。§14.207)
  - KP の特殊能力の★。自分と同じく KP のランクの上限(`ssCap`)が掛かる。今の「相手は★の上限なし」をやめ、★で決める
- 量は**強さの段**と**任期の進み**(節)で決める。任期の後半ほど相手も育っている
  - 目安(先発11人の個人能力の★の平均。任期の初め → 終わり): 段1 0 → 1 / 段2 0.5 → 1.5 / 段3 1 → 2.5 / 段4 2 → 3.5 / 段5 3 → 4.5
  - 覚醒している人数(任期の初め → 終わり): 段3 0 → 1 / 段4 1 → 3 / 段5 2 → 5
  - KP の特殊能力の★: 段1〜2 ★1〜2 / 段3 ★3 / 段4 ★4 / 段5 ★5(今の「段5 は特殊能力 ★5 相当」と同じ)
- 作った相手クラブ(段1〜3)の能力のずれ(§14.208 で +1.4)は、案1で育つぶんを見て戻すか決める(測ってから)

## 31.3 案2: 調子と連携を、自分と同じ物差しで

- 調子: 相手の選手も5段の調子を持ち、同じ倍率(`TUNING.grow.mot.mul`)が掛かる。今は相手は全員 1.0(不調と好調の間)
  - 強いクラブほど良い調子が多い。目安(絶好調 / 好調 / 不調 / 絶不調): 段1 10 / 40 / 35 / 15% 〜 段5 30 / 50 / 15 / 5%
  - ケガ(調子0)は相手には出さない(自分の側のケガは試合をまたいで続くもので、相手は1試合ごとのため)
- 連携: 今も段ごとに線の数を持つ。段4・5は黄金線(3)が出やすいよう、線の段の決め方を少し上げる(上限は自分と同じ黄金線まで)

## 31.4 案3: 相手監督のチームスタイルとハーフタイムの指示

- チームスタイル(監督能力 `MAB`): 相手監督も3つをセットし、熟練度(I / II / III / マスター)を持つ。自分と同じ効き目(`TUNING.mab.rankK`)
  - 選び方: 相手監督の性格(`persOfClub`。docs/13)に合うもの。例: 攻撃的 → センター/サイドアタック強化・ラストスパート、堅実 → DFコーチング・デュエル強化・セービング強化
  - 熟練度: 段1〜2 I / 段3 II / 段4 III / 段5 マスター
- ハーフタイムの指示: 相手監督も後半の始めに1つ出す(自分と同じ `htPlan`。docs/26 の型と星の強さ)
  - 選び方: 前半の結果と性格で(負けていれば攻めの型、勝っていれば守りの型)。星は段で(段1〜2 ★1 / 段3〜4 ★2 / 段5 ★3)
  - 試合画面の実況で「相手監督『〜！』」と出す(自分の指示と同じ出し方)

## 31.5 見せ方(視察)

- 相手の札: 自分の SQUAD の札と同じく、調子のタグ(§14.200)・覚醒の★(§14.204)。カードの数字の下の伸び(+n)は出さない(札の数字は試合の値の合計)
- 視察の報告書に「相手監督のチームスタイル」の欄(3つの名前と熟練度)。秘書の親密度で見える数を増やす(docs/18 の所見と同じ)
- 説明の文は足さない(→ memory: 説明文は消していく)

## 31.6 釣り合いの目標(clubtest の6任期・監督まかせ)

- 監督まかせの勝率 45〜50%(いま 49.8%)
- タイトル(6任期)20〜25 前後(いま 33。−1.4 があった頃は 17)
- 段4(実在クラブ)との得失点差: 任期の初め −0.5〜−1.0、終わり 0 前後
- enginetest: 相手の監督能力・ハーフタイムの指示が入っても、既存の項目が崩れない

## 31.7 進め方

1. 案1(選手の★・覚醒・KP の★)→ 測る
2. 案2(調子・連携)→ 測る
3. 案3(チームスタイル・ハーフタイムの指示)→ 測る
4. 視察の見せ方
5. 段1〜3 の能力のずれ(+1.4)を戻すか決める

各段のあと、clubtest の数字をこの文書に書き足す。

## 31.8 実測

### 案1(2026-11-27。`club.js` の `oppGrowth`、数値は `TUNING.club.oppGrow`)

- 相手の育成(先発11人。任期の初め → 半ば → 終わり): 段1 ★0.3 → 0.7 → 1.1 / 段3 ★1.1 → 2.1 → 2.8(覚醒 0 → 1)/ 段4 ★2.4 → 3.1 → 3.8(覚醒 1 → 3)/ 段5 ★2.9 → 3.9 → 4.5(覚醒 2 → 5)
- 覚醒の割り振りは自分と同じ関数(`awakeSplit` / `awakePts`。重なりは 0 枚あつかい)。★1つの +0.5 は得意な能力へ(`bestStat`。自分の3択の正解と同じ)
- 作った相手クラブ(段1〜3)の能力のずれは、§14.208 の +1.4 から **+1.05** に下げた(`tierStat` −0.55 / +0.15 / +0.75)

| clubtest(6任期・監督まかせ) | 案1の前(+1.4) | 案1 + 1.4 | 案1 + 0.7 | **案1 + 1.05** |
|---|---|---|---|---|
| 勝率 | 49.8% | 42.3% | 50.7% | **47.8%** |
| タイトル | 33 | 15 | 30 | **30** |
| 段4 との得失点差(初め → 終わり) | — | — | — | **−0.66 → −0.01** |

- タイトルの数は1本の通しの試行では大きく揺れる(上の表で 15〜30)。案2・3 のあとでまとめて見る
- clubtest の「育てると強くなる」は、相手を任期の初めの育成済みの段4にそろえ、自分の調子と疲れも初めと同じにして比べる形に直した

### 案2(調子。`oppGrowth` の中、数値は `TUNING.club.oppGrow.mot`)

- 相手の選手は試合ごとに調子(絶不調〜絶好調)を持つ。倍率は自分と同じ(平均の倍率: 段1 0.99 / 段3 1.00 / 段5 1.02。これまでは全員 1.0)
- 連携は変えない: 段4・5 の実在クラブはもともと太線〜黄金線(段5 はほぼ黄金線)を持っていた
- clubtest: 勝率 51.8% / タイトル 27 / 段4 との得失点差 −0.84 → −0.20
