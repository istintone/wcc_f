# 23. タグ(チームと選手のバフ・デバフ)— 設計案(2026-11-22)

オーナーの依頼: 本家には明確に無かった仕様(裏のパラメータとして「黄金期到来」などがあった)。スマホ版は試合運びがカジュアルなぶん、**タグで深みを足す**。
タグはチームや選手に付く**バフ・デバフ**。基本は一定期間で消える一過性。育成で付いたものが任期の終わりまで続くものもある。
入手は**特定の条件**か**ランダムに起きる出来事**。

この文書は**案**。オーナーと決めたところから「決定」に書き換える。§23.7 の問いはすべて決定済み(2026-11-22)。一覧の数値は実装しながら `TUNING.tag` で合わせる。

## 23.1 タグの形

| 項目 | 中身 |
|---|---|
| 付く先 | **チーム** / **選手** |
| 種類 | チーム: **汎用**(出来事・経営・成績)/ **象徴**(二つ名。成長グラフから)。選手: **汎用**(調子・話題)/ **特性**(ポジション)/ **固有**(特別な能力値や選手だけ) |
| 向き | バフ(金の札)/ デバフ(青紫の札)。名前の色で一目で分かるように |
| 期限 | **N試合**(一過性。3・5・10 など)/ **条件が解けるまで**(連敗が止まるまで など)/ **任期の終わりまで**(それ以外すべて。任期の終わりで全部クリア)。特別なカードの固有だけは、カード自身の性質として毎任期初めから持つ |
| 強さ | 小・中・大・超(数値は `TUNING.tag` にまとめる。下の §23.5) |

- **同じタグがもう一度付いたら**、期限を延ばすだけ(重ねがけしない)
- **反対のタグは打ち消す**: 勢い ⇔ スランプ、ケガに強い ⇔ ケガがち、成長期 ⇔ 反抗期 など。新しく付いたほうが残る
- **数の上限**(画面と遊びが散らからないように):
  - チーム: 称号2(国1 + クラブ1)+ 汎用は3まで(4つ目が付くときは、残りの期限がいちばん短いものが押し出される)
  - 選手: 固有1 + 特性1 + 汎用は「任期まで続くもの」2 と「一過性」2 の別の枠(続くものが一過性に押し出されないように。2026-11-22 第3段で改め)
- **能力の上乗せの上限**: タグの能力アップは、1人の1つの軸につき合計 +3 まで(超のタグ〈MVP など〉だけは +5)。重ねて壊れないように

## 23.2 入手の仕組み

1. **条件で付く**(試合のあとに判定。`afterMatchGrowth` の流れ)
   - 成績: 3連勝で「勢い」、3連敗で「スランプ」、昇格・降格で「昇格の勢い / 降格の重圧」、大きな大会の決勝の MVP で「MVP」
   - 育成: 黄金期で「黄金期到来」、成長グラフの金色の組み合わせで**二つ名**(§23.3)
   - 出場: 同じポジションで好採点が続くと**特性**、20試合続けて先発で「鉄人」、ベンチが続くと「出番待ち」
   - 加入: 若い選手が加わると「ROOKIE」、熟練の選手が加わると「ベテラン」
2. **ランダムに起きる出来事**(秘書が知らせる。今の「監督室の短い会話」を広げる)
   - 試合のあとに一定の率(案 15%)で、**クラブの出来事**か**選手の出来事**が起きる。たいていは**2〜3択**で、選んだ答えでタグが付く・付かない
   - 例: 「地元の企業から合宿の申し出が」→ 受ける(合宿: 練習の経験アップ・疲労がたまりやすい 5試合)/ 断る(なし)
   - 例: 「○○ が移籍の噂に心を乱しているようです」→ 話を聞く(コミュニケーションを1回使う。成長期になることも)/ 放っておく(反抗期になることも)
   - 出来事はクラブ新聞のゴシップにもなる
3. **スポンサーの報酬**: 今の報酬(ケアの効果アップ・個人練習の経験アップ など)を**タグとして見せる**。施設の名前に寄せて「練習場施設充実」など(オーナーの案)。中身は今の効き目のまま
4. **監督の選択の結果**: 例: 疲れたまま出し続けると「ケガがち」、ケアを続けた選手は「ケガに強い」
5. **選手からの提案**(オーナーの案 2026-11-22): **信頼度が高い**選手の**個人練習**のとき、まれに選手のほうから「こう育ちたい」と**育成の方針が3択**で出る。
   選んだ方針の**特性タグ**(§23.4 の特性)が付く。監督が狙って選手の色(メタ)を足せる機会
   - 3択は、その選手のポジションと能力の伸びしろから選ぶ(例: CB なら「リベロ / スイーパー / ストッパー」)。すでに特性があれば、付け替えるかどうかの問いになる
   - 起きやすさの案: 信頼が「深い」以上で、個人練習1回につき 10%。1人につき任期に1回まで

## 23.3 チームの称号(オーナーの案 2026-11-22)

**チームを象徴する強い称号**。2種類あり、入手の道が別なので**両方持てる**(国の称号1 + クラブの称号1)。付いたら**任期の終わりまで続く**。
- **国の称号**: 本家のチームKP(国籍16選手 + 1軸が世界有数)をタグで再現する(「KP らしい振る舞い」として差別化しにくいため)。**同じ国籍の11人で実際に試合をする**ことで付く。成長グラフは問わない
- **クラブの称号**: 成長グラフの**金色が3つそろった(黄金期)**とき、その形で付く。育成の極致のご褒美

### 国の称号(本家のチームKP。参考: footballchamp.nobody.jp の一覧)

本家の条件は「同じ国籍の16選手 + 1軸が世界有数 + 特定選手の KP 指定を外す」。本作では(**決定 2026-11-22**):
- **先発の11人全員が同じ国籍で、実際に試合をする**。その試合のあとに**確率で**付く。**実際の試合で再現して初めて達成**
  - 付くときは秘書(または新聞)の言葉といっしょに: 「アズーロFC は代表選手をそろえて起用することで、無敵艦隊の再現といわれています」
  - **急造のチームでは取りにくくする**: 同じ国籍の11人で戦った試合を、この任期に重ねるほど確率が上がる。カードがそろった次の任期の最初の数試合では、まず付かない
  - 確率の案: その国の11人で戦った試合が**この任期に5試合目から**判定。1試合ごとに `3% ×(その試合数 − 4)`、上限 30%。勝った試合は ×1.5(ならすと 10〜15試合目あたりで付く)。数値は `TUNING.tag.nation`
  - **黄金期は条件にしない**(狙うのが難しいため。黄金期のご褒美はクラブの称号)
  - 届くのはカードが11枚以上ある国(スペイン・フランス・イタリア・イングランド・ドイツ・ブラジル・ポルトガル・アルゼンチン・オランダ)。少ない国は実名パックで足せば届く
- 効き目は**チーム全体**: その国の軸 中アップ + 国ごとの振る舞い1つ。**先発がその国の11人のときに効く**(代表をそろえて起用してこその称号)

## 23.3b コンビのタグ — 本家のコンビKP から(オーナーの案 2026-11-22)

**2〜5人の選手に同時に付く**タグ。本家のコンビKP(特定の選手 + 選手間の黄金連携 + 一定の信頼度 + 1軸が震撼〈金色〉)をもとにする。

- **条件**: ① メンバーの全員のあいだが**黄金線**でつながっている(3人なら3本とも)② 全員の信頼度が一定以上 ③ チームの成長グラフで、そのコンビの軸が**金色**(1つでよい)④ メンバーの**ポジションの組み合わせ**がコンビの型に合う
- **決め方(決定 2026-11-22: 両方)**:
  - **ポジションの型**: 黄金線でつながる組のポジションと金色の軸で決まる(下の表)。誰でも狙える
  - **特別なコンビ**: 決められた**カードの組**(本家のコンビKP の選手の組にあたるカード)は、より強い「特別なコンビ」になる。型のコンビより効き目が一段上(中 → 大)
    - 表はレアKP と同じやり方: `tools/combo_source.txt`(カードの No. | コンビ名 | 軸)→ 生成して `src/js/combos.js`。**キーはカードの No. だけ**で、名前は架空(実在の選手・クラブを指す名前は使わない)
    - 同じ組が型のコンビにも当てはまるときは、特別なコンビのほうが付く
- **効き目**: メンバーが**全員ピッチにいる**あいだ、メンバーの能力が上がり(中)、メンバー同士のパスやプレーが通りやすい。1人でも下がると止まる
- 1人が入れるコンビは1つ。チームに付くコンビは2つまで
- 付いたら任期の終わりまで(条件のうち、黄金線と金色の軸は消えないので)

| ゴール前の三銃士 | 3 | GK + CB 2人 | DEF | 失点しにくい、GK の能力 小アップ |
| 鉄のカーテン | 3 | DF 3人 | DEF | DEF 中アップ |
| 魔の三角地帯 | 3 | DF 3人 | STA | 奪いやすい、STA 小アップ |

## 23.5 効き目の語彙と強さ

実装を散らかさないよう、効き目は**決まった語彙**だけで書く(スタイルの `FX0` と同じ考え方)。

| 語彙 | 中身 | 効くところ |
|---|---|---|
| `stat` | 軸の上乗せ(役割・先発・途中出場・決勝などの条件つき) | 試合の前に選手の能力へ足す(`playerDef`) |
| `motUp` / `motDown` / `motLock` | 調子の上がりやすさ・下がりやすさ・下がらない | 試合のあとの調子(`afterMatchGrowth`) |
| `fat` | 疲労のたまりやすさ | 同上 |
| `inj` / `foul` | ケガ・退場の起きやすさ | 試合の中の判定 |
| `comm` | コミュニケーションの成功しやすさ | ミーティング・ラウンジ・ケア |
| `exp` | 経験の入り(個人・特殊・連携) | 練習・コミュニケーション |
| `kp` | KP の効き目 | 試合 |
| `money` | 入場料・賞金・年俸の上乗せ | 経営・任期の終わり |

強さ(案): **小** = 軸 +1 / 率 ×1.15 ・ **中** = +2 / ×1.3 ・ **大** = +3 / ×1.5 ・ **超** = +5 / ケガなし。能力は今の能力の値(1軸 10〜20 ほど)に対して足す。

## 23.11 話題のタグ(白): スター選手・問題児(2026-11-23、オーナーの案)

- **第3のタグ**: バフ(金)・デバフ(紫)と別に、**白い札**の「話題」のタグ(`kind:"fame"`)。能力には効かず、**クラブのお金**に効く。任期の終わりでクリア(他の選手のタグと同じ)。汎用の枠(2つ)には入らない
- **スター選手**(`star`): ジャイアントキリング(強さの段がリーグの格より2つ以上上の相手に勝つ)・大会の優勝・昇格を決めた試合で、**活躍した選手**(MVP → 得点 → 採点の順)に付く。人数は ジャイアントキリング 1人・優勝 2人・昇格 2人(重なったときは多い方)
- **問題児**(`trouble`): 同じ任期に**ゴシップが2回**付いた選手に付く(週刊誌の件・協賛の広告)
- **効き目(オーナーの決定)**:
  - スター1人ごとに **入場料とスポンサー収入 ×1.3**、問題児1人ごとに **スポンサー収入 ×0.85**。SQUAD にいる人数ぶん**掛け算**(スター 3人 ×2.2・5人 ×3.7・7人 ×6.3)
  - 賞金には掛けない(成績のごほうびは変えない)
  - **年俸の稼ぎには数えない**: 増えたぶんはクラブの資金(スタジアム・施設に使う)だけ。年俸・監督ランク・オファーの釣り合いは崩さない
- 見せ方: 盤面の札の右上に白い ★(スター)・✖(問題児)。選手の窓・COACHING NOTE では白い札。試合のあとの行に「〇〇 に「スター選手」…(優勝の立役者)」、入場料・スポンサー収入の行に「スター ×n」
- 数値は `TUNING.tag.fame`、仕組みは `grow.js` の `fameK` / `fameAfterMatch`、お金は `club.js` の `bizAfterMatch` / `spAfterMatch`
