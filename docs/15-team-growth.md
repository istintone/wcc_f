# 15. チームの成長グラフと KP のランク

オーナーの記憶と、オーナーが貼った本家の仕様(2026-11-20)から組み、要確認の6項目をオーナーに1つずつ確かめて決めた(2026-11-20)。
クラブオファー(§15.9)とチームのタグ(§15.3)だけは、後で別の仕様にする。実装は §15.10。

## 15.0 いまの作りとの違い

| | 前(docs/04 §4.5・docs/05 §5.6) | いま |
|---|---|---|
| グラフが表すもの | **戦力**: 盤面の11人の能力の平均 + 連携 + 練習の上乗せ(−2〜+3) | **チームの成長度**: 練習だけで伸び縮みする。選手の能力とは別 |
| KP のランク | C / B / A / S。戦力の値で決まる | **B / A / S / G**。成長度で決まる |
| 練習 | 上げる軸・下げる軸を持つ。全軸が少しずつ 0 へ戻る | 上げる軸と、その**対角**が下がる。戻らない |
| 最大まで伸びたとき | 何も起きない | MAX。さらに伸ばす練習で限界突破 → **金色**で固定。対の軸はそれ以上伸びない |
| レアKP | KP の特殊能力が ★5 | ★5 **かつ** 対応する成長度が金色 |

## 15.1 6つの軸と対角

| 対 | 軸 | 略称 |
|---|---|---|
| 1 | オフェンス ↔ ディフェンス | OFE ↔ DEF |
| 2 | スピード ↔ パワー | SPE ↔ POW |
| 3 | 支配 ↔ 奪取 | **TEC ↔ STA**(前の CON・INT から替えた) |

レーダーの六角形も、向かい合う軸が対角になる並び(上から時計回りに OFE・TEC・SPE・DEF・STA・POW)。

## 15.2 器(1つの対で1つの最大値)

- 軸は 0〜100。**対の2つの軸は合計が「器」を超えられない**。器は 130(戦術室の段ごとに +4)
- 片方を伸ばして合計が器を超えると、超えた分だけ対角が下がる(「OFE が伸びると DEF がやや下がる」)
- 片方が 100 に届くと **MAX**。まだ固定ではない(対角の練習をすれば下がる)
- **限界突破**(決定 2026-11-20): MAX の軸を伸ばす練習をすると、**およそ 30% で突破のイベント**が起き、その軸が**金色になって固定**される(練習で下がらない)。
  たいてい1〜2試合、長くても4試合ほどで起きる。金色になると、対角は「器 − 100」より上に伸びない
  → **1つの対で金色にできるのは1つだけ**。金色は最大3つ
- 施設: 戦術室の段で器が広がり(+4・+8・+12)、伸びやすさ(`facK`)も上がる。監督の称号の効き目は、まだ付けていない

## 15.3 金色の軸と黄金のグラフ

- 金色の軸: 文字を金色にして光らせる
- 金色が3つ(各対に1つずつ)そろうと、**グラフ全体が金色**になる(黄金期)
- 狙って育てれば、**60〜80試合**で黄金期になる伸び方に合わせる(1任期は100試合)

- **黄金期**(決定 2026-11-20): 3試合ほど続き、そのあいだ**選手全員が絶好調**になる。調子は落ちない。
  クラブ新聞のゴシップで「黄金期到来」として紹介する
- 後で別の仕様で考える: チームの好調・不調を表すタグ(黄金期・連敗中のスランプ=調子が落ちやすい など)

- 黄金期が終わっても、**金色の3軸と KP の G はそのまま残る**(決定 2026-11-20)。絶好調が続くことだけが終わる

## 15.4 練習

- 基本の練習: その軸だけが伸びる(対角は器を超えたときだけ下がる)
- 特殊練習: `tools/train_source.txt` の上げる軸・下げる軸のとおり。上げる軸が多い練習ほど1軸の伸びは小さい
- 強度(軽め・普通・ハード)が伸びに掛かる。全軸が 0 へ戻る仕組み(いまの `decay`)はやめる

## 15.5 KP のランク(B / A / S / G)

| ランク | 条件 | 効き目の倍率 |
|---|---|---|
| B | 初めの状態 | 0.8 |
| A | 必要な軸がすべて 40 以上 | 1.0 |
| S | 必要な軸がすべて 75 以上 | 1.25 |
| **G**(震撼) | 必要な軸がすべて金色。スタイル名が金色に光る | 1.5 |

- KP ごとに**必要な軸**を1つか2つ持つ。チーム系の強い KP に2つのものが多い(育てるのは大変、育てば強い)
- 必要な軸が2つあるときは、**低いほうの軸**でランクが決まる
- **ランクは成長グラフだけで決める**(決定 2026-11-20)。選手の能力・連携・KP の特殊能力の★はランクに効かない(試合の中では、これまでどおり効く)
- ランクの段 40・75 と、2軸のときは低いほうで決めることも決定(2026-11-20)

**2軸の KP**(決定 2026-11-20): チーム系で効き目の大きい次の8つ。
**対角の2軸は選ばない**(両方を金色にできないため)

| KP | 前の軸 | いま |
|---|---|---|
| T01 ショートパスワーク | TEC | TEC + OFE |
| T03 ショートカウンター | SPE | SPE + STA |
| T06 センターポスト | OFE | OFE + POW |
| T09 コンビネーションプレイ | TEC | TEC + SPE |
| T10 全員攻撃 | OFE | OFE + SPE |
| T11 プレッシング | STA | STA + SPE |
| T14 オーガナイズドディフェンス | DEF | DEF + STA |
| T15 マンツーマンディフェンス | DEF | DEF + POW |

ほかのチーム系9つと、個人系(K01〜K24)は1軸のまま。

## 15.6 レアKP

- 発動の条件: KP の特殊能力が ★5、**かつ**その KP に必要な軸がすべて金色(= ランク G)
- 特殊能力(ミーティング)・連携(ラウンジ)・個人能力・チーム練習は別々にも効くが、最後はこの組み合わせを作ることが目標になる

## 15.7 相手クラブと任期

- 相手クラブは育成しない代わりに、強さの段に応じた成長度を初めから持つ(段1〜5 で全軸 25・45・60・75・90。段5は既定の KP に必要な軸が金色)

- **任期ごとにリセット**(決定 2026-11-20)。1任期目は 0 から
- 2任期目からの初めの値は、次の「クラブオファー」で決まる(下の §15.9。別の仕様で作る)

## 15.8 画面

- SQUAD の下の「成長グラフ」(前の「戦力グラフ」): 六角形と、対ごとの値(OFE ⇄ DEF のように並べる)。MAX と GOLD の印
- 金色の軸は文字を金色で光らせ、3つそろうとグラフ全体を金色に塗る。黄金期のあいだは「あと N 試合」の帯
- いまの KP のランクと、次のランクまでに要るもの(「TEC・OFE が 75 で S」)。SQUAD で選んだ選手の板にも、その選手のスタイルのランク
- ランク G の札は金色で光る(試合の帯・選手の情報でも)
- 対戦カードのレーダーは**戦力**(選手の能力)のまま。成長グラフは監督室で見せる

## 15.9 クラブオファー(後で別の仕様にする。オーナーの話 2026-11-20 の記録)

- 任期が終わって次の任期を始めるとき、**3つのクラブからオファー**が届き、1つを選ぶ。届くクラブは、取った称号と年俸で決まる
- 弱小クラブからメガクラブまであり、**初めの成長グラフ・スタジアム・クラブ施設の育ち具合**が違う。スポンサーも、大きいクラブほど良いものになる
  → 2任期目からは、少し育った成長グラフから始まる
- **3択の時点で、各クラブのグラフと施設を見比べてから**、監督が次のキャリアを決められる
- いまの作り(自分で作ったクラブを任期をまたいで率いる。docs/10)との関係は、その仕様を作るときに決める

## 15.10 実装

| やること | 場所 |
|---|---|
| 数値(器・伸び・限界突破の率・黄金期の長さ) | `data.js` の `TUNING.grow.graph`。ランクの段と倍率は `TUNING.rank`、相手の段ごとの値は `TUNING.club.tierGraph` / `tierGold` |
| 対角・2軸の KP | `data.js` の `AXIS_PAIR` と `STYLES` の `axes`(`styleAxes`) |
| 伸び縮み・限界突破・黄金期 | `grow.js` の `graphAdd` / `graphBreak` / `graphCap`、`doTraining`、`afterMatchGrowth` の末尾 |
| ランク・レアKP | `engine.js` の `styleRank` / `styleAxisVal` / `rareOf` |
| 画面 | `clubui.js` の `growGraphHtml` / `myStyleRank`、`cardback.js` の `radarSvg`(`gold`)、クラブ新聞は `paper.js` |
| テスト | `clubtest.js` ⑥(器・金色・ランク・黄金期・狙って育てたときの試合数)、`enginetest.js` ⑩⑫ |
