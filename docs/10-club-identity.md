# 10. 監督とクラブ(監督ライセンス・監督契約・称号のセット・監督能力)— 設計の案(2026-11-19)

ユーザーの要望: 本家にならい、初回と100試合ごとの新しい任期に、クラブ名とエンブレムを決められるようにする。監督名はキャリアを引き継ぐデータなので、任期をまたいで変えられない。
称号には効き目を持たせ、任期の始めに「セット」して効果を得られるようにする。FOOTISTA の監督能力のように、試合に軽い効き目を足す仕組みも検討する。

## 10.1 調べたこと

- **WCCF 2012-13**(公式の遊び方。www.wccf.jp/wccf1213/howto/ の 01・02・05)
  - 初めて遊ぶときに「監督ライセンス」を発行し、**監督名と生年月日を登録する。生涯変更できない**
  - 「監督契約」で、クラブの**ホームタウン・チーム名・ユニフォーム(1st/2nd)・エンブレム**を選ぶ
  - リーグモードでは試合中にミッションが出て、達成すると次のプレイで**称号**が手に入る。「称号は監督能力に影響するものもある」
  - 新しくクラブを作ると 3rd Division から。「**監督能力の継承**」や監督オファーを受けると、上のディビジョンから始められる
  - (参考)ハーフタイムに、後半に向けたチームへの指示(選択肢でチームパラメータが変わる)があった版もある
- **FOOTISTA 2021**(4Gamer の稼働時の記事、個人ブログ)
  - 監督能力は**全14種類。1試合に3種類まで選べる**。試合で使うと**熟練度**が上がり、監督レベルが上がったときにランクが上がる(ランクの最上位は「マスター」)
  - 名前が分かったもの(10種): センターアタック強化 / サイドアタック強化 / カウンターアタック強化 / ポストプレイ強化 / デュエル強化 / クラブホットライン強化(スキルコンボ)/
    リーダーシップ / ハーフタイム(ケア)/ DFコーチング / スタミナコントロール。ユーザーの記憶では「士気向上」もある
  - **それぞれの効き目の数値は、資料が見つからなかった**(wcc_f で決める)
- **pftb のエンブレムメーカー**(c:\Claude\repository\pftb の src/js/emblem.js・emblem-art.js、docs/10 §3.54)
  - 絵の素材を持たず、**形5 × 地の柄9 × 紋章13 × 外装5 × 文字の並べ方3 × 色26** を組み合わせて SVG で描く。紋章は描いた意匠を輪郭追跡したパス
  - クラブの id と名前から自動で決まり、自分のクラブだけ組み替えられる。約62KB

## 10.2 案: 3つに分けて作る

### A. 監督ライセンスと監督契約(最初に作る)

- **監督ライセンス**(初回だけ): 監督名(と、任意で生年月日)。**あとから変えられない**。HOME の見出し・歴代・任期終了の画面に出す。
  生年月日を入れると、監督の動物(→docs/05 §5.5 の動物占い)が出て、相性の良い動物の選手が分かる……という遊びも足せる(任意)
- **監督契約**(初回と、100試合ごとの新しい任期の始め): 次を決めてからクラブハウスへ
  - クラブ名(全角10字まで)と略称(英字3字。スコアボード用)
  - ホームタウン(架空の街の一覧から選ぶ。対戦カードの帯や秘書の言葉に出る)
  - エンブレム(pftb のエンブレムメーカーを取り込む。形・地の柄・紋章・外装・文字・色を選ぶ。「おまかせ」でクラブ名から自動でも決まる)
  - ユニフォームの色(1st。盤面のカード・試合の映像の自チームの色になる)
  - 続いて、今と同じく秘書とスポンサーを選ぶ
- 前の任期のクラブの持ち物はすでに戻している(→docs/08 §8.12)ので、**クラブそのものが入れ替わる**形になる。最初の16枚のカードの所属(アズーロFC)はカードの印刷として残す
- 相手クラブのエンブレムも、同じメーカーで id と名前から自動で描くと見た目がそろう(実在クラブの色はそのまま)

### B. 称号のセット(監督能力の継承)

- 任期の始め(監督契約のあと)に、**これまでに獲った称号から1つを選んでセット**する(獲った称号が無ければ「なし」)
- 称号ごとに、その任期の**特殊練習の出方**と**成功しやすさ**が変わる。今は特殊練習がランダムに出るが、セットした称号の系統のものが出やすくなる
- 対応の案(称号は今の term.js の一覧):

  | 称号 | 出やすくなる特殊練習 | もう1つの効き目(小さく) |
  |---|---|---|
  | レジェンド | すべての系統が少しずつ | 特殊練習の枠 +1 |
  | 皇帝 | 戦力グラフ(全軸) | 大会の試合で士気(やる気)が下がりにくい |
  | 名将 | 戦術・KP のスタイル | ミーティングの★突破が成功しやすい |
  | 覚醒工場 | 個人能力 | 個人練習の経験 +10% |
  | 魔術師 | スタイル・KP | KP を替えたときのスタイルが早く効く |
  | 伝承者 | 連携 | ラウンジが大成功しやすい |
  | 刺客 | 守備・カウンター | 格上との試合で士気が上がる |
  | 知将 | セットプレイ | セットプレイの練習の伸び +20% |
  | 生え抜き | 個人能力(若手) | 21歳以下の伸びやすさ +10% |
  | 浮気者 | 疲労の回復 | 控えのやる気が下がりにくい |
  | 闘将 | 攻撃 | 勝ったときにやる気が上がりやすい |
  | 迷将・新米監督 | (なし) | (なし) |

  ※ 称号の名前と条件は今のもの。効き目の数値は、育成の釣り合い(集中した3人が★5)を崩さない範囲にする
- 本家にならい、セットした称号によっては**上のリーグの格から始められる**ようにもできる(今は任期終了の称号の grade で決めている。これと合わせる)

### C. 監督能力(FOOTISTA 風。試合に軽い効き目)

- **全14種類から、1試合に3つまでセット**する(準備の手順の最後、試合の前)。使うほど熟練度がたまり、ランク(I → II → III → マスター)が上がって効き目が少し増える
- 効き目は wcc_f の試合の仕組みに当てはめた**軽い上積み**(+2〜5% ほど)。分かった名前を使い、足りない分は wcc_f で決める:

  | 監督能力 | 効き目(wcc_f) |
  |---|---|
  | センターアタック強化 | 中央のレーンの攻めの判定 + |
  | サイドアタック強化 | サイドのレーンの攻めの判定 + |
  | カウンターアタック強化 | 奪ってから数手の速い攻め + |
  | ポストプレイ強化 | 前線の選手が受ける・競る判定 + |
  | デュエル強化 | 1対1の競り合い + |
  | クラブホットライン強化 | 連携の線がある2人のパス + |
  | リーダーシップ | KP のスタイルの効き目 + |
  | ハーフタイムケア | ハーフタイムにスタミナが少し戻る |
  | DFコーチング | 守備の判定 + |
  | スタミナコントロール | スタミナの減り − |
  | 士気向上 | 試合の初めのやる気(調子)の倍率 + |
  | セットプレイ強化(wcc_f) | FK・CK・PK + |
  | セービング強化(wcc_f) | GK のセーブ + |
  | ラストスパート(wcc_f) | 75分以降の攻め + |

- 本家ではリアルタイムの対人戦で効いていたが、wcc_f は CPU 戦なので、**戦術ボタンの代わりにはならない程度**にとどめる(enginetest で、どの組み合わせでも勝率の上積みが小さいことを確かめる)

## 10.5 A を作った(2026-11-19)

- **監督ライセンス**(`club.js` の `registerManager`、画面は `clubui.js` の `licenseHtml`): 初回の HOME で監督名(必須・12字まで)と生年月日(任意)を登録する。
  **登録したら変えられない**。生年月日を入れると監督の動物が出る(HOME の見出しに監督名と動物)
- **監督契約**(`signClub`、画面は `contractHtml`): 初回と新しい任期の始めに、クラブ名(10字まで)・略称(英字3字。空ならクラブ名から作る)・
  ホームタウン(架空の12の街)・クラブの色・エンブレムを決める。決めたクラブ名・略称・色で試合に出る(`playerDef`)。HOME・対戦カード・タイトルの画面もこのクラブ
- **エンブレムメーカー**: pftb の `emblem.js` / `emblem-art.js` を取り込んだ(形・地の柄・紋章・外装・文字の並べ方・柄の色を選ぶ。「おまかせ」でクラブ名から自動)。
  選んだクラブの色はエンブレムの地の色にも使う(名前の色の言葉より優先)。**相手クラブのエンブレムも同じメーカーで、id・名前・クラブの色から自動で描く**
- 決める順: 監督ライセンス(初回だけ)→ 監督契約 → 秘書 → スポンサー
- 古いセーブ: 監督ライセンスは次に開いたときに登録する。途中の任期のクラブは「アズーロFC」のまま(`defaultClub`)
- 最初の16枚のカードの所属(アズーロFC)は、カードの印刷として残す

## 10.6 B を作った(2026-11-19)

- 任期の始め(監督契約のあと、秘書の前)に、**獲った称号から1つをセット**する(獲った称号が無ければ出ない。「セットしない」も選べる)。HOME の見出しにセット中の称号
- **特殊練習の出方**: セットした称号の系統に合う特殊練習は4倍選ばれやすい(`TUNING.tset.favorW`、`term.js` の `trainWeight`)。
  例: 覚醒工場をセットすると、出る特殊練習のうち個人能力のものが 55% → 82%(clubtest)
- **小さな効き目**(`TUNING.tset`、`term.js` の `TITLE_FX`): §10.2 B の表のとおり。ただし浮気者は「疲労の回復」の特殊練習が無いので**スピードの特殊練習**にした
- 新しい任期では選び直す(`S.tsetChosen`)

## 10.7 C を作った(2026-11-19)

- **監督能力は14種類**(`data.js` の `MAB`)。FOOTISTA 2021 で名前が分かった10種と士気向上に、wcc_f で3種(セットプレイ強化・セービング強化・ラストスパート)を足した
- 準備の画面の下で、**1試合に3つまで**セットする(次の試合以降もそのまま)。セットして試合をすると熟練度 +1。
  **10試合で II、30試合で III、60試合でマスター**(効き目 ×1 / ×1.25 / ×1.5 / ×2)。熟練度は監督のデータなので任期をまたいで残る
- 効き目は試合の倍率への軽い上積み(`engine.js` の `refreshFx`。リーダーシップは KP のスタイルの効き、カウンターは速い攻め、ハーフタイムケアはハーフタイムの回復)
- **強さの実測**(`TUNING.mab.base` を2回下げて合わせた。最初の値はマスター3つで得失点差 +0.92 と強すぎた): マスターで1つだけ +0.01〜+0.08、上位3つで +0.15(1000試合)。
  全員・グループの力に掛かるもの(センター・サイド・DF・士気・ラストスパート)は、ほんの少しでも勝敗に大きく響くので小さくしてある。enginetest の ⑩ で「3つ・マスターでも +0.35 未満」を確かめる

## 10.8 ハーフタイムの指示(2026-11-19)

本家(→ユーザー提供の情報): チームを作るときにハーフタイム作戦指示を登録し、ハーフタイムに3択から1つを選ぶか、指示せずに終える(4択)。
新しい練習メニューを得ると、選べる指示が増える。指示ごとにチームのパラメータが上下し、**上下する軸は対応する練習と同じ**
(1VS1 = オフェンス・奪取↑ スピード↓ など)。wcc_f の決定: チーム作成時ではなく、**特殊練習を繰り返すと覚え、編成(SQUAD)で登録する**。

- 指示は**特殊練習1つにつき1つ**(48種)。名前は練習から付けた(`data.js` の `HT_PHRASE`。例: 4VS4パスゲーム =「パスワークで崩せ」、非公開練習 =「相手の裏をかけ」)。
  初めから使えるのは3つ(`HT_BASIC`。上がる軸だけ、効きは半分)
- **同じ特殊練習を2回すると覚える**(`TUNING.ht.unlock`)。監督の覚えた作戦なので任期をまたいで残る(`S.ht`)
- SQUAD で**3つまで登録**。ハーフタイムの字幕に登録した3つと「**このまま維持しろ(2026-11-22 に廃止。時間切れで同じ意味。→docs/14 §14.69)**」(パラメータを変えない。ユーザーの指摘で「指示なし」から改めた)のボタンが出て、8秒で維持のまま後半へ
- 効き目(後半のあいだ。`engine.js` の `refreshFx`): 上がる軸は強く、下がる軸は 0.6倍。オフェンス = 前線の力 / ディフェンス = DF の力 / 支配 = 受ける力 /
  奪取 = 追う・防ぐ力 / スピード = スタミナの減り / パワー = 空中戦。戦力グラフにも足す(KP のスタイルのランクに効く)
- **実測**(51種、各400試合): 得失点差 −0.06〜+0.09、平均 +0.03。すべての軸が上がる指示がいちばん効く(本家の「最初の指示はすべて上がる」とも合う)。
  enginetest の ⑪ で ±0.25 以内を確かめる
- ロッカールームで選手が訴えてくる「ハーフタイムイベント」は入れていない


## 10.9 【仮】選手の絵(2026-11-19)

見た目を確かめるための**一時的な**調整。実名ベースの選手の絵ができたら差し替える。

- pftb の汎用選手の絵(`../pftb/src/assets/players/any-{gk,out}-<id>_{play,stand}.webp`)を幅150に縮めて `src/js/art-players.js` に埋め込む。作り直しは `python tools/gen_player_art.py`(生成物。手で編集しない)
- カードには動きのある絵(play)を使う。どの絵になるかはカードの id から決まる(`clubui.js` の `artKeyOf` / `artSrc`)
- 試合のモニターでも同じ play の絵を使い、**相手チームは左右反転**して描く。足元にチームの色の輪と背番号の札(`render.js` の `drawMan`)
- 汎用の play の絵にはボールが描かれているものがある。試合中のボールと紛らわしいので、本番の絵では描かない
- index.html が約 0.8MB 太る
