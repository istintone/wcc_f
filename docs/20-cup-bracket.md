# 20. カップ戦のトーナメント

オーナーの決定(2026-11-21): 組み合わせが決まった時点で全部見せる(WCCF の仕様に合わせる)。

## 20.1 決まり

- **抽選のタイミング**: その大会の1試合目が次の試合になった時点(出場条件を満たしていれば)。このとき山を全部組む
- **顔ぶれ**: 世界のクラブから、大会ごとの強さの段(`COMPS.tiers`)の候補を弱い順に並べて選ぶ
- **勝ち抜き戦だけの大会**: 2^ラウンド数 のクラブ(3ラウンド = 8、1回戦2試合制 + 決勝 = 4、決勝だけ = 2)。自分の山は弱い側、反対の山は強い側に置くので、勝ち進むほど強い相手になる
- **グループ戦のある大会**: 自分のグループ(4クラブ)と、もう1つのグループ(4クラブ)。W4 = 両グループの1位で決勝、ICC = 1位と相手グループの2位で準決勝 → 決勝
- **ほかの試合**: 自分の試合が終わったときに、同じラウンドのほかの試合を計算で決める(`simCpu`。2試合制は合計、引き分けはたねで勝者)。**勝ち上がったクラブが次の相手**。負けたら残りのラウンドも決めて山を最後まで埋める
- 決まっていない先の相手は、日程に「勝ち上がり次第」

## 20.2 画面

- SEASON の大会の一覧で、抽選済みの大会の名前を押すとトーナメント表(`bracketModalHtml`)。グループ(順位・勝点)と、ラウンドごとの山(スコア・勝者・PK)。自分の試合は赤の印
- 表のクラブを押すと、そのクラブの SQUAD を重ねて見られる

## 20.3 実装

| やること | 場所 |
|---|---|
| 抽選・山 | `club.js` の `drawCup`(`cup.br` / `cup.grp2` / `cup.rmap`)|
| 勝ち上がり | `brAdvance`(勝ち抜き戦のラウンドが終わったとき)/ `brAfterGroups`(グループ戦が終わったとき)。`applyResult` から呼ぶ |
| 画面 | `clubui.js` の `bracketModalHtml` |
| テスト | `clubtest.js` ④ の「トーナメント」 |

前のセーブで抽選済みだった大会(`cup.rmap` が無い)は、前の作りのまま進む(トーナメント表は出ない)。次の周から新しい作り。
