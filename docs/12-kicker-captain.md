# 12. キッカーとキャプテンの任命(2026-11-19)

D14(キッカーの指名)の設計。あわせてキャプテン(CAP)を入れる。

## 12.1 伺った本家の仕様

- PK・FK・CK のキッカーは、**スカッドの編成で種類ごとに事前に指定**できた。本家は編成画面でカードをこすって役割を任命した
- キャプテン(旧作 〜17-18)はチームに1人任命できる
  - 選手ごとに**キャプテンシー(CP適性 S/A/B/C)**があり、適性が高い選手を任命すると**試合中、チーム全体のスタミナが減りにくい**
  - キャプテンがピッチにいると**チームの士気が下がりにくく**、連携やプレーが安定する
  - クラブハウスで任命したとき、性格や適性で**本人のやる気が上下する**ことがある
- (ユーザーの案)SQUAD も試合画面と同じく、**右に控え・中央に先発・左にセットプレーと CAP**

## 12.2 画面(SQUAD)

```
┌──────┬────────────────┬──────┐
│ CAP  │                │ 控え  │
│ [  ] │    ピッチ        │ [12] │
│ PK   │   (先発11人)     │ [15] │
│ [  ] │                │ [14] │
│ FK   │                │ [17] │
│ [  ] │                │ [19] │
│ CK   │                │      │
│ [  ] │                │      │
└──────┴────────────────┴──────┘
```

- 左の列に CAP・PK・FK・CK の4つの枠。枠には任命した選手の背番号と名前、その役の向き不向き(S/A/B/C)
- **任命のしかた**: 枠をタップ → ピッチの選手をタップ(またはピッチの選手を枠へドラッグ)。もう一度枠をタップすると「自動」に戻す
- 任命していない枠は「自動」(いまと同じく能力で選ぶ)
- 右の列は控え5人を縦に(試合画面と同じ並び)。ピッチは少し細くなる
- 選手の札には小さな印(C = キャプテンの腕章、キッカーは印なし)

## 12.3 キッカー

- 任命した選手が**ピッチにいればその選手が蹴る**。いなければ(交代・退場)自動
- 向き不向き(S/A/B/C)は、いまの自動の選び方と同じ式(PK = 決定力と技術、FK = 技術と決定力、CK = 技術とパワー、スキルのバフ込み)で、チームの中の順位から出す
- 効き目は**蹴る人が変わるだけ**(任命そのものの上乗せは無い)。FK の名手やレアKP の選手に蹴らせる、といった選び方ができる

## 12.4 キャプテン

- **CP適性 S/A/B/C** をカードに持たせる。スキル(キャプテン・リーダー → S)と年齢(30歳以上は1段上)から決める
- 効き目(キャプテンがピッチにいる間。適性で強さが変わる。数値は `TUNING.cap`)
  - チーム全体のスタミナの減り: S −6% / A −4% / B −2% / C 0
  - **士気**: 負けているとき、チーム全体が少し踏ん張る(全能力 S +3% / A +2% / B +1% / C 0)
- 任命したとき(クラブハウスでキャプテンを替えたとき)、本人のやる気: S・A は上がりやすく、C は重荷で下がることがある(1試合の準備につき1回まで)
- 相手チームも、いちばん適性の高い選手を自動でキャプテンにする(プレイヤーだけが得をしないように)
- 試合中、キャプテンが交代・退場したら効き目は消える(任命し直しはしない)

## 12.5 作る順番

1. CP適性・キャプテンとキッカーの効き目(engine)→ enginetest で効きを測る(キャプテン S で得失点差 +0.1 前後が目安)
2. SQUAD の3列の配置と任命の操作、セーブ項目(`S.roles = { cap, pk, fk, ck }`)
3. 試合画面: キャプテンの腕章、キッカーの実況(「指名キッカーの○○が直接狙う！」)

## 12.6 決まったこと(2026-11-19)

- この設計で進める。操作は「枠をタップ → 選手をタップ」
- **任命でやる気を上げる効き目は、やる気を戻す仕掛けに使えないようにする**(ユーザーの指摘)
  - 任命でやる気が上がるのは、**同じ選手に任期1回まで**(`S.capHist`。任期の始めに空にする)
  - キャプテンを付け替えると、**外された前のキャプテンは半分の確率でやる気が下がる**
  - 適性 C の選手は、任命すると重荷で下がることがある。B は動かない

## 12.7 作った(2026-11-19)

- エンジン: `capApt`(CP適性)・`rolePlayer`、`refreshFx` でキャプテンの効き目、`spKicker` が指名を先に見る。相手はいちばん適性の高い選手を自動でキャプテンに。
  プレイヤーのキャプテンは**任命したときだけ**(未任命なら効き目なし)
- 数値は `TUNING.cap`。セーブは `S.roles = { cap, pk, fk, ck }` と `S.capHist`(`migrate` で補う)。任命は `pool.js` の `setRole`
- 画面: SQUAD は3列(`clubui.js` の `sqRolesHtml`、`theme.css` の「SQUAD の3列と任命」)。3列のときピッチは縦長(100:150)。
  枠にはキャプテンシー(S/A/B/C)、キッカーは先発の中の順位から出す向き不向き(`kickMark`)。選手の板にキャプテンシー
- 試合: 盤面の札に腕章「C」(`board.js` の `iscap`)、実況「指名キッカーの○○が直接狙う！」
- **実測**(enginetest ⑬、600試合): キャプテンなし 0.18 → 適性 S のキャプテン 0.28(**+0.10**)、終了時のスタミナ 0.59 → 0.62。
  指名したキッカーは、ピッチにいる間は 216本中 210本を蹴った(残りは退場などのあと)
