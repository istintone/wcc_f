# 22. 日程(節)と任期

オーナーの決定(2026-11-21。→docs/21 §21.5 の1): 本家はゲームセンターの全筐体が同じ日程で進み、出ないカップは飛ばせた。これを応用し、100試合を自由に使えるようにする。

## 22.1 決まり

- 日程は「節」(1周 43枠)で進む
- **リーグの節は飛ばせない**(必ず試合をする。本家は飛ばせたが、wcc_f では飛ばせない形に決めた)
- **出ない・出られないカップの枠**は2択: フレンドリーマッチ(育成あり。節が1つ進み、任期の試合を1つ使う。本家でもフレンドリーをしている間も全体の日程は進んだ)/ **休んで節を進める**(試合なし。任期の試合は減らない)
- 出場が決まったカップは試合をする(棄権すれば、その先の枠は上の2択)
- 任期は100試合。100試合目で、途中のリーグとカップは打ち切り(昇格・降格・優勝は付かない)。決着しないオーナーの指令は「任期の終わりで打ち切り」(年俸は動かない)
- カップの枠を飛ばすほど周が早く回り、1任期でリーグの最終節(昇格の機会)が増える

## 22.2 画面

- HOME: 次がフレンドリー(出ないカップの枠)なら、試合の札の下に「この枠は休んで節を進める」
- SEASON の日程: 試合番号はリーグと出場するカップにだけ振る。飛ばせる枠は「・」と「休んで節を進められる」
- 任期終了の画面: 「途中のリーグとカップは任期の終わりで打ち切り」

## 22.3 実装

`club.js` の `skipSlot`(枠を進め、周を越えたら `endCycle`)/ `upcoming`(試合番号)、`term.js` の `endTerm`(指令の打ち切り)、`clubui.js` の `nextTileHtml`(フレンドリーの札の「節をスキップ」)。テストは `clubtest.js` ④ の「日程」
