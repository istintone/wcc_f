# 35. スポンサーのバナー(架空の企業ロゴ)

2026-11-28。オーナーの課題(次の課題の2番)「スポンサーをバナーにして使えるようにしたい」。サンプルを見てもらい、おすすめのとおりで合意。

## 35.1 ねらい

- スポンサーは社名の文字だけで出ていた。試合の奥の広告の帯は、社名を赤地に書いているだけだった
- 実際の企業ロゴのような**架空の**ロゴを社名から作り、試合の広告の帯・スポンサーミッション・スポンサーの画面に出して、クラブ経営のリアリティを上げる
- 実在の企業のロゴに似る形(有名なスウッシュ・三本線・楕円の重なりなど)は使わない

## 35.2 ロゴの作り方(`splogo.js`)

- 社名は業種(`SP_IND` / `SP_RARE`)の頭(pre)と尾(suf)の組み合わせ。保存は社名の文字列のままで、業種の候補と照らし合わせて頭と尾に分ける(セーブは変えない)
- ロゴタイプ: 頭を英字に(`SPL_ROMA`。ハヤブサ → HAYABUSA)。尾は小さな英字の添え字(`SPL_SUF`。モーターズ → MOTORS。家電のように訳さないものは空)
- マーク: 業種で決める(自動車 = 翼の山形 / 家電 = 稲妻の丸 / IT = 立方体の六角 / 飲料 = しずく / スポーツ用品 = 2本の斜線 / 金融 = 柱 / 航空・旅行 = 鳥 / ゲーム = 再生の角丸 / 医療 = 十字の丸 / 放送・芸能 = 星 / 食品 = 葉 / レア = 王冠)
- 会社の色: 業種ごとの色の組の候補から、社名のハッシュで選ぶ。同じ社はいつも同じロゴと色
- 型は3つ。社名のハッシュで選び、業種で固定するものもある
  - A マーク + 横文字(下に添え字)
  - B 会社の色の帯に白抜き(金融・医療は B に固定)
  - C 斜体の文字 + 下線の帯(スポーツ用品は C に固定)
- 書体はゲームに入っているものだけ(Oswald・Barlow Condensed)
- 1つの設計図(`spLogoSpec`)から、画面用の SVG(`spLogoSvg`)と、試合の背景のキャンバス用(`spLogoDraw`)の2通りに描く(SVG を画像にするとページの書体が使えないため)
- 暗い地・会社の色の地の上では白抜き(onDark)

## 35.3 出す場所

1. **試合の奥の広告の帯**(`render.js` の `boardAds` / `drawBoards`)
   - 枠の半分(偶数の枠)は契約しているスポンサー: 会社の色の地に白抜きのロゴ。スポンサーがいなければ WCC F のロゴ
   - 残りはパートナー企業(架空の他社。`spPartners`): 自分のスポンサーと違う業種から、クラブのたねで決まった顔ぶれ。白い地に色のロゴと、会社の色の地に白抜きが混ざる
   - 枠の数はスタジアムの段で増える(`TUNING.view.boardNLv`: Lv1〜2 = 4 / Lv3〜4 = 5 / Lv5 = 6)
   - Lv3 から LED: パートナーの枠が `TUNING.view.boardRot` ミリ秒ごとに入れ替わる。入れ替わりは上から下へ転がるように回る(`boardFlip` ミリ秒。前の面が下へ倒れ、次の面が上から起き上がる。回っている面ほど暗い。オーナーの希望「くるりんぱ」)。回っている間だけ、帯を背景の上に描き直す
   - パートナーの顔ぶれ(5社)に、ゲームのロゴ(WCC F)が1枠ぶん紛れている(オーナーの希望)。LED の段では入れ替わりの中でときどき出る。LED でない段は試合のたねで並びが決まり、試合によって出る
2. **スポンサーミッション・スポンサーを選ぶ画面・CLUB のスポンサーの欄**(`clubui.js` の `spCardHtml`): 1社の札の頭を、会社の色の帯に白抜きのロゴ(右に ☆ と RARE)にする。社名(日本語)・業種・収入はその下。ミッションの一覧は帯の下に続く
3. **対戦カードの場面(VS)**: ホームの側の社名を白抜きのロゴに
4. **ミッション達成の知らせの帯**: 帯の色を会社の色にし、見出しを「MISSION」に
5. **クラブ新聞の広告**(3面の下。`paperPage3`): 会社の色の地に白抜きのロゴ。上に OFFICIAL SPONSOR、下に社名と業種。記事に残る `ad`(社名・業種・☆)から描くので、前の号もロゴになる(オーナーの希望。2026-11-28)

## 35.4 決めたこと

- 広告の帯は自分のスポンサーが半分・残りはパートナー企業(オーナーがおすすめを選んだ)
- 出す場所は 35.3 の 1〜4 のとおり。ユニフォームの胸は今回は入れない
