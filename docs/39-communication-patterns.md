# 39. 選手とのコミュニケーションのパターンを増やす

2026-11-28。オーナーの課題(次の課題の8番)「選手コミュニケーションのパターンを増やしたい」。2026-11-28 にオーナーと合意(「すべて了解。実際に試さないとバランスが予想難しいので全部やりましょう」)。
性格を増やす(課題の9番)は別に扱う。ここでは今の3つの性格(褒められて伸びる・負けず嫌い・マイペース)のまま広げる。

## 39.1 いまの形

- 選手の話しかけ(`voiceOf`): 選手の状態 12通り(壁の手前・覚醒・調子が低い・疲れ・反抗期・成長期・控え続き・絶好調・若手・ベテランなど)× 性格3つ、各2文ほど
- 監督の言葉(`MGR_SAY`): 種類ごとに2〜3文。返事(`REACT_P`): 性格 × 結果3段で1〜2文
- 3択はミーティングの★突破(褒める・厳しく・任せる)だけ

## 39.2 案

### A. 話しかけの場面を増やす(試合の出来事とタグに反応する)

選手の状態に、最近の出来事を足す。優先は「いちばん最近・いちばん大きいこと」

| 場面 | 例(負けず嫌い) |
|---|---|
| 前の試合で点を取った | 「次も決めます。もっと取れる」 |
| 前の試合で MVP | 「今日の自分は、悪くなかったですよね？」 |
| 前の試合でミス・低い採点 | 「あのミス、自分で取り返します」 |
| ケガから戻った | 「やっと戻れた。遅れた分、取り返します」 |
| 不発・決定力不足 | 「入らない……でも、打ち続けます」 |
| 得点の上の段(嗅覚・量産) | 「今なら、どこからでも入る気がする」 |
| ゾーン | 「全部見えてるんです、今」 |
| 疲労の蓄積・オーバーワーク | 「まだやれます。……たぶん」 |
| 迷い・騒動・ゴシップ | 「今は、サッカーのことだけ考えたい」 |
| スター選手・受賞者 | 「注目されるのは悪くない。結果で応えます」 |
| 大一番の前(決勝・格上) | 「こういう試合のために、やってきたんです」 |
| 連携の相手(線が深い仲間) | 「{q}とは目が合うだけで分かるんです」 |
| 新加入(ROOKIE・ベテラン) | 「早くチームの力になりたいです」 |

13場面 × 性格3 × 2〜3文。今の12状態と合わせて 25 状態になる

### B. 監督の言葉と返事を増やす

- 監督の言葉: 種類ごとに 3 → 6 文、場面(A)に合わせた言葉も(例: ケガ明けの選手への声かけ)
- 返事: 性格 × 結果3段 × 種類4 で、それぞれ 3〜4 文(今は1〜2文)

### C. 相談の3択(メディカルの声かけに)

- 選手に悩み(調子が低い・控え続き・迷い・騒動・不発・オーバーワーク)があるとき、メディカルで声をかけると、選手が悩みを打ち明け、監督は3つの言い方から選ぶ(共感する・背中を押す・具体的に助言する)
- 性格ごとに合う言い方がある(褒められて伸びる = 共感 / 負けず嫌い = 背中を押す / マイペース = 助言)。合えば、やる気の戻りが大きく、悩みのタグも消える。合わなければ、いつもの声かけと同じ
- ミーティングの★突破の3択と同じ見せ方(並びは毎回入れ替える)

## 39.3 決めたいこと

1. A・B・C の全部をやるか、どれかから始めるか(おすすめは全部)
2. A の場面: この13でよいか。足したい場面はあるか
3. C の相談: メディカルの声かけに入れる形でよいか。悩みのタグを消すのは強すぎないか

## 39.4 実装(2026-11-28)

- 言葉は `talks.js`(DOM に触らない): `VOICE_SCENE`(A の13場面 × 性格3)・`MGR_MORE`(監督の言葉を足す)・`MGR_WORRY`(悩みに合わせた最初の一言)・`REACT_K`(返事: 種類4 × 性格3 × 結果3段 × 3文)・`CONSULT`(悩み6つの打ち明けと3つの言い方)・`CONSULT_BEST`
- 仕組みは `grow.js`: `voiceScene`(場面を選ぶ。準備の話・覚醒のあとに優先)・`worryOf` / `consultOpts` / `doConsult`(相談)。ケガが治った試合は `g.healAt`、前の試合の選手ごとの得点・採点・MVP は `S.lastPl`(`applyResult`)
- 数値は `TUNING.grow.comm` の `missRate`(ミスの場面の採点)・`consultMot`(合う言い方のやる気の上乗せ)・`consultFat`(疲れの悩みの抜け)
- 画面: メディカルで悩みのある選手を選ぶと、監督の一言 → 選手の打ち明け → 3つの言い方(`clubui.js` の `commChatHtml`。押すと `consult`)
