## 5. クラブ運営の設計(段階3)

**§5.10 の 3a(土台)・3b(育成)・3c(任期の終わり)は実装済み。3d(編成)は設計案**で、決めることは §5.9。
進め方は合意済み: **まず「1任期を最後まで回せる最小の形」を作り、細部はあとで足す。**
実装の中身と実測は §5.11。

### 5.1 本家の骨格

参照: 公式の「ゲームの流れ」、練習の一覧(48種。`tools/train_source.txt` に控えてある)、
覚醒と連携の解説、監督称号の一覧、大会のスケジュール。

| | 本家の仕組み |
|---|---|
| **1プレイ** | 育成(選手とのコミュニケーション)→ 試合 → カードが1枚払い出される。これの繰り返し |
| **育成の場所** | グラウンド(個人能力)/ ミーティングルーム(特殊能力 = KP)/ ラウンジ(呼び出して連携)。選手を指名する |
| **練習** | 6つほどの候補から選ぶ。候補は施設レベルや監督の称号で変わる。練習ごとに「何が伸びるか」と「戦力グラフのどの軸が上がり、どの軸が下がるか」が決まっている |
| **個人能力の★** | 育成値がたまると★が増える。**コミュニケーションでは★4まで**。その先は特別な選択肢に正解し、**フレンドリーマッチに勝つと覚醒(★5)**。能力が最大3項目、各+1(どれが上がるかは不定) |
| **特殊能力の★** | ミーティングルームで伸ばす。**KP にする選手だけ伸ばせばよい**。レアチームスタイルに関わる |
| **連携** | 線なし → 薄線 → 太線 → 黄金線。選手ごとに相性の組(A〜K)があり、相性が良ければ呼び出さなくても太線まで育つ。黄金線は「太線 → ラウンジで呼び出す → フレンドリーマッチに勝つ」 |
| **戦力グラフ** | 練習で上下する。選手の能力とは別に持つ |
| **試合の選択** | エントリー条件を満たしていればカップ戦、そうでなければ(または選んで)フレンドリーマッチ |
| **大会の並び** | 43試合で1周。リーグ戦(全14節)の合間に、格の違うカップ戦が8つ挟まる |
| **任期** | 100試合。終わると内容に応じて**監督称号**が付き、**年俸**が積み上がる。**絆を結んだ選手は、育成後のまま次の任期についてくる**。クラブの格が高い状態から始まることもある |

### 5.2 本作での置き方(最小の形)

```
 クラブハウス ─▶ 育成(練習を1つ選ぶ → 選手を1人指名)─▶ 試合を選ぶ ─▶ 試合 ─▶ 結果 ─┐
      ▲                                                                              │
      └──────────────────── 100試合で任期終了 → 称号・年俸・引き継ぎ ◀───────────────┘
```

| 画面 | 中身 |
|---|---|
| クラブハウス | 次の試合・任期の残り・成績・戦力グラフ。ここから育成と試合へ |
| 育成 | 練習の候補から1つ選び、続けて選手を指名する(§5.3) |
| 編成 | 16枚の出し入れと初期配置・既定の KP。(カードの入手は段階4。それまでは16枚固定) |
| 試合前 | 相手・大会・相手のスタイルを見る。カップかフレンドリーかを選ぶ |
| 結果 | スコア・育成の伸び・覚醒や黄金連携の成立・大会の進み |
| 任期終了 | 称号・年俸・ついてくる選手 |

**モードは増やさない**(touchline P7)。大会もイベントも、この1本の流れの中の出来事として置く。

### 5.3 育成 — チーム練習とコミュニケーション

**1試合につき: ① チーム練習を1つ → ② コミュニケーション(最大3回。使わなくてもよい)→ ③ 試合。**
**★の上昇・覚醒・連携の変化は、試合のあとに起きる**(練習やコミュニケーションでは経験がたまるだけ)。
実装は `src/js/grow.js`。

#### ① チーム練習

- 候補は**6つ。能力ごとに1つずつ**(攻撃 / 守備 / 技術 / パワー / スピード / スタミナ)。**全員に効く**
- **強度を選ぶ**: 軽め(伸び ×0.5・疲れない)/ 普通(×1.0・疲労 +2%)/ ハード(×1.6・疲労 +5%)
- **疲労**: 試合をそのぶん消耗した状態で始める。試合に出ると +2% たまり、次の試合までに 6割が抜ける(上限 20%)。
  4% を超えると選手に「！」が付く
- 基本の練習: 全員に個人能力の経験 +2(その能力が得意な選手は +3)× 伸びやすさ × 強度。戦力グラフの対応する軸 +0.12 × 強度
- **特殊練習**: 本家の48種。**基本の練習の上位として、同じ能力の枠に差し替わって出る**
  (差し替わる率 = 施設レベル × 12%)。伸びるもの(個人 / 連携 / 特殊 / セットプレイ)と、
  グラフの上がる軸・下がる軸を持つ。データは `tools/train_source.txt` → `python tools/gen_trainings.py`
  → `src/js/trainings.js`(手で編集しない)
- 能力と軸の対応: 攻撃 = オフェンス / 守備 = ディフェンス / 技術 = 支配 / パワー = パワー / スピード = スピード / スタミナ = 奪取

#### ② コミュニケーション(最大3回)

| 種類 | 呼ぶ人数 | 中身 |
|---|---|---|
| **個人練習** | 1人 | 個別に指導する。個人能力の経験 +8 × 伸びやすさ |
| **ミーティング** | 1人 | 戦術の話をする。特殊能力の経験 +8。**経験が満ちていると★突破の3択**が出る |
| **ラウンジ** | 2人 | 2人の様子(相性の手がかり)が出て、**3択**に答える。大成功 / 成功 / 失敗で連携の経験 +8 / +4 / 0 |
| **声かけ** | 1人 | やる気を上げる(好調以上は1段、不調以下は2段) |

- 同じ選手を何度呼んでもよい。練習を終えたら、コミュニケーションの途中でも試合へ進める
- ラウンジの3択(連携の練習をさせる / 食事に行かせる / 競わせる)は、**相性ごとに合う手が違う**。
  合う手なら 大成功 64% / 成功 30% / 失敗 6%。合わない手なら 5% / 35% / 60%
- ミーティングの3択(褒めて伸ばす / 厳しく求める / 本人に任せる)は、**選手の性格ごとに響く言い方が違う**。
  合えば成功 85%、外すと 32%。失敗すると経験が半分になり、やる気が1段下がる
- 選手に「！」が付くのは、★突破の話があるか、やる気が絶不調か、疲れているとき
- **特別指導**(追加スキルの習得など)はまだ無い(→§5.9)

### 5.4 選手の成長

| | 上がり方 |
|---|---|
| **個人能力 ★0〜4** | 経験(要る経験 26 / 48 / 68 / 94)がたまると**試合のあとに**上がる。★1つごとに、**その間にいちばん練習した能力が +0.5** |
| **個人能力 ★5(覚醒)** | ★4でさらに経験 40 →「覚醒の兆し」→ **フレンドリーマッチに出して勝つと 60% で覚醒**。能力が最大3項目、各+1(1つは必ず。2つ目 60%・3つ目 40%) |
| **特殊能力 ★0〜4** | ミーティングと特殊練習の経験(要る経験 12 / 18 / 24 / 30)。**★が上がるにはミーティングの3択に成功する**こと |
| **特殊能力 ★5** | ★4でさらに経験 30 → 兆し → フレンドリーマッチに出して勝つと 60% |

#### 蓄積に差が付く理由

**覚醒する選手・しない選手が分かれるのは、経験のたまり方に差があるから。**
**育成は集中させるもの**(→docs/08 §8.5。2026-11-18 に釣り合いを組み替えた): 練習と試合で全員に入る経験は小さく、
個人練習・ミーティングで呼んだ選手に大きく入る。1人に5〜10試合ぶん集中すると覚醒に届き、関わらない選手は★1〜2どまり。

| 差の元 | 中身 |
|---|---|
| **年齢** | 伸びやすさ: 21歳以下 ×1.40 / 22〜24歳 ×1.20 / 25〜28歳 ×1.00 / 29〜31歳 ×0.85 / 32歳以上 ×0.70 |
| **能力** | 得意な2能力の平均が 14 より1高いごとに −4%(×0.80〜×1.20)。**能力の高い選手ほど伸びが遅い** |
| **選んだ練習** | 全員に 0.4(得意な能力の練習なら 0.8)× 強度。特殊練習は 0.4 + 練習ごとの上乗せ |
| **個人練習で呼んだ回数** | 1回で **+20** × 伸びやすさ(ミーティングは特殊能力の経験 **+14**) |
| **試合に出たか** | 出ると +0.3 × 伸びやすさ |

- **若い選手は能力が低めで、やる気の上下が大きい**(上下の起きやすさ: 21歳以下 ×1.6 〜 32歳以上 ×0.55)。
  ベテランはその逆。相手クラブの選手も年齢を持つ(21歳以下は能力 −0.8、31歳以上は +0.4)
- 特殊能力の効き: **スキルのバフが ★1つごとに +5% 強まる**。**その選手を KP にすると、スタイルの軸の値に
  ★1つごと +0.2、★5でさらに +0.5**(ランクが上がる。本家の「★5で特殊KPに進化」にあたる。固有の名前と効果は段階4)
- **任期の初めは、全員の能力が −1.4**(6以下の能力は除く)。育てて戻し、上回る
- 能力の上限は 20

#### モチベーション

5段: ケガ(×0.80)/ 絶不調(×0.92)/ 不調(×0.97)/ 好調(×1.02)/ 絶好調(×1.06)。全能力に掛かる。初めは好調。

- 試合に出て勝つと上がりやすく(35%)、負けると下がりやすい(30%)。引き分けは 15% でどちらかに動く。
  **控えは、出番の無い試合が3試合続くと 25% で下がり始める**(ゆるやか。→docs/08 §8.4)。勝てば控えも 12% で上がる。
  何も動かなかった試合では、15% で普通(好調)へ1段戻る。どれも年齢による上下の起きやすさが掛かる
- 「！」の印は、★突破の話がある選手と、**先発で**絶不調の選手だけ
- 声かけで上がる。ミーティングの★突破の3択に失敗すると1段下がる
- **ケガはまだ起きない**(試合中の負傷を入れる段で使う)。相手クラブには掛けない

### 5.5 連携の育ち方

| 段 | 育ち方 |
|---|---|
| 線なし → 薄線(経験 10) | 一緒に試合に出る(+1)・連携の練習・ラウンジ。**段は試合のあとに上がる** |
| 薄線 → 太線(経験 30) | 同上。**試合と練習で育つのは相性の良い組だけ**。それ以外はラウンジで |
| 太線 → 黄金線 | **ラウンジで大成功 →「兆し」→ 2人ともフレンドリーマッチに出て勝つと 50%(1試合に1本まで)** |

- 相性はカードごとの組(11組。本家の A〜K)の近さで決まる: **良い**(試合に出るだけで太線まで)/
  **ふつう**(薄線まで)/ **悪い**(ラウンジでしか育たない)。本家の相性表は使っていない
- 任期の初めは線なしから始まる

### 5.6 戦力グラフ

- 6軸それぞれに**練習による上乗せ**(−2.0〜+3.0)を持ち、スタイルの軸の値に足される
- 練習のたびに全軸が 1.5% ずつ 0 へ戻る。**全部を高く保つことはできない**
- 特殊練習は上げる軸(+0.10。全軸なら +0.06)と下げる軸(−0.08)を持つ
- セットプレイの練習は、FK・CK・PK に掛かる倍率を上げる(星1つで +2%、上限 +20%)
- **相手クラブは育成しない代わりに、強さの段に応じた上乗せを初めから持つ**(−0.3 〜 +0.9)。
  連携の線も段に応じて多い(10〜26本)。→touchline P4

#### 実測(1任期を、検証用の方針で育てながら回す)

| | 任期の終わり |
|---|---|
| 個人能力 | 集中して育てた3人は個人・特殊とも ★5(兆しが出たら次の選手へ移る遊び方)。関わらなかった控えは ★1〜2 / 覚醒 **5人** |
| 特殊能力 | 集中して育てた3人が ★5 |
| 連携 | 薄線 38 / 太線 23 / 黄金線 8 |
| 段4の相手との得失点差 | **−1.33 → −0.63** |
| 控えのやる気(放っておいた場合) | 絶不調は多くて16人中5人(前は終盤に12人) |
| 練習の強度(40試合) | 軽め ★0.4・疲労 1% / 普通 ★1.3・疲労 3% / ハード ★1.5・疲労 5%(集中育成の方針で、全16人の平均) |
| やる気が動く率(1試合) | 19歳 42% / 34歳 16% |

疲労は効きが強い: 試合の初めの疲労 3% で得失点差 −0.06、6% で −0.38、10% で −0.66。
**ハードは続けるものではなく、試合の間隔や相手を見て使うもの**。

### 5.7 試合と大会

**43試合で1周する本家のスケジュールをそのまま使う。** 100試合の任期で2周と少し。

| 格 | 大会 | 試合数 | 形式 |
|---|---|---|---|
| — | レギュラーリーグ | 14 | 8クラブの2回総当たり |
| E | プレシーズンカップ | 3 | 勝ち抜き |
| D | エンタープライズカップ | 3 | 勝ち抜き |
| C | キングスクラブカップ / ナショナルスーパーカップ | 3 / 1 | 勝ち抜き / 1試合 |
| B | W4タイトルホルダーズカップ | 4 | 小さなリーグ + 決勝 |
| A | コンチネンタルカップ / コンチネンタルスーパーカップ | 3 / 1 | 勝ち抜き / 1試合 |
| S | チャンピオンズトロフィー / ジャパントロフィー / インターナショナルクラブチャンピオンシップ | 5 / 1 / 5 | 勝ち抜き |

- **エントリー条件**: 格の高い大会ほど、前の周の成績(リーグの順位・下の格の優勝)が要る。
  満たさない枠・負けて残った枠は**フレンドリーマッチ**になる
- **カップの枠でも、フレンドリーマッチを選べる**(覚醒と黄金連携はフレンドリーでしか成立しないため)
- 勝ち抜き戦で同点なら **PK戦**(延長は入れない)
- 賞金は大会の格と結果で決まり、任期の合計が称号と年俸に効く
- 大会名は本家のものを仮に使う。公開する版では差し替える(実名パックと同じ扱い)

**相手クラブ**: 段階4で実在クラブのデータが入るまで、**架空のクラブを自動生成**する(24クラブ・強さ5段)。
強いクラブほど★・連携・グラフが進んでいる(固定値。→touchline P4)。

### 5.8 任期の終わり

#### 年俸と施設

```
年俸 = 20億 + その任期の賞金 × 0.15 + 称号の上乗せ        累計に積み上がる
施設レベル = 累計 80 / 200 / 380 / 640億 で 2 / 3 / 4 / 5
```

施設レベルが上がるほど、チーム練習の枠が特殊練習に差し替わりやすい(レベル × 12%)。

#### 次の任期についてくる選手

- **絆**はコミュニケーションで呼ぶと深まる(個人練習・声かけ +1、ラウンジ +1ずつ、ミーティング +2)
- 絆が 6 以上の選手のうち、深い順に**最大3人**がついてくる
- ついてきた選手は**個人能力の★・特殊能力の★・伸ばした能力をそのまま**持って始まる。互いの連携も残る。
  やる気は好調・疲労は0から。絆は半分になる
- ほかの選手は育成が初めから(任期の初めの −1.4 から)

#### 残るもの / 消えるもの

|---|---|

### 5.9 決めること

| | 決めること | 案 |
