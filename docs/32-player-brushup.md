# 32. 選手のブラッシュアップ会議(2026-11-27)

テーマ(オーナー)
1. 選手の数値と能力が、実在選手をイメージできる内容か
2. 選手のイメージをより想起させる、新しいスキルや KP はあるか
3. 全体的な選手のバランス

材料: カードの一覧 256枚(実在16クラブ × 16人)の作り方(`tools/gen_cards.py`・`pool.js`)、能力の分布、スキル・KP・レアKP・固有タグ・特性の割り当てを Node で数えた。
実名の照らし合わせは手元の `tools/squads.local.txt` で行い、この文書には実名を書かない(傾向と数だけ)。

## 32.1 いまの作り方

- 能力 = **役割のひな形**(GK・CB・SB・DMF・CMF・OMF・SMF・WG・CF の9種。`club.js` の `GEN_ROLE`)
  \+ **格**(0.5〜3.5。6能力すべてに同じだけ足す。低い能力は 3割だけ)
  \+ **特徴**(o d t p s a に +2 / −2 を1〜2個)
- スキルは1枚1つ。**KP の型はスキルで決まる**(`SKILLS[k].style`)
- レアKP 64枚(固有名と技。技は7種)、固有タグ 16、特性タグ 16

## 32.2 観点1: 数値で実在選手をイメージできるか

### 見えたこと

| 指標 | 値 | ひと言 |
|---|---|---|
| 同じ役割の誰かと6能力が**完全に同じ**カード | **185 / 256 枚**(51組) | 個性はほぼ「特徴の1〜2個」だけ |
| 総合値(6能力の合計)の幅 | 62〜88 | 世界最高峰(格 3.4)と主力(格 1.6)の差が 6 しかない例もある |
| 能力 20(上限)を持つカード | 2枚 | 「この能力は世界一」が表せない |
| GK どうし | 世界最高峰の GK 2人が6能力まで同じ | GK はひな形 + 特徴1つで、ほぼ見分けがつかない |

- **格が6能力に均等に乗る**ので、スターほど「全部そこそこ高い」になり、尖りが出ない。最高峰の CF 2人(点取り屋と快足)が同じ合計・同じスキル
- **ひな形が強く出る**: 守備的 MF に入れた司令塔型が、DEF 15・POW 14 の「潰し屋」の数字になる。快足ウイングの3人が 1〜2 の差でほぼ同じ並び
- 一方で、**役割と格のおおまかな並び**(誰が上位か)は実在の印象とおおむね合っている

### 提案

- **P1 役割の「型」を足す**(ひな形を役割 × 型に細かく)
  - 例: CF = 点取り屋 / ターゲット / 偽9番 / 万能型。WG = 突破 / カットイン / チャンスメイク。CMF = レジスタ / ボックス・トゥ・ボックス / 潰し屋。CB = 対人 / ビルドアップ / 空中戦。SB = 攻撃型 / 守備型 / インサイド。GK = ショットストッパー / スイーパー / フィード
  - 型ごとにひな形の6能力を変える(同じ合計で配分だけ違う)
- **P2 格は「強み」に厚く乗せる**: 格の上乗せの多くを、その選手の上位2〜3能力へ。弱みにはほとんど乗せない。スターほど尖る(最高峰は1〜2能力が 19〜20)
- **P3 特徴を3段階・最大4つに**: +1 / +2 / +3 と −1 / −2。「SPE +3・TEC +1・POW −1」のように書ける
- 目標: 6能力が完全に同じ組 51組 → **5組未満**。最高峰の上位2能力の平均 19 以上

## 32.3 観点2: イメージを想起させる新しいスキル・KP

### 見えたこと

- スキル 41種のうち 37種を使用。未使用は4種(ロングパス・神・ライン統率・キラー)
- **KP の型がスキルで決まる**ので、同じ型が固まる: オーバーラップ 15人・シュートセービング 14人・オーガナイズドディフェンス 13人・カバーリング 13人。SB と GK はほぼ全員が同じ KP になる
- レアKP の技は7種(ルーレット・ロングシュート・ノールック・ヒール・オーバーヘッド・スライディング・神セーブ)。64枚で7種なので、技でも差が出にくい
- 固有タグは 16人(各クラブ1人)

### 提案

- **S1 新しいスキル(選手の「らしさ」が試合の動きに出るもの)**。どれも試合の処理と映像の両方で効く(docs/30 の特性の動きと同じ作り)
  | スキル | 中身 | 想起させる型 |
  |---|---|---|
  | カットインシュート | 逆サイドから中へ切れ込み、巻いて撃つ。斜めの角度のシュートが入りやすい | 逆足ウイング |
  | レジスタ | 低い位置からの散らし・ロングパスが通る(未使用のロングパスを作り直す) | 深い位置の司令塔 |
  | 偽9番 | CF が中盤へ降りて受け、2列目の飛び出しを生む | 偽9番 |
  | ジャッカル | こぼれ球・ゴール前の混戦に強い | 点取り屋 |
  | ゲーゲンプレス | 奪われた直後に奪い返しやすい | ハードワーカー |
  | ビッグマッチ | 決勝・格上との試合で能力が上がる | 大舞台に強いベテラン |
  | ロングスロー | サイドのスローがクロスと同じ扱い | 守備的 SB |
  | PK の名手 | PK が決まりやすい(キッカーに任命すると) | 名キッカー |
- **S2 KP の型をスキルから切り離す**: カードはスキルと KP の型を別々に持つ。同じ「オーバーラップ」のスキルでも、KP の型は「全員攻撃」「サイド突破」などに分かれる(SB・GK の偏りが解ける)
- **S3 レアKP の技を増やす**(7種 → 15種前後): 無回転FK・ループシュート・股抜き・シザース・ダイビングヘッド・アウトサイドパス・ラボーナ・ジャンピングボレーなど。技はカットインの演出つき
- **S4 固有タグを広げる**: 各クラブ1人 → 2〜3人(32〜48人)。そのクラブの顔になる選手の「らしさ」(例: 大舞台・鉄人・ムードメーカー)

## 32.4 観点3: 全体のバランス

### 見えたこと

| 役割 | 人数 | 総合値の平均 |
|---|---|---|
| GK | 32 | **64.6** |
| CB | 47 | 74.5 |
| SB(左右) | 29 | 79.1 |
| DMF / CMF / OMF | 73 | 80.0 前後 |
| SMF・WG・CF・ST | 75 | 79〜81 |

- **GK の総合値が 15 低い**(ひな形の OFE 3 が効いている)。盤面の札の数字・視察の OVR で、GK が強くても低く見える。CB も 5 低い
- **SB が高い**(ひな形の SPE・STA 15)。総合値だけ見ると、主力の SB が最高峰のストライカーと並ぶ例がある
- 格 → レアリティ → 排出率(W 60% / B 30% / K 8.5% / L 1.5%)の流れは素直。格 3 以上は 5人だけ
- 能力の上限 20 に対して、カードの天井が 19 前後。育成(★の +0.5 × 4・覚醒 +最大3)で、主力の多くが上限近くにそろってしまう

### 提案

- **B1 札の数字を「役割で重みをつけた評価」にする**: 6能力の単純な合計をやめ、役割ごとに効く能力へ重み(GK は DEF・POW・SPE、CB は DEF・POW など)。GK・CB が低く見える問題がなくなる。試合の処理は変えない(見せ方だけ)
- **B2 ひな形の合計を役割ごとにそろえる**(B1 を入れないなら): GK・CB の合計を上げ、SB を下げる
- **B3 格の効きを広げる**: 格 0.5 と 3.5 の差を今の約2倍に。最高峰がはっきり強い
- **B4 スキルの強さを測る**: enginetest で「そのスキルを持つ選手を1人入れたときの得失点差」を全スキルで測り、強すぎ・弱すぎを直す(docs/30 の特性と同じ測り方)
- **B5 確かめをテストに**: 同じ並びの組の数・総合値の幅・役割ごとの評価の差を clubtest に入れ、データを足しても崩れないようにする

## 32.7 オーナーの答え(2026-11-27)

1. 本家の総合値はやや MF 寄りの重みだったが、**今回は重みをほとんど付けない**のが望ましい。ただし **GK に使わない数値がある、などは無いこと**が前提
2. 型は実在選手のイメージに合わせて設定する(オーナーが確かめる)。型の特徴は、数値に乗せるのもよいが、**振る舞いで差別化**するのもよい
3. KP の型とスキルは**分ける**
4. 新しいスキルはどれも面白い。**不足があれば多めに足してよい**

## 32.8 設計(第1弾: 数値・型・KP・スキルのデータ)

### A. 6能力はどの役割でも全部使う / 合計はそろえる

- GK の OFE は、今は試合のどこにも使われていない。**GK の OFE = 攻撃の起点(フィード)**にする: ロングキック(今は POW)を OFE で判定する
  - これで GK は OFE(フィード)・DEF(セーブの主)・TEC(セーブ・短い繋ぎ)・POW(セーブ・競り合い)・SPE(飛び出し・スロー)・STA を全部使う
- 役割のひな形の6能力の合計を**すべて 73 にそろえる**(今は GK 62 〜 DMF 75)。札の数字(合計)は重みなしのまま
  - 合計は同じで、配分だけが役割と型で違う

### B. 型(役割 × 型。数値の配分 + 振る舞い)

### C. 格は強みに厚く / 特徴は3段階・最大4つ

- 格の上乗せは、その選手の上位2〜3能力に厚く(例: 上位から 1.6 / 1.3 / 1.0 / 0.7 / 0.5 / 0.4 の比)。最高峰は強みが 19〜20 に届く

## 32.9 第1弾の実装と実測(2026-11-27)

### 型の振る舞い(`TUNING.ptype`。特性タグと同じ語彙を `bhOf` で1つにまとめ、試合の処理と映像は `p.bh` だけを見る)
