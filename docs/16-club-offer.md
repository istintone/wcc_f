# 16. クラブオファーとクラブの期待

オーナーの話(2026-11-20。→docs/15 §15.9)から組み、オーナーに1つずつ確かめて決めた(2026-11-20)。実装は §16.4。

## 16.0 わかっていること(オーナーの話)

- 任期が終わって次の任期を始めるとき、**3つのクラブからオファー**が届き、1つを選ぶ
- 届くクラブは、**取った称号と年俸**で決まる
- 弱小クラブからメガクラブまであり、**初めの成長グラフ・スタジアム・クラブ施設の育ち具合**が違う。スポンサーも、大きいクラブほど良いものになる
  → 2任期目からは、少し育った成長グラフから始まる
- **3択の時点で、各クラブのグラフと施設を見比べてから**、監督が次のキャリアを決められる

## 16.1 いまの作り(任期の始め)

1. 任期終了の画面(称号・年俸・監督ランク・ついてくる選手)
2. **監督契約**: クラブ名・略称・ホームタウン・エンブレム・色を自分で決める(→docs/10 §10.2 A)
3. 称号のセット → 秘書 → スポンサー
- 資金・ファン・スタジアム・施設・スポンサー・成長グラフは、すべて初めの状態に戻る(→docs/08 §8.12)
- 始めるリーグの格は、前の任期の称号で決まる(`TITLES` の `grade`)

## 16.2 決めること

- **オファーのクラブ**(決定 2026-11-20): 「欧州のメガクラブ」「南米の地方クラブ」「3部リーグのクラブ」のような**くくりの名前**(偽名)で届く。
  選んだあとは、今までどおり**監督契約でクラブ名・エンブレムを決める**
- **規模で違うもの**(決定 2026-11-20): 成長グラフ・スタジアム・施設・スポンサー・**初めの資金・ファンの数・始めるリーグの格・期待される成績**
- オーナーの話: クラブの名前の**くくりに特色**がある。「欧州」ならスタジアム、「南米」なら練習場が育っている。
  「2部リーグ」なら1段階育っていて、「欧州の2部リーグのクラブ」ならスタジアムが2段目から。
  「メガ・ビッグ・中堅・弱小」と「何部リーグか」で、ファンと資金の幅が決まる。全体の格の大きさで、期待される成績が決まる

### 案: オファーの名前 = 地域 × 規模 × 部(例「欧州 2部リーグの中堅クラブ」)

| 要素 | 決まるもの |
|---|---|
| **地域**(特色) | 育っている施設が1つ。欧州 = スタジアム / 南米 = 練習場 / 北中米 = メディカル / アジア = ラウンジ / アフリカ = 戦術室 |
| **部** | 始めるリーグの格(1部 = 格3・2部 = 格2・3部 = 格1)と、特色の施設の段(3部 +0・2部 +1・1部 +2。スタジアムは1段目が初め) |
| **規模** | ファン・資金の幅と、成長グラフの初めの値。メガは1部だけ、ビッグは1〜2部、弱小は2〜3部 |
| **格の大きさ**(規模 × 部) | 期待される成績 |

| 規模 | ファン(1部の幅。2部 ×0.7・3部 ×0.5) | 初めの資金(億。同じく部で減る) | 成長グラフの初め(各軸) |
|---|---|---|---|
| 弱小 | 4,000〜6,000 | 0〜10 | 0 |
| 中堅 | 9,000〜13,000 | 10〜30 | 10〜20 |
| ビッグ | 18,000〜26,000 | 30〜60 | 20〜35 |
| メガ | 32,000〜45,000 | 60〜100 | 35〜50 |

- 上の形は**決定**(2026-11-20。数値の細部は任せる)
- **地域の育成の特性**(決定 2026-11-20): 成長グラフの初めの値は、地域で得意な軸が高い。欧州 = OFE / 南米 = TEC。
  ほかは案: 北中米 = POW / アジア = SPE / アフリカ = STA(DEF は下の「伝統的クラブ」)。各対の器(130)の中に収め、金色・MAX からは始まらない
- **レアオファー**(決定 2026-11-20): 監督の年俸などに応じて、3択の1つが**まれに**レアなクラブになる

| レアクラブ | 特色 |
|---|---|
| 銀河系軍団 | すべてがメガのさらに上 |
| オイルマネークラブ | 初めから資金がとても多い |
| 新興クラブ | 1部リーグ級だが、期待される成績が低い(易しい) |
| 名門クラブ | ファンがとても多い |
| 伝統的クラブ | 2〜3部級だが、期待される成績は高い(案: 成長グラフは DEF が得意) |
- スポンサーはファンとリーグの格で候補が決まる今の仕組みのままで、大きいクラブほど良くなる
- 稼いだ資金(称号の条件・歴代の最高額)は、初めの資金を引いた分で数える(今の `money0`)
- **3つの決まり方**(決定 2026-11-20): 取った称号と年俸から「監督の格」を出し、**だいたい見合ったクラブ**が届く。**たまに上や下のクラブ**が混ざる。
  1任期目(称号なし・年俸 0)は、弱小〜中堅の格になる
- **1任期目も同じ**(決定 2026-11-20): 初めて遊ぶときも、オファーの3択からクラブを選ぶ(監督ライセンスのあと、監督契約の前)

## 16.3 期待される成績(本家からアレンジ。決定 2026-11-20)

オーナーの方針: **全編を通して目標にするのは獲得賞金**。メガクラブほどメリット・デメリットが大きく、運営が難しくなるようにする。

- **賞金の期待値**: クラブの格ごとに、その任期の獲得賞金(リーグ・カップの賞金)の期待値がある。任期の終わりに届いていれば**達成で年俸アップ**
- **オーナーの気まぐれ指令**: カップ戦やリーグ戦の途中で「このタイトルを獲れ」という指令が出る。**クラブの格が大きいほど出やすい**。
  達成で年俸アップ、失敗で年俸ダウン

### 決めた形(2026-11-20。数値の細部は任せてもらった)

| | 案 |
|---|---|
| クラブの格 | 規模(弱小 1・中堅 2・ビッグ 3・メガ 4)+ 部(3部 0・2部 1・1部 2)で 1〜6。銀河系軍団は 7。新興クラブは期待だけ 2 段下、伝統的クラブは期待だけ 2 段上 |
| 監督の格 | 取った称号の格(前の任期の `grade`)と監督ランク(累計の年俸)から 1〜7。1任期目は 1〜2 |
| 3つのオファー | それぞれ「監督の格」にばらつきを足した格のクラブ。たいていは ±0、ときどき ±1、まれに ±2。3つの地域は重ならないように選ぶ |
| レアオファー | 3つのうち1つが、年俸の累計が多いほど出やすい率(初めは 5% ほど)でレアクラブに替わる |
| 賞金の期待値 | クラブの格ごとの額(実測して、見合った格のクラブで半分ほどが届く額に合わせる)。達成で年俸 +(格 × 数億)、未達は上乗せなし |
| 指令 | 大会が始まるとき(カップの初戦・リーグの1節)に、クラブの格で決まる率(弱小 10% 〜 メガ 50%)で「◯◯で優勝せよ」「リーグで N 位以内」。HOME と秘書が伝える |
| 指令の結果 | 達成で年俸 +、失敗で年俸 −(どちらも格が大きいほど大きい)。任期の終わりの画面に、期待・指令の結果と年俸の増減を並べる |

## 16.4 実装

| やること | 場所 |
|---|---|
| 数値(規模ごとの幅・部の倍率・地域の得意な軸・ばらつき・レアの率・賞金の期待値・指令の率と年俸) | `data.js` の `TUNING.offer` |
| 地域・規模・レアクラブ | `club.js` の `OF_REGIONS` / `OF_SIZES` / `OF_RARES` |
| 監督の格・オファーを作る・選ぶ | `club.js` の `mgrLv` / `mkOffer` / `makeOffers` / `offersOf` / `pickOffer` |
| オーナーの指令 | `club.js` の `misAfterMatch` / `misEnd`(`applyResult` と `endCycle` から呼ぶ) |
| 年俸の内訳 | `term.js` の `endTerm`(期待の達成 + 指令の増減。`S.tend.exp` / `mis`) |
| 画面 | `clubui.js` の `offerHtml` / `offerCardHtml`(監督ライセンスのあと、監督契約の前)、HOME の `expTileHtml`、任期終了の `termExpHtml` |
| テスト | `clubtest.js` ④ の「クラブオファー」 |

- 手順: 監督ライセンス(初回)→ **クラブオファー** → 監督契約 → 称号のセット → 秘書 → スポンサー
- 古いセーブ: 途中の任期(クラブを決めたあと)は `cprof:{ legacy:true }` にして、オファーも期待も指令も無いまま続ける。次の任期からオファーが届く
- **賞金にリーグの格の倍率を掛けた**(`TUNING.club.prize.gradeK` = 格1 ×1・格2 ×1.6・格3 ×2.4。フレンドリーマッチは除く)。
  上のリーグほど相手が強く、倍率なしでは大きいクラブほど獲得賞金が減っていたため

#### 実測(検証用の素朴な育て方で1任期。5通りのたね)

| 期待の格 | 獲得賞金の中央 | 期待値 |
|---|---|---|
| 1 | 122億 | 70億(届きやすい) |
| 2〜3 | 67〜82億 | 80・95億 |
| 4〜5 | 115〜126億 | 110・125億(半分ほど) |
| 6 | 104億 | 140億(届きにくい) |
| 7(銀河系軍団) | 76億 | 160億(とても届きにくい) |

メガクラブ・銀河系軍団ほど期待が高く、指令(失敗で年俸 −)も多いので、運営が難しい。

## 16.5 所属するリーグ(国)(2026-11-22)

- オーナーの決定: クラブに所属するリーグ(国)を持たせる。**オファーで決まり、表示する**(遊びの数字には効かない)
- 地域ごとの国(`club.js` の `OF_COUNTRIES`): 欧州 = イングランド・スペイン・イタリア・ドイツ・フランス・オランダ・ポルトガル / 南米 = ブラジル・アルゼンチン・ウルグアイ・コロンビア / 北中米 = アメリカ・メキシコ・カナダ / アジア = 日本・韓国・サウジアラビア・オーストラリア / アフリカ = エジプト・モロッコ・ナイジェリア・南アフリカ
- オファーの `country`。乱数の並びを変えないよう、たね・任期・地域・格から決める。オファーの名前も国で(例「コロンビアの2nd Div の弱小クラブ」)
- リーグの名前は国名で「○○・リーグ」(実在のリーグ名は使わない。`leagueOf`)。前のセーブで国が無ければ地域と名前から決める(`countryOf`)
- 見せる: オファーの札(上の行と「リーグ」の欄)、CLUB のクラブの欄(略称 ・ ○○・リーグ 2nd Div)
- ホームタウンは今は選ばない・出さない(クラブの欄と編集の画面から外した。データは残す)
