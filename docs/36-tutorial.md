# 36. チュートリアル

2026-11-28。オーナーの課題(次の課題の3番)「チュートリアルを用意したい」。案 A(秘書の案内)・B(練習試合)・C(両方)から、オーナーが C を選んだ。

## 36.1 ねらいと決まり

- 初めて遊ぶ人が、クラブハウスの流れと試合中の操作で迷わないようにする
- 画面に説明文を常に置かない(「説明文は消していく」の方針)。案内は**その場面に初めて来たときに1回だけ**、秘書が出てきて話す
- いつでも飛ばせる(SKIP で残りのチュートリアルをすべて止める)。MANAGER の設定から、もう一度見られる

## 36.2 A 秘書の案内(クラブハウス。`tutorial.js`)

- 画面の上に重なる層(`#tut`)。押すところを光らせ(まわりを暗くする)、下に秘書の顔と吹き出し(1〜2行)。TOUCH で次へ、SKIP で全部止める
- 光らせる部品が画面に無いときは、吹き出しだけ出す
- 初めて来たときに出る場面と話すこと(`TUT_CLUB`)
  - HOME: クラブの情報(OVR・資金)/ 次の試合と「試合の準備」/ 下のメニュー / 練習試合の札
  - 準備 ① 練習: 強さ(休養〜)と練習の選び方
  - 準備 ② コミュニケーション: 4つのやり方と残りの回数
  - 準備 ③ 視察: スカウティングレポート(秘書との親密度で読める量が変わる)
  - 準備 ④ 戦術: 称号・監督能力・ハーフタイムの指示を選んで試合へ
  - SQUAD: 盤面のカードを引っ張って並べる・最適配置・KP
  - CARDS: 集めたカード
  - SEASON: 日程と順位・相手を押すとスカウティングレポート
  - CLUB: スポンサーと施設
- 見たかどうかはセーブに持つ(`S.tut = { seen:{ 場面: 1 }, off, match }`)。古いセーブは見たことにする(遊んでいる人に急に出さない)。設定の「チュートリアルをもう一度見る」で最初から

## 36.3 B 練習試合(試合中の操作)

- HOME に「TUTORIAL MATCH」の札(練習試合をまだしていない・チュートリアルを止めていないとき)。押すと、次の試合の相手と練習試合。**結果・成長・資金は記録に残らない**。札の「今はしない」で消える
- キックオフの前に試合を止めて、秘書が順に案内する。「やってみる」の段は、その操作をすると次へ進む(TOUCH でも進める)
  1. 盤面のカード: 指で引っ張ると、その位置で戦う(やってみる)
  2. 十字の戦術ボタン: 中央突破・左右のサイド・プレス・カウンター(やってみる)
  3. KP: キープレイヤーのスタイルを発動
  4. SHOOT: 押しておくと、次のチャンスで撃つ(やってみる)
  5. KEEPER: キーパーの指示
  6. 控え: SUB の列のカードを盤面の選手に重ねると交代
  7. 「では、キックオフです!」で試合が動く
- 試合が終わったらクラブハウスへ戻る(練習試合を済ませた印を付ける)
