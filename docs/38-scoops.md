# 38. ゴシップの秘密の情報(スクープ)

2026-11-28。オーナーの課題(次の課題の7番)「ゴシップから得られる秘密の情報でイベントを起こしたい」。2026-11-28 にオーナーと合意(38.5)。

## 38.1 いまの形と、ねらい

- いま: クラブ新聞の3面の RUMORS(ゴシップ欄)は、その試合で起きたことを噂の書き方にした文と、決まった型のうわさ話1つ。読み物で、遊びにはつながっていない
- ねらい: ゴシップの中に「本当かもしれない手がかり」を混ぜる。監督が気になった手がかりを秘書に調べさせると、秘密が分かり、出来事(2択)になる。新聞を読む理由と、秘書との親密度の使い道を増やす

## 38.2 流れ

1. **手がかり**: 新聞の号ごとに、ゴシップの1つが手がかりになることがある(率は TUNING)。紙面では「SCOOP?」の小さな赤い判子が付く
2. **調べる**: 判子を押すと「秘書に調べてもらう」。調べられるのは同時に1つ。手がかりは5試合で古くなる
3. **報告**: 次の試合のあと、秘書が HOME で報告する(EVENT の札)。本当だったか・ただの噂だったかは、秘書の親密度で決まる(親密度が高いほど本当の秘密にたどり着く)
4. **出来事**: 本当なら秘密に応じた2択。ただの噂なら一言で終わる
5. 見つけた秘密は COACHING NOTE に「SCOOPS」として数える

## 38.3 秘密の種類(案)

| 手がかり(ゴシップ) | 秘密 | 2択と結果 |
|---|---|---|
| 次の相手のエースが練習を休んでいる | エースは足を痛めている | 「そこを突く」= 次の試合、相手のエースの能力 −2 / 「見なかったことに」= サポーターの評判(ファン +) |
| うちの{p}に国外のクラブが関心か | {p}は本当に迷っている | 「話を聞く」= 確率で 成長期(残る決意)か 反抗期 / 「放っておく」= 調子が下がりやすい |
| {p}、夜中にひとりで練習 | 実は焦っている | 「付き合う」= 経験 + ・疲れ + / 「休ませる」= 疲れが抜ける |
| {p}と{q}がオフに一緒に食事 | 2人は昔からの仲 | 「同じ組で練習させる」= 2人の連携の経験 + / 「普段どおり」= 何もしない |
| スポンサーの社長が試合を見に来ていた | 協賛を増やす気がある | 「もてなす」= 次のミッションの報酬 ×2(資金 −0.3億)/ 「普段どおり」 |
| 相手監督が新しい布陣を試しているらしい | 次の試合で布陣を変える | 「対策を練る」= 次の試合、相手の後半の采配の効きが弱い / 「気にしない」 |
| 街で伝説の OB を見かけた | OB がクラブを気にかけている | 「会いに行く」= のちの隠しイベント(課題13)の種 / 「そっとしておく」 |

- 相手の秘密を使う選択(エースの足を突く)には、後ろめたさの代わりに小さな代償(新聞に「卑怯」と書かれ、ファンが少し減る率)を付けるか、付けないかを決めたい

## 38.4 決めたいこと

1. 入り口: 新聞の手がかり(判子)を押して秘書に調べさせる形でよいか(新聞を開かない人には、HOME の秘書が「気になる噂がありますよ」と一言だけ知らせる)
2. 秘密の種類: 38.3 の7つでよいか。足したい・外したいもの
3. 相手の秘密を使うときの代償: 付けるか(付けるなら「ファンが少し減る率」)
4. 伝説の OB の種: 課題13(隠しイベント)につなげる前提でよいか

## 38.5 決めたこと(2026-11-28)

1. 入り口は新聞の判子。秘書の誘導は言い回しを何通りか(「気になるうわさが載っていますよ。もう新聞は読まれましたか？」「たまにはニュースもチェックしてくださいね」など)
2. 秘密の種類はまず 38.3 の7つ
3. 相手の秘密を突くときの代償を付ける(新聞に「卑怯」と書かれ、ファンが減る率)
4. 伝説の OB の種は、課題13(レジェンドチームとの隠しイベント)につなげる

## 38.6 実装

- 仕組みは `scoop.js`(DOM に触らない): `scoopLead`(新聞の号に手がかりを作る。`paper.js` の `makeArticle` から)/ `scoopAsk`(調べる)/ `scoopAfterMatch`(試合のあとに報告を作る・相手の弱みを使い終える)/ `scoopAnswer`(2択に答える)/ `scoopOppDef`(相手のエースの能力を下げる・相手監督の采配を止める。`oppDefOf` の最後)
- 数値は `TUNING.scoop`。保存は `S.scoop = { inv, rep, weak, plan, found:{ 種類:数 }, readNo }`、手がかりは新聞の記事(`art.lead`)に持つ
- 相手監督の新しい布陣への対策は、その試合だけ相手監督の性格を「頑固(自分たちのやり方を最後まで貫く)」にする(後半の布陣の変更をしない)
- 伝説の OB に会うと `S.obSeed = true`(課題13で使う)
