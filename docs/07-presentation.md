## 7. 見た目と体験の設計(筐体らしさ)

**見本として、タイトル・対戦カード・試合(スコア帯・ゴール演出・音)・結果・カード排出を実装した(§7.7)。** 監督室など残りは、見本の雰囲気が合ってから広げる。決めることは §7.6。

### 7.1 いま何が「ただのブラウザアプリ」に見せているか

| いま | 筐体(WCCF) |
|---|---|
| クラブハウスが**縦に長い1枚のページ**。練習も選手一覧も順位表も設定も同じ画面に並び、スクロールして読む | **1画面に1つのこと**。画面は切り替わるもので、スクロールしない |
| 押すと**その場で表示が書き換わる**だけ | 場面が変わるたびに**演出**が入る(場所の移動、対戦カード、入場、結果、排出) |
| 文字と表が主役。角丸のカードと細い罫線 | 絵と大きな数字が主役。金属・ガラスの質感、斜体の太い見出し、金の縁 |
| 音が無い | 笛・歓声・ボタン音・実況が鳴り続けている |
| 試合は「記号が動く図」と1行の文字 | 中継風の画面(スコア帯・時計・実況の字幕・ゴールのリプレイ) |
| カードは色の付いた四角 | カードそのものが主役。払い出しは1試合のご褒美 |

**直すのは色や角丸ではなく、まず「画面の進み方」。** 見た目はその上に乗せる。

### 7.2 場面の流れ(1プレイ = 筐体の1クレジット)

スクロールする1枚のページをやめ、**全画面の場面を順に進む**形にする。戻る・寄り道は監督室からだけ。

```
 タイトル ─▶ 監督室 ─▶ ①練習 ─▶ ②コミュニケーション ─▶ ③対戦カード ─▶ 試合 ─▶ 結果 ─▶ ロッカールーム ─▶ カード排出 ─┐
               ▲                                                                                  │
               └──────────────────────────────────────────────────────────────────────────────────┘
```

| 場面 | 中身 | 演出 |
|---|---|---|
| **タイトル** | ロゴ・「TOUCH TO START」・続きの任期と試合数 | ロゴの光、スタジアムの環境音 |
| **監督室**(ハブ) | 次の試合の札が中央。周りに 選手 / カード / 日程と順位 / 記録 / 設定 の入口 | 秘書役の一言(状況に応じた案内。本家の秘書にあたる) |
| **①練習**(グラウンド) | 強度 → メニュー6枚。選ぶと練習の短い場面 → 伸びた能力の帯 | メニューは札を並べる。結果はゲージが伸びる |
| **②コミュニケーション** | 場所を選ぶ: グラウンド(個人練習)/ ミーティングルーム / ラウンジ / ロッカールーム(声かけ)。残り回数は札で見せる | 場所ごとに背景が変わる。3択は会話の吹き出しで出す。大成功・成功・失敗は大きく |
| **③対戦カード** | 大会名 → 両クラブの名前・エンブレム・KP・戦力グラフを左右から | 「VS」のカットイン、歓声 |
| **試合前** | 盤面にカードが並んだ状態(いまのキックオフ前)。スタメン発表を1人ずつ | 入場の音、笛 |
| **試合** | §7.4 | |
| **結果** | スコア → 得点者 → チームの数字 → 自チームの採点 → MVP(§7.12) | 勝敗で音と色を変える |
| **ロッカールーム** | 秘書のまとめ + 目立った選手1〜2人の一言 + 育成の結果(§7.12)。**大会を優勝したらトロフィーの撮影**に代わる | 覚醒・黄金線は光る行と音 |
| **カード排出** | 裏向きのカードが出る → めくる → レアリティに応じた光 | 筐体の払い出し口を模した動き。キラ・レジェンドは演出を変える |
| **任期終了** | 称号の発表 → 年俸 → ついてくる選手 | 式典風 |

- 選手・カード・日程・記録は**監督室から開く別の場面**にする(いまのページの下半分を分ける)
- 各場面は**画面1枚に収める**。収まらない一覧(コレクション・日程)だけ、その場面の中で横にめくる

### 7.3 見た目の決まり

| | 案 |
|---|---|
| 基調 | 濃紺〜黒の地に、**金**(決定・主役)と**シアン**(情報)。芝の緑は試合と盤面だけ |
| 質感 | 金属の縁・ガラスの板・斜めに切った帯。平らな角丸の箱をやめる |
| 文字 | 見出しは**斜体の極太**(英数字は幅の狭い書体)。数字は大きく、ラベルは小さく |
| 動き | 場面の切り替えは帯が横切る。数字はカウントアップ。押したら必ず光と音が返る |
| カード | 実物の比率(縦長)。上に名前の帯、中央に絵の枠(仮のシルエット)、下に6能力のレーダーかバー。レアリティは 白 / 黒 / キラ(ホロの光が動く)/ レジェンド(金) |
| 盤面 | フェルトの質感の緑。カードは実物の見た目のまま縮めたもの。置くと影が落ちる |
| 向き | 縦持ちのまま。上 = モニター / 下 = パネル の構成は変えない |

| | 案 |
|---|---|

### 7.5 音

Web Audio で**その場で合成する**(音声ファイルを持たない。単一ファイル・オフラインのまま)。

| 種類 | 内容 |
|---|---|
| 環境音 | スタジアムのざわめき(ノイズを加工)。攻め込むと大きくなる |
| 効果音 | 笛(開始・反則・終了)、キック、ゴールの歓声、ボタン、決定、カードをめくる、ファンファーレ |
| 音楽 | 当面は入れない(合成では安っぽくなる)。入れるなら素材を用意して後から |
| 設定 | 音のオン/オフ。スマホは最初のタップまで鳴らせないので、タイトルの「TOUCH TO START」で始める |

### 7.8 テーマとカードの意匠(2026-11-17)

**目標の水準: 後期の筐体と、その後継のスマホ版。印刷物としてのサッカーカードの洗練を取り入れる。**
各社のロゴや具体的なカードのデザインは写さず、「印刷物らしさ」の要素だけを独自に組み直す。

#### テーマ

色はすべてトークン(`--t-*`)を通す(`src/css/theme.css`)。**テーマを足すときはトークンの組を1つ増やすだけ。**
設定・データからいつでも切り替えられる。

| テーマ | 主 | 副 | 差し色 |
|---|---|---|---|
| **ホワイト × レッド**(既定) | 白(紙の白 #f2efe9) | 赤 #c8102e | 金 #b8892c / 黒 #141414 |
| ネイビー × ゴールド | 濃紺 | 金 | — (最初の見た目) |

#### 意匠の決まり

| 要素 | 使い方 |
|---|---|
| **斜めに切った帯** | 見出しの帯・ボタン・名前のリボン・場面の背景。水平な箱をなるべく使わない |
| **網点(ハーフトーン)** | 場面の背景の端・カードの人物の地 |
| **細い罫線** | カードの内側の枠、見出しの上の赤い短い線 |
| **幅の狭い太い数字** | Oswald(SIL Open Font License。英数字だけを埋め込む。日本語はシステムの書体) |
| **箔** | キラ = 虹色が流れる / レジェンド = 金の地に細い斜線 + 光が流れる |
| **影の落ち** | 大きな英字(WCC_F・VS・WIN・GOAL!)は黒か金の影を斜めにずらす |

#### カード

| 部位 | 中身 |
|---|---|
| 斜めの色帯 | クラブの色。帯の右に白と色の細い線を重ねる |
| 人物 | 網点の地に、汎用の上半身の影(独自に描いたもの。絵は後で差し替え) |
| 左上 | 背番号(大きな数字)と役割 |
| 右上 | レアリティの刻印を縦書き(BASE / PREMIUM / FOIL / LEGEND) |
| 名前のリボン | 赤(レジェンドは黒に金の文字)。下にクラブ名 |
| 右 | 得意な能力3つ(中のサイズ以上) |
| 下 | スキル名と KP スタイル |

| レアリティ | 台紙 |
|---|---|
| 白(BASE) | 白い台紙 |
| 黒(PREMIUM) | 黒い台紙に銀の罫 |
| キラ(FOIL) | 白い台紙に虹色の箔が流れる。枠も虹色 |
| レジェンド | 金の箔の台紙(細い斜線)、黒いリボン、光が流れる |

カードの裏(排出の場面)は、赤に白の細い斜線と WCC_F の印。

#### まだ直していないところ

- 監督室は色と質感だけ新しいテーマに合わせた。**1画面1つの場面に分ける作業(§7.2)はまだ**
- 試合の映像(俯瞰の2D)の選手の丸と芝は元のまま
- カードの絵(人物)は仮の影

### 7.9 監督室の構成(2026-11-17)

**縦に長い1枚のページをやめ、HOME をハブにして、下のタブで行き来する。** pftb の HOME の考え方を取り入れた。

```
 HOME ─ 次の試合のタイル(全体が押す面)─▶ 準備の手順(全画面。タブを隠す)
   │                                       ① チーム練習 → ② コミュニケーション(最大3回)→ 試合へ
   │                                       → 対戦カード → 試合 → 結果 → カード排出 → HOME
 下のタブ: HOME / SQUAD(登録選手・戦力グラフ)/ CARDS(コレクション)/ SEASON(順位・大会)/ CLUB(記録・歴代・設定)
```

| 画面 | 置くもの | 置かないもの |
|---|---|---|
| **HOME** | 見出し(クラブ・任期・施設・称号・試合数・賞金)/ **次の試合のタイル** / 秘書の一言 / 前の試合の要約(スコア・出たカード・主な出来事3行) | 練習・名簿・順位表・設定 |
| **準備の手順** | 上に「×」と手順の印(①②③)、対戦相手の1行 / 中に今の手順 / 下に「試合へ」と「棄権」 | タブ(手順の途中で寄り道させない) |
| SQUAD | 登録選手(★・やる気・疲労。2行タップで先発と控えを入れ替え)/ 戦力グラフ / 連携の本数 | |
| CARDS | コレクション・詳細・登録の入れ替え。**持っているカードを全部並べ、登録中のカードには「登録中」の印**(並べ替えはレア順・No.順・合計順) | |
| SEASON | リーグの順位表 / 大会の出場状況 | |
| CLUB | この任期の記録 / 歴代 / 設定・データ | |

pftb から取り込んだ決まり:

- **タイルが押せるなら、中にボタンを置かない**。行き先は右下に文字だけ(`› 準備をはじめる`)
- **試合を始める入口は1つだけ**(準備の手順の「試合へ」)
- **VS は中央に固定**(`grid-template-columns:1fr auto 1fr`)。クラブ名の長さで中心がずれない
- **秘書は次の一手を示す**。状況から1つ選ぶ(兆しのあるフレンドリー / コミュニケーションの残り / 疲労 / 「！」の選手 / 決勝 / 初回)
- **煽りは状況から選び、同じ試合なら毎回同じ文**(格上への挑戦・決勝・最終節・負ければ終わり など)

- 「！」の印は**★突破の話がある・やる気が絶不調**のときだけ。疲労では付けない(練習のたびに全員に付いて意味が無くなった)
- 手順の途中で「×」を押して HOME に戻っても、進み具合は保つ(タイルの文字が「準備のつづき」になる)

### 7.10 SQUAD = 既定の陣形(2026-11-17)

試合の盤面と同じ考え方で、**縦のピッチ(自陣が下)に先発11人を陣形どおりに並べる**画面。
ねらいは2つ: 試合前に毎回並べ直す手間をなくすこと、連携(とくに黄金線)を目で確かめられること。

- **ここで決めた並びと KP が「既定」**。毎試合この配置から始まる。試合中に動かした位置・替えた KP は**その試合だけ**(結果の反映で上書きしない)
- 陣形の選択(4-3-3 / 4-4-2 / 4-2-3-1 / 3-5-2)で、先発の並び順(枠の順。先頭が GK)どおりに一括で置き直す。陣形はセーブの `form`
- **ドラッグで動かす**と、置いた場所の役割と適性がその場で変わる(色: 緑=得意 / 金=同じ系統 / 赤=不向き)。置ける範囲は試合の盤面と同じ(GK はエリアの中)
- **2人をタップで入れ替え**。控えとも入れ替えられ、入った人が出た人の位置に立つ。KP が控えに下がったら、入った人が KP を引き継ぐ
- 選んだ選手の板: 役割と適性・★・特殊・やる気・疲労・スキル。**「KP にする」**はここから
- 連携の線: 薄線(細い白)・太線(太い白)・黄金線(金・光る)。黄金線の兆しは金の点線を重ねる
- KP は先発にしか置けない。古いセーブで控えにいたら、クラブの既定(いなければ最前線の人)に戻す

### 7.11 試合画面 = 筐体の配置(2026-11-18)

本家の筐体と同じ並び(上にモニター、手前にカードを置く縦の盤面、左の台に十字の戦術ボタン、右の台に SHOOT と KEEPER)。
まず基本形で作り、スマホ向けの詰めはあとで行う。

- **モニター**(上): 試合の映像は横向きのまま(テレビ中継の見え方)。高さは 110〜160px(画面の高さの 19%)
- **盤面**(中): **縦向き。下が自陣ゴール、上が敵陣ゴール、左サイドが左**。SQUAD の盤面と同じ向き。
  右に控えのカードを縦一列に置く(控えを盤面のカードに重ねると交代)。座標は `board.js` の `bdPos` / `bdInv`
- **操作の台**(下): 左に十字(上 = 中央突破・左右 = サイド・下 = カウンター・中央 = プレス。→docs/04 §4.9b)、
  真ん中に KP・再生・速さ・交代の数、右に丸い **SHOOT**(赤)と **KEEPER**(青)
- 十字とキーパーはどれも同時に点けられ、点いているものは光る

#### 触り心地(2026-11-18、スマホで触った指摘から)

- SQUAD のカードは試合の盤面のカードと同じ作り: 上の帯 = ポジションの色(GK 黄・DF 青・MF 緑・FW 赤)、役割の文字の色 = 適性(白 得意 / 黄 同じ系統 / 赤み 不向き)
- **カードの詳細は長押し**で、盤面の上にカードの裏として開く(モニターは隠さない)。タップは KP を選ぶときだけ
- 動かしている盤面のカードは、指より 34px 上に出す(指で隠れない)
- **控えをつまむと、指の上に浮いたカードが付いてくる**。重ねた相手が光り、帯に「離すと交代: OUT → IN」が出る
- **交代は確認を挟む**(交代する / やめる)。確認の間は試合を止め、答えたら元に戻す
- 倍速は上部(スコアの右)へ。操作の台は筐体の意匠: 黒い天板に黄色い十字と赤い中央、赤い SHOOT と青い KEEPER の丸ボタン

#### 画面の大きさに合わせる(2026-11-18)

- 盤面と控えのカードは、**盤面の高さに合わせて縮める・広げる**(`board.js` の `fitBoard` が CSS の `--k` を決める。
  盤面の高さ ÷ 400px を 0.7〜1.12 に収める。数値は `TUNING.play` の `cardRef` / `cardMin` / `cardMax`)。小さい機種でもカードが重ならず、控えの5枚が収まる
- 背の低い画面(高さ 700px 以下)では、モニターの高さを少し抑える
- 確かめた大きさ: 360×640(小さい Android)/ 375×667(iPhone SE)/ 390×780 / 412×915(大きい Android)
- 端の余白(ノッチ・ホームバー)、拡大・引っ張って更新・長押しのメニューを止める設定は前から入っている

### 7.12 試合のあと: 結果 → ロッカールーム → カード(2026-11-18)

本家の順(→docs/08 §8.11)に合わせ、結果と育成とカードを別の場面に分けた。

- **結果**(`scenes.js` の `sceneResult`)
  - スコア・得点者に加えて、**チームの数字**(シュート・枠内・支配率・パス成功率)と**自チームの採点**を出す
  - 採点は 10点満点・0.5刻み。`engine.js` の `matchRatings` が**試合の記録(イベント)だけから**数える。
    6.0 から、得点・アシスト・枠内・通したパス・奪った・止めた を足し、奪われた・失点(GK・DF)・反則を引き、勝てば +0.3・負ければ −0.3。
    数値は `TUNING.rate`。MVP は採点がいちばん高い選手(同点なら得点・勝った側)
  - アシストは得点のイベントに `as` として記録する(記録だけで、判定には使わない)
  - 実測(200試合): 平均 6.43、8.0以上 6.5%、MVP の 88% が得点者(`enginetest.js` の ⑨)
- **ロッカールーム**(`sceneLocker`)
  - 秘書が試合をまとめ、大会の進み具合・賞金を添える
  - 話す選手は最大2人。育成の知らせの重い順(覚醒 → ★5 → 黄金線 → 覚醒の兆し → ★ → 連携)、足りなければ自チームでいちばん採点の高い選手。
    知らせは `grow.js` の `newsOf` が試合のあとだけ集め、`S.last.news` に残す
  - 吹き出しで話した知らせ以外の育成の行は、下にまとめて出す
- **優勝の撮影**(`sceneTrophy`): 大会の優勝すべてで、ロッカールームの代わりに出す。トロフィーと出ていた選手の名前、フラッシュが2回
- **カード**(`sceneCard`)
  - レアリティは台紙・枠・箔で見分ける: REGULAR 白い紙と灰の細い枠 / SPECIAL 黒い紙と銀の枠 / WORLD CLASS 虹色の紙と虹の太い枠・流れる箔 / LEGENDS 金の紙と金の二重枠・光の筋
  - **めくる前の予兆**(本家にはない wcc_f の演出): 裏の後ろの光がレア度どおりに光る(REGULAR なし / SPECIAL 銀 / WORLD CLASS 虹が回る / LEGENDS 金の光の筋で、カードが震える)。
    `TUNING.pack.promo` の割合で一段下の光り方から始まり、1.3秒で本来の光り方へ**昇格**する(先にめくっても昇格してから開く)
- **ゴールのリプレイ**(`main.js` の `stepReplay`): ゴールの間のあと、**得点までのボールの動き(同じチームが持っていた直近5手)を半分の速さで**モニターに描き直す。
  「REPLAY」の札を押せば飛ばせる。倍速のときは流さない。流している間は試合は進まない(記録を描き直すだけ)。数値は `TUNING.play` の `replay*`

#### 試合の区切り・映像の立体化(2026-11-18、スマホで触った指摘から)

- **試合の区切りはダイアログにしない**。モニターの中に中継の字幕(KICK OFF / HALF TIME / FULL TIME)を出し、**数秒で自動で進む**(本家と同じく強制。
  キックオフ前 3.2秒・ハーフタイム 4.2秒・試合終了 2.4秒。`TUNING.play` の `capKick` / `capHalf` / `capEnd`)。字幕のあいだ試合は止まり、盤面のカードは触れる
- 試合終了の字幕のあとは結果の場面へ(結果・スタッツはそちらで出すので、ここでは出さない)。練習試合(?quick=1)は次の試合へ
- **一時停止ボタンはなくした**(ゲーム性を変えてしまうため)
- 対戦カードの場面は画面の高さの中央にそろえた
- **試合映像を大きく**(画面の高さの 28%、背の低い画面は 25%)。盤面のカードは残りの高さに合わせて縮む(fitBoard)
- **映像は立体**(`render.js`): テレビ中継のように斜め上の横から見た遠近(奥のタッチラインは手前の 0.62倍)。選手は地面に立つ紙の板(チームの色・背番号・縁の厚み・足元の影)で、
  奥から順に描くので手前の選手が重なる。ゴールに高さ、奥にスタンドと観客(高さはスタジアムの段)、看板にはスポンサーの名前。数値は `TUNING.view`。
  外部のライブラリは使わず canvas で描く(RPG Paper Maker はパソコン用の制作ソフトで、ページに組み込めないため)
