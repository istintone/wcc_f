# 27. エンブレムエディターの作り直し(2026-11-26。合意して実装中)

オーナーとの相談のための設計。27.10 の答えは 27.11 に。

## 27.1 目標

- 実在のクラブを想定して、そのエンブレムに寄せたものを作れるエディターにする
- ただし、ゲームの本体(公開する版)には実在クラブのエンブレムを入れない。作るのはプレイヤー本人。実名と同じく、実在に寄せたプリセットを用意するなら、手元だけのパック(`packs/*.local.json`。公開しない)に入れる

## 27.2 今のエディターと限界

| 項目 | 今 | 限界 |
|---|---|---|
| 形 | 盾・丸・楕円・尖り・旗の5つから1つ | 形の数は足りるが、縁の太さ・二重縁を選べない |
| 地の柄 | 無地・縦縞・半分・四分割・たすき・横縞・山形・十字・斜め十字の9つ | 縞の本数・太さを選べない |
| 紋章 | 星・王冠・鷲・獅子・馬・兜・竜・百合・大砲・グリフォン・ワイバーン・アテナから **1つだけ**。紋章を置くと文字は消える | 紋章を複数並べられない。文字と一緒に置けない |
| 文字 | クラブ略称の頭 **2文字に固定**。並べ方は横・縦・斜めの3パターン | 文字を自由に入れられない。3文字にできない。位置を動かせない |
| 外装 | 王冠・月桂樹・リボン・冠と月桂樹とリボンの4つから1つ | リボンに文字が入らない。上下に置けない。月桂樹の絵が粗い |
| 色 | 地・柄・紋章と文字の3色 | 同じ色が重なると境目が消える(縁取りが地の色の明暗で決まり、重なりを見ていない) |

## 27.3 方針

1. **パーツを重ねる作りにする**: エンブレムを「盾(形・地の柄・縁)」の上に、パーツ(紋章・文字・リボン・外装)を最大6つまで重ねる形にする。パーツごとに位置・大きさ・色を変えられる
2. **文字を自由に**: 英字・数字・記号(& . ')で最大4文字。字体を3種から選ぶ。位置と大きさを動かせる。円弧に沿わせることもできる
3. **リボンに名前を**: リボンにクラブ名や略称を入れる。盾の上・下・中央に置け、上下に2本も置ける
4. **重なっても読める縁取り**: パーツの縁取りの色を、下にある色との差で自動で決める。同じ色どうしが重なっても境目が見える
5. **月桂樹を描き直す**: 葉の形・並び・陰影を作り直す

## 27.4 データの形(新しい作り)

```
emblem = {
  v: 2,
  shape: "shield",            // 盾の形(今の5つ + 足すもの)
  field: "stripe", n: 5,      // 地の柄と、縞などの本数
  home: "#E11B22", away: "#F2F2EF", third: "#1A1A1E",   // 3色(第3色は縁や文字に)
  rim: "double",              // 縁: 細い / 太い / 二重
  parts: [                    // 下から順に重ねる(最大6)
    { t:"crest", k:"lion", x:50, y:45, s:1.0, c:"third" },
    { t:"text",  s:"MUF", font:"serif", x:50, y:78, size:22, c:"away", arc:0 },
    { t:"ribbon", pos:"top",    s:"MANCHESTER", c:"away", ink:"home" },
    { t:"ribbon", pos:"bottom", s:"UNITED",     c:"away", ink:"home" },
    { t:"orn", k:"laurel" }
  ]
}
```

- 位置 x・y は盾の中の 0〜100、大きさ s は倍率
- 色は "home" / "away" / "third" の3色から選ぶ(盾の配色を変えれば全体がそろって変わる)。金・白・黒も選べる
- 今のデータ(v なし)は、読み込むときに新しい形へ直す(紋章 or 文字 → パーツ1つ、外装 → orn)。CPU のクラブは今までどおり名前から自動で作る

## 27.5 パーツの中身

| パーツ | 中身 | 新しく足すもの |
|---|---|---|
| 紋章(crest) | 今の12種 | 複数置ける。大きさ・位置・左右反転。足す候補: 船・城・樹・ボール・鍵・十字・錨・薔薇(どれも輪郭で語る意匠で描く。前に剣・稲妻・塔・ボールを「幾何で組んだ形は浮く」として外したので、描き方をそろえる) |
| 文字(text) | 自由な1〜4文字 | 字体3種(セリフ / 太いゴシック / スラブ)。大きさ・位置。円弧(上向き・下向き) |
| リボン(ribbon) | 盾の上・下・中央に横断 | クラブ名・略称など最大12文字。上下に2本まで。リボンの両端の切り込み・巻き込みの立体 |
| 外装(orn) | 王冠・月桂樹・星(1〜5個) | 月桂樹の描き直し。星の数・並び(上に弧を描く) |

## 27.6 縁取り(重なっても境目が見える)

- 文字・紋章・リボンの文字には、**内側に濃い縁、外側に明るい縁の二重の縁取り**を付ける
- 縁の色は、そのパーツの色と「真下にある色(地・柄・下のパーツ)」の明るさの差で決める。差が小さいとき(同じ色どうし)は、縁を太く・濃くする
- 盾の縁(rim)も、地の色と同じ明るさなら、自動で一段明るい / 暗い色にする

## 27.7 月桂樹の描き直し

- 今: 楕円の葉を円弧に並べただけで、粗く見える
- 新しく: 葉は「先が尖り、中央に葉脈の筋がある」形を手で描いたパス1つを使い回す。茎に沿って、外側と内側に互い違いに付け、先に行くほど小さくする。下で2本の枝が交差し、リボンで結ぶ。金の2色(明・暗)で葉の表と陰を分ける
- 小さく(30px)表示しても潰れないよう、葉の数は片側 9 枚程度に抑える

## 27.8 エディターの画面

- **上**: 大きなプレビュー(画面幅いっぱい)。パーツを指でドラッグして動かせる。2本指で大きさを変える(無理なら下の「大きさ」で)
- **中**: タブで「盾」「パーツ」「色」を切り替える
  - 盾: 形・地の柄・本数・縁
  - パーツ: 重ねたパーツの一覧(並べ替え・削除)と「+ 紋章」「+ 文字」「+ リボン」「+ 外装」。選んだパーツの設定(種類・文字・字体・大きさ・色・円弧・反転)
  - 色: 3色を選ぶ(今の色見本 + 自由な色)
- **下**: 「テンプレート」から始められる(例:「盾に紋章と上下のリボン」「丸い縁に文字を円弧で」「縦縞の盾に頭文字」)。どれも架空の組み合わせで、実在のクラブをそのまま再現したものにはしない
- 文字の入力は、英字の小さなキーボード(A〜Z・0〜9・記号)を画面に出す(スマホの入力で日本語が混ざらないように)

## 27.9 進め方(案)

1. データと描画: パーツを重ねる形・文字(最大4文字・字体・位置)・リボンの文字・縁取り。今のデータからの移し替え
2. エディターの画面: タブ・パーツの一覧・ドラッグ・テンプレート
3. 絵: 月桂樹の描き直し・紋章を足す・形と縁を足す
4. (希望があれば)手元だけのパックに、実在クラブに寄せたエンブレムを入れられるようにする

## 27.10 決めてほしいこと

1. **「スクテッドのように」の意味**: 盾をいくつかに区切って、区画ごとに別の紋章を置く(紋章学の分割盾)の意味でよいか。それとも、イタリアの優勝の印(スクデット)のような盾の形のことか
2. **パーツの数**: 最大6つでよいか(多いと小さく表示したときに潰れる)
3. **文字**: 最大4文字・英数字と記号だけでよいか。日本語(カタカナ)も入れたいか
4. **リボンの文字**: クラブ名(英字)で最大12文字程度でよいか
5. **動かし方**: 指でドラッグして自由に動かす形でよいか(細かい位置合わせは、上下左右の矢印でも少しずつ動かせるようにする)
6. **実在クラブに寄せたエンブレム**: プレイヤーが自分で作るだけでよいか。それとも、手元だけのパックにこちらで用意しておくか(用意する場合も、公開する版には入れない)
7. **新しい紋章**: 27.5 の候補(船・城・樹・ボール・鍵・十字・錨・薔薇)で足りるか。欲しいモチーフがあれば

## 27.11 オーナーの答え(2026-11-26)

1. 分割盾の意味でよい
2. パーツは最大6つ
3. 文字は英字と記号
4. リボンの文字も英字で最大12文字
5. 自由に動かす形。矢印で微調整も。一般的なゲームのエディタと同じようなふるまい
6. 実在クラブに寄せたエンブレムは、今のゲームに入れてほしい。素材が違い完全一致はしないので、モチーフ元が伝わる程度に似せる
   - → 相談中: 公開する版には実在のロゴを入れない決まりがあるため、公開する版は「モチーフのヒント」(色・紋章の種類・リボンの有無)まで、似せたエンブレムは手元の実名パック(packs/*.local.json)に入れ、実名パックで遊ぶときだけ切り替わる形を提案
7. 候補の紋章で足りる。ただし細かさ・曲線の質は今の竜などと同じであること。外部のイラストを描ける AI やツールに任せてもよい。質が悪ければ使わないこともある

## 27.12 実装(段階1・2。2026-11-26)

- 描画(emblem.js): `embSvg` をパーツを重ねる描き方にした。旧い形は `embParts` がパーツの並びに読み替えるので、CPU のクラブもこの描き方で描く
  - 紋章: 位置・大きさ・左右反転。文字: 英字・記号 4字、字体3種(セリフ・ゴシック・スラブ)、位置・大きさ・円弧(上に反る / 下に反る)。リボン: 上・中央・下、名前 12字を帯の中心線に沿って、両端は折り返しと V の切り込み。外装: 王冠・月桂樹・星(1〜5)
  - 縁取り: 紋章と文字は二重の縁(明るい色には暗い内縁と白い外縁、暗い色には逆)。盾の縁は 細い・ふつう・太い・二重
  - 地の柄: 縦縞・横縞の本数(3・5・7・9)
  - 月桂樹を描き直した(先の尖った葉に葉脈と明るい面、外側・内側に互い違い、先ほど小さく、下で交差して結び目)
- エディター(clubui.js `emblemEditorHtml` / `eeAct` / `eeBindDrag`): 大きなプレビュー(選んだパーツを指でドラッグ)、矢印と − + で微調整、タブ(パーツ / 盾 / 色)、パーツの一覧(選ぶ・奥へ・手前へ・消す)、＋紋章・＋文字・＋リボン・＋外装、パーツごとの設定、画面の英字キーボード、テンプレート4つ(架空の組み合わせ)
- まだ: 新しい紋章8種の絵(外部の絵を用意してもらい、今の竜などと同じ輪郭追跡で取り込む)・実在クラブに寄せたエンブレムの置き場所(上の相談)・小さく表示したときの見え方の確認
