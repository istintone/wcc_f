# 8. 本家の仕様の確認(2026-11-18)

4人の精査(アートディレクター・ゲームプランナー・WCCFファン・Webエンジニア)で「要確認」になった本家の仕様を、
ユーザーに1つずつ確かめた結果。**ここに書いたことが本家由来の要素の正本**。実装したら各設計文書(docs/02・04・05・06・07)へ写す。

## 8.1 方針

- **任期は100試合のまま**。育成・黄金線の釣り合いは100試合を基準に取る。短い任期の選択肢は作らない
  - 理由: 獲得した称号のコレクションは、将来の対人戦で相手の強さを測る指標になる(エンドコンテンツの土台)
- 本家の仕様は記憶で組まず、確かめてから入れる(この文書がその記録)

## 8.2 戦術ボタン(初期の十字の5つ + キーパー)

| 位置 | ボタン | 効き方 |
|---|---|---|
| 上 | 中央突破 | 真ん中へのパスとドリブルが増える。外へは開かない |
| 左・右 | サイド攻撃 | その側へボールが集まり、クロスが増える。左右両方を点けると幅を使う |
| 下 | カウンター | 守るときは深く構え、奪ったら速く前へ蹴る(長いパス・裏へのボール) |
| 中央 | プレス | ボールを持った相手に寄せて奪いに行く。疲れやすい |
| 別 | キーパー | 点けている間、GK が高い位置を取り、裏へのボールの処理に加わる。そのぶんスタミナが減りやすい |

- どれも同時に点けられる
- いまの「ラインを上げる・下げる」はやめ、カードを動かして位置で示す
- 本家のキーパーボタンは「押し続けている間、ボールに向かって飛び出す」。そのまま入れるとタイミングだけの遊びになるので、点けっぱなしの指示に置き換える(ユーザーの提案)

## 8.3 ミーティング

- **1人を呼ぶが、周りにも効く**。答えの結果はその選手に強く、周りの選手(仲のよい選手など)にも少し効く
- 対応が期待と合えば信頼度と調子が上がり、外れると下がる(ユーザーの記憶)
- wcc_f の作り(2026-11-18): 周り = ①呼んだ選手と連携のある登録選手(太い順)②先発なら SQUAD の盤面で近い先発。合わせて3人まで。周りには特殊能力の経験が少し入り、★突破が成功するとやる気が上がることがあり、失敗すると下がることがある(`grow.js` の `meetNear`、数値は `TUNING.grow.sp.near`)

## 8.4 控えのやる気

- **下がるが、ゆるやか**。出番が続けて無いと不満がたまって下がる。声かけや出場で戻る。放っておいても普通へ戻る力がある

## 8.5 覚醒・黄金線の時期(育成の釣り合いの基準)

- **1人あたり5〜10試合ぶんの集中育成で覚醒に届く**。集中させるかどうかで個人差が大きい
- 育成に関わらなかった選手は、後半に連携が白の太線まで行くが、覚醒は★なしのまま
- 任期の途中では、集中的に育てた3人ほどが個人・特殊の両方で★5まで覚醒する
- 100試合近くになるとほかの選手も呼ぶので、★0〜4がまばらにいる程度まで育つ
- 黄金線は狙って育てたものだけ

## 8.6 連携が付きやすくなるボーナス

- **同じ国籍・同じクラブ・動物占いの一致**で、それぞれ連携が付きやすくなる
- 国籍・生年月日は実在のデータを使う。分からない選手は疑似的なものに置き換える
  - 生年月日は実名側(`tools/squads.local.txt` と実名パック。Git管理外)に置く。本体には生年月日から出した動物と国籍だけを載せる
- 動物占いは、当時のプレイヤーが「相性のいい選手をあぶり出す手法」として好んだもの。再現する
  - **生年月日から逆引きできる**決まりで動物を出し、動物どうしの相性で連携のボーナスを決める。決まりの設計は任されている(既存の占いの表は写さず、独自に作る)
- wcc_f の作り(2026-11-18): docs/05 §5.5

## 8.7 秘書

- **選べる秘書 + 信頼度**。口調の違う秘書を数人から選ぶ。信頼度が上がると報告が詳しくなる(相手の分析・ケガの兆しなど)
- 本家の秘書(ユーザーの補足、2026-11-18):
  - **コミュニケーションのフォロー**: 選手とのコミュニケーション(特別指導など)に失敗したとき、秘書がフォローに入って選手のモチベーションを戻してくれる
  - **親密度でフォローが起きやすくなる**: プレイ(ログイン)や突発イベントで親密度が上がる
  - **能力差はない**: 秘書によって得意な選手や能力の違いはなく、好みで選ぶ。本家では配布の「秘書カード(EXTRA カード)」で特定の秘書を出せた
  - 直接の効果は小さいが、ゲーム全体で**監督を誘導し、世界観を演出する**語りの役
- wcc_f の作り: docs/05 §5.12

## 8.8 ケガ

- **たまに起き、数試合出られない**。疲労がたまると起きやすい。秘書が兆しを知らせる
- **試合の中で判定**される。試合のあと、確率でケガが治るか続くかが決まる。ふつうは **1〜3試合で治る**
- 試合の中でケガをした選手は、**ピッチに残り、能力が落ちる**。交代させるかは監督が決める
- ケガが続いている選手は、本家では次の試合に出せなかった。**wcc_f では出せるが能力が落ちる**ことにし、監督が自分で入れ替えるのを期待する。秘書がヒントとして交代を促す
- **個別の声かけ(コンディションの改善)で早く治せる**
- 「声かけ」は分かりにくいので、**選択肢の名前を「ケア」に変える**(ユーザーの要望)

## 8.9 資金(スポンサーとスタジアム)

- **任期の始めにスポンサーが決まる**。スポンサーには指令が付いていて、達成するとクラブ資金が入る
- カップ戦の賞金が加わり、一定に達すると「クラブ増強イベント」が起きる
- スタジアム改修(ユーザーの補足):
  - **起きる時**: 試合前のマネージメント中のイベント。一定の資金がたまったとき、タイトル獲得・昇格などで突発的に
  - **選択**: 提示された費用を払って実行するか、見送るかを選ぶ
  - **効果**: 収容人数が増える → 観客動員が伸びる → 入場料収入が上がる。外観が小さな地方スタジアムから屋根付きの大きなスタジアムへ変わっていく。クラブの格(ファン数)が上がり、ファン増加とスポンサー収入の好循環になる
- スポンサー(ユーザーの補足、2026-11-18):
  - **いくつかの候補から選ぶ**。クラブの立ち上げ時と任期の更新時に、架空の企業と契約する
  - 契約中は試合のあとに、基本の賞金とは別に**スポンサー収入**が入る。企業の格が高いほど1試合あたりが大きい
  - 契約した企業のロゴが**ユニフォームの胸**に入る
  - 最初は小さい企業(地域の商店・地元の運送会社・中小メーカー)から。成績に応じて大きな企業からオファーが届く:
    中(全国の飲料メーカー・アパレル・IT。リーグ昇格やカップ優勝を重ねる)/ 高(業界一の大手・グローバル企業。トップリーグ優勝や国際タイトルが要る)
  - 契約を替えるのは主にリーグの終わりと任期の更新時
  - 後期(16-17〜17-18)の**スポンサーミッション**: 企業ごとに「◯試合以内に◯勝」「無失点試合」「特定の大会で優勝」などの条件。
    達成すると賞金に加えて、確率で**育成・覚醒用のアイテム**(ゴールデンシューズなど)がもらえる。どの企業がアイテムをくれやすいかで選ぶ人も多かった
  - 資金の使い道: 監督ランクの上昇(年俸・評価)、クラブハウスの施設拡張、練習メニューの解放など

## 8.10 カードのレアリティ

- 本家(16-17)の呼び方: 白 = **レギュラー**、黒 = **スペシャル**、キラは種類が多く、その中に現役選手とレジェンドがある。現役キラ・レジェンドキラにはシーズンごとの子カテゴリがある(例: 16-17 の WORLD CLASS は位置別に WGK・WCB・WSB・WDM・WCM・WOM・WSS・WCF・WSA。ほかに MVP・POY・YGS/RGS・SOC・TBU・SPE、レジェンドは KOLE・HOLE・LEOC・SATLE・ATLE など)
- **wcc_f では REGULAR・SPECIAL・WORLD CLASS・LEGENDS の4つを軸にする**。WORLD CLASS と LEGENDS は、細分化したカテゴリを後から足せる作りにしておく
- 見分けは台紙の色と箔で付ける(4人の精査の合意)

## 8.11 試合のあとの流れ

- 本家の順: **試合結果 + 選手スタッツ・MVP → ロッカールーム**(選手・秘書のコメント、覚醒の知らせ。話すのは**秘書 + 目立った選手1〜2人**)。
  優勝したときは代わりに**トロフィーを掲げるウイニングショットの撮影**(リーグ・カップを問わず**大会の優勝すべて**)。そこでゲームが終わり、筐体から実物のカードが出る
- 結果画面の選手スタッツは、**選手ごとの採点とチームの数字(シュート数・支配率など)の両方**。採点は**10点満点の小数**(6.0・6.5 など)
- ゴールのリプレイ: **ゴールのたびに流れ、ボタンで飛ばせた**
- カードの排出の予兆: **本家にはない**(実物が出てくるので)。wcc_f の演出として決めてよい
- wcc_f では1試合ごとにカードを1枚出すので、**結果 → ロッカールーム(または優勝の撮影)→ カード**の順にする
