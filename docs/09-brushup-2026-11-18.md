# 9. ブラッシュアップ会議(2026-11-18)

テーマは「WCCFらしさはあるか? さらによくするには?」。4つの観点を、それぞれ担当のエージェントが受け持った(ゲーム体験・ビジュアル・UIとデザイン・全体の品質)。
各担当は実際の画面を撮り、コードを読み、Node で長期プレイを回して検証した。リポジトリは読むだけで、書き換えていない。

## 9.1 総評

- **らしい所**(4人の意見がそろった)
  - 1プレイの流れ: 練習 → コミュニケーション → 対戦カード → 試合 → 結果 → ロッカールーム → カード
  - 試合画面の筐体の並び: モニター・縦の盤面・十字・SHOOT/KEEPER
  - 対戦カードと結果の演出
  - 遊びの外側の堅さ: 5任期・500試合で例外0件、セーブは最大18KB、読み込み直しても結果は同じ
- **まだらしくない所**
  - 主役のカードが弱い: 全員が同じ影の絵、名前の帯はいつも赤、小さい表示ではレア度が分かりにくい
  - 育てた手応えが見えにくい: 「！」「兆」や薄線が増えすぎて、印の意味が薄れる
  - 準備の画面が文字の札の一覧になっている
  - 長く遊ぶと、称号とお金の使い道が単調になる

## 9.2 進め方(4段)

| 段 | 中身 |
|---|---|
| 第1弾 | 不具合、十字の点灯、印と知らせの整理、称号の条件、HOME の焦点、準備の画面のボタン、細かい整え(この文書の §9.3) |
| 第2弾 | 育成の手応えを測り直して釣り合いを調整する。盤面のカードに★・やる気・疲労を出す |
| 第3弾 | カードの意匠(帯をクラブの色に・エンブレム・ポジション別のポーズ・台紙)、排出の場面(暗い店内と払い出し口)、準備の画面のカード化 |
| 第4弾 | 長く遊ぶ要素(お金の使い道・維持費・S の大会までの道のりの表示) |

## 9.3 第1弾でやったこと(2026-11-18)

### 不具合

- **裏に回ると、試合が止まったまま戻らない**
  - 戻ったときにモニターへ「中継再開 / TOUCH で再開」の字幕を出し、画面のどこかを触ると再開するようにした
  - 一時停止ボタンは入れていない(ユーザーの決定のまま)。`main.js` の visibilitychange
- **カードの文字の重なり**
  - レア名は右端の細い帯に置いた
  - 能力の列を下げ、スキル名はカードNo. の手前までにした
- **十字の点灯が分からない**
  - 消えているボタンは暗い色(ランプが消えた色)にした
  - 点いたボタンは明るく光り、右上に白いランプが付く。中央のプレスも同じ決まり
- **隠れている間も試合の絵を描き続けている**
  - 監督室や場面が出ている間は描かないようにした
  - 芝・ライン・スタンドは裏のキャンバスに1回だけ描き、使い回す(大きさ・スタジアム・スポンサーが変わったら描き直す)
- **セーブの守り**
  - 保存のたびに、直前のセーブを1つ前の世代(`SAVE_KEY.prev`)に回す。最新が読めなければ、そこから戻して知らせる
  - 読めないセーブの退避は、新しい順に3件まで持つ
  - 秘書やスポンサーを選ぶ画面でも、セーブの異常の知らせが見えるようにした(それまでは見えなかった)

### 印と知らせ

- **練習で入る特殊能力の経験は、★突破の話(！)の手前で止める**
  - 話はミーティングで経験を足して出す
  - それまでは40試合で16人中15人に印が付いていた
- **ロッカールームの「薄線に」の知らせ**は「新しい連携(薄線)が N 組できた」の1行にまとめた

### 称号

- 覚醒工場は「6人以上を覚醒させ、勝ち越した」に変えた(第2弾で8人以上に上げた)
- 負け越した任期には付かない(それまでは負け越しでも付いていた)

### HOME と準備

- **HOME**
  - スポンサーの欄は1行(社名・ミッションの達成数・効いている効果)にし、詳しくは CLUB タブで見る
  - リーグを1周したときの候補は、次の試合の下に「契約を更新できます」の帯としてたたんで出す
  - 見出しの英語を日本語にした: MATCH / FUNDS / FANS → 試合 / 資金 / ファン
- **準備の画面**
  - コミュニケーションが残っている間、「試合へ」は枠線だけのボタンにし、残り回数を添える
  - 使い切ったら、赤いボタンになる
- **チーム練習の強度**: 補足を短くした(折り返さないように)
- **CARDS**: 「登録中」の印は、カードの左下の小さい札にした
- **SEASON**: 出られない大会に、出場の条件を書いた(`clubui.js` の `ENTRY_NEED`)

## 9.3b 第2弾でやったこと(2026-11-18)

- **育成すると強くなるか、測り直した**(clubtest の集中育成の方針。同じ相手=段4のクラブに200試合ずつ。scratchpad の s2/grow_sim.js)

  | 方針 | 試合0 | 25 | 50 | 75 | 100 |
  |---|---|---|---|---|---|
  | 集中して育てる(たね 2026) | −1.28 | −0.65 | −0.84 | −0.61 | **−0.26** |
  | 集中して育てる(たね 7) | −1.28 | −1.11 | −0.78 | −0.83 | **−0.17** |
  | 育てない | −1.28 | −1.2 | −1.9 | −2.2 | −1.3 |

  育てれば、任期の終わりには得失点差が +1.1 ほど良くなる。それでも勝敗が右肩上がりに見えないのは、任期が進むほど相手が強くなる(リーグの格が上がる・上の大会に出る)から。
  問題は**伸びが見えないこと**と判断し、釣り合いの数値は変えなかった
- **称号の数え方**: 覚醒と黄金線は**その任期に起きた数**で数える(`S.ts.awake` / `S.ts.gold`)。それまでは前の任期からついてきた選手の覚醒まで数えていた
- **育った分を盤面で見せる**: SQUAD の駒と試合の盤面のカードに、個人能力の★の札(★5 は虹色)とやる気の点を出す。カードには `growCard` が★とやる気を持たせる(見た目だけで、判定には使わない)
- **チーム力**: HOME の見出しに、先発11人の育成を反映した能力の合計の平均と、任期の始めからの伸び(例: 68.0 +1.5)を出す(`grow.js` の `teamPower`)

## 9.3c 第3弾でやったこと(2026-11-18)

伺った本家の仕様(→docs/08 §8.12): コミュニケーションの相手は盤面(フォーメーション)から選んでいた。台紙は今の方向(白・黒・虹・金)でよい。

- **準備の画面の盤面化**: コミュニケーションの相手を、SQUAD と同じ縦の盤面から選ぶ(`clubui.js` の `commBoardHtml`)。
  先発は SQUAD の既定の位置、控えは下の列。駒には、ポジションの色・背番号・名前・★・「！」と、次の★までの進みなどの情報が出る
- **カードの意匠**
  - 人物の絵を、ポジション別のポーズにした(独自に描いた。GK は両手を広げる、DF はスライディング、MF はトラップ、FW はシュート。`POSES` / `poseSvg`)。
    上着はクラブの色で、胸に背番号。中サイズでは絵を左に寄せ、右の能力の列と重ならないようにした
  - 名前の帯をクラブの色(暗め)にした。LEGENDS は黒、WORLD CLASS はクラブの色から紫へのグラデーション
  - 右上にクラブのエンブレムを入れた
- **排出の場面**: 暗い店内の地にした。下に払い出し口を置き、カードがそこからせり上がって出てくる。めくる前の予兆の光はそのまま
## 9.3d 第4弾と、伺った残りの4点(2026-11-19)

伺ったこと(→docs/08 §8.12): 始めた試合の取り消しは今のまま / ハーフタイムは省略 / 重なったカードは Footista にならう / SHOOT は独自の仕様 /
任期が終わると別のクラブへ移り、監督の情報と師弟関係の選手以外は戻る(資金はその任期の最高額を競う)。維持費・資金で選手パック・監督ランクへの投資は保留。

- **重なったカード**: 重なり1枚ごとに個別指導(個人練習)の経験 +10%(最大5枚で +50%)。覚醒で上がる値を 1〜3(無地 / ＋ / ＋＋)にし、重なりが多いほど大きい値が出やすい
  (平均 1.36 → 5枚で 2.00。`TUNING.grow.dup`、`grow.js` の `dupOf` / `awakeGain`)。カードの詳細に重なりと効き目を出す
- **SHOOT**: 押すと「撃て」が最大5手残り(`TUNING.shot.orderN`)、敵陣の深い所(奥行き 0.55 より前)で撃つ。指示が生きている間はボタンが光り、撃ったらモニターに「SHOOT!」。
  奪われたら消える。光っている間にもう一度押すと取り消し
- **任期をまたぐとクラブの持ち物を戻す**: 資金・ファン・スタジアム・施設・スポンサーは任期の始めの状態へ。歴代の記録に、その任期に稼いだ資金を残し、最高額を見せる
- **施設を Lv5 まで**(費用 20 / 50 / 100 / 160 / 240億。効き目は最大 ×1.5)。1任期では全部は上げきれないので、どれを優先するかを選ぶ
- **S の大会への道**: SEASON に、S の大会3つの出場条件と、満たしているかを出す。大会の一覧は日程の順に並べ、次の試合の大会に ▶

## 9.4 確かめが要ること・判断が要ること(第2弾以降)

- ゲーム体験の担当は「育成しても勝ちが増えない」と測った。ただし、育成の方針を単純化した検証で、clubtest の「集中して育てれば強さ +0.2 以上」とは食い違う。第2弾で clubtest の方針で測り直す
- 称号: その任期の覚醒で数えても、テストの育て方では6任期中4回が覚醒工場。コミュニケーションは1任期に約300回、覚醒は1人14回ほどで届くので、多く覚醒するのは数値どおり。→ **ユーザーの決定で8人以上に上げた**(2026-11-18)
- ユーザーに伺うこと(本家の仕様を含む。1つずつ聞く)
  1. 始めた試合は取り消せないようにするか。今は、試合の途中で読み込み直すと同じ試合をやり直せる。取り消せなくするなら、途中で落ちたときに CPU が最後まで解くのか、負けとするのか
  2. 重なったカードの使い道
  3. SHOOT の「押しどき」を見せるか
  4. ハーフタイムにできたこと
  5. 試合・結果・排出の画面を暗い地にそろえるか
  6. コミュニケーションで選手を選ぶ画面は盤面だったか
