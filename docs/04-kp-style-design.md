## 4. KP・スタイル・連携の設計(D15)

設計の正本。決定は §4.8。実装の仕組みと実測は [02. 試合エンジン](02-match-engine.md) の §2.11〜2.13。

### 4.1 本家の骨格

参照: 本家の汎用KP戦術の一覧(106種。`tools/kp_source.txt` に名称・範囲・軸・効果を控えてある)。

| | 本家の仕組み |
|---|---|
| **戦術はカードが持つ** | カード1枚に KP戦術が1つ。**そのカードを KP に指定すると、その戦術が発動する** |
| **範囲は2つ** | 全体(チームの意識と動きを変える) / 個人(KP 本人のプレーを強める) |
| **軸は6つ** | 必要項目 = オフェンス(O) / ディフェンス(D) / 支配(R) / 奪取(C) / スピード(S) / パワー(P)。チームの戦力グラフの6項目と同じ |
| **効きはランクで決まる** | 連携や育成が進むとチームスタイルランク(C〜S・SS)が上がり、効果が強くなる |
| **有効なのは同時に1つ** | KP は1人。**戦術を変える = KP を別のカードに替える** |

106種の内訳は 全体 42 / 個人 64。軸は O 43 / D 32 / R 17 / S 6 / C 5 / P 3(偏っている)。

### 4.2 いまの実装とのずれ

| いま(§2.11〜2.12 の仮置き) | 本家 | 直す方向 |
|---|---|---|
| 戦術ボタン(攻撃5・守備4)を KP と無関係に選ぶ | 戦術は KP のカードが持つ。ボタンは監督の指示 | **戦術は KP の指定に一本化。ボタンは指示として残す**(§4.9) |
| 攻撃と守備を1つずつ、同時に2つ有効 | 同時に1つ | **1つにする**。守備の戦術を取ると攻撃の戦術は使えない |
| KP の効果は「スキル ×1.5 + ボールが集まる」 | 個人系の KP戦術 | 個人系スタイルとして作り直す |
| スキル(カードに1つ・常時) | SKILL と KP は直結している | **スキルを根にする**。スキルからスタイルとバフが決まる(§4.10) |
| 効きは固定 | ランクで変わる | 軸とランクを入れる(§4.5) |

### 4.3 体系 — 範囲 × 軸 × 主題

**多すぎるのは「同じ主題の場所ちがい・強さちがい」を別の戦術にしていたため**
(プレスが4種、ブロックが4種、支配が4種、アンチが5種、パスワークが6種)。
本作は**主題ごとに1つ**にまとめ、場所や相手は「カードをどこに置くか」「誰を KP にするか」で表す。

```
 スタイル = 範囲(全体 / 個人) × 軸(O / D / R / C / S / P) × 主題
 効き     = チームの戦力グラフの、その軸の値 → ランク → 倍率
```

- **全体スタイル**は「チームがどう繋ぎ、どう守るか」を変える。**必ず失うものを持つ**
- **個人スタイル**は「KP 本人の得意な場面」を強める。失うものは**全体スタイルを使えないこと**
- **左右の使い分けは全体スタイルに持たせない**。本家でもクロスやサイド突破は個人系で、
  「サイドの選手を KP にする」ことでサイド攻撃になる

### 4.5 軸とランク

**チームの戦力グラフ(6軸)が、スタイルの効きを決める。**

> **2026-11-20 から、ランクはチームの成長グラフだけで決まる(B / A / S / G)。正本は [docs/15](15-team-growth.md) §15.5**。下の表とランク C〜S は前の作りの記録。

| 軸 | 何を表すか | 盤面の11人から出す値(案) |
|---|---|---|
| O オフェンス | 点を取る力 | `off` |
| D ディフェンス | 守る力 | `def` |
| R 支配 | ボールを持つ力 | `tec` |
| C 奪取 | 奪いに行く力 | `def`・`spd`・`sta` の平均 |
| S スピード | 速さ | `spd` |
| P パワー | 強さ・高さ | `pow` |

- ランクは C / B / A / S の4段。**倍率は「得るもの」にだけ掛かり、「失うもの」には掛からない**
  (低いランクで使うと、損だけが満額で残る。合わないスタイルを選ぶ意味を無くすため)
- 値は**いま盤面に居る11人**で出す。交代や退場で変わる
- 段階3で、練習がグラフを伸ばし、連携がランクを押し上げる形にする。
  それまでは能力だけで決まる
- グラフは KP を選ぶ画面に出す(「このチームでこのスタイルはランク B」と見える)
- **相手も同じ式**。相手監督は構えに合わせて KP を替える(前がかり → 攻撃のスタイルを持つカード /
  固める → 守備のスタイルを持つカード)

### 4.9 監督の指示

**筐体のボタンにあたるもの。スタイルとは独立で、いつでも押せる。**

| 指示 | 効果 | 失うもの |
|---|---|---|
| ラインを上げる / 下げる | カードを動かさずに、隊列全体を前後へずらす(どちらか一方、または無し) | 上げれば裏が空き、下げれば前線が遠い |
| 左サイド重視 / 右サイド重視 | そのサイドの選手にボールが集まり、外へ開く手がそちらを向く(どちらか一方、または無し) | 逆サイドと中央が使われない |
| プレスしろ | ボールが敵陣にあるとき守備が強い | 自陣で少し弱い。スタミナを使う |
| シュートしろ | 敵陣で持っていれば次のプレーで撃つ(押したときだけ) | 遠くからでも撃つ |

- プレスの指示は全体スタイルの「プレッシング」と**重なる**(両方なら掛け算)。指示は弱く、スタイルは強い
- 相手監督も同じ指示を使う(前がかり → ラインを上げる、終盤はプレスも / 固める → ラインを下げる)

#### 4.9b 十字の戦術ボタン(2026-11-18。エンジンは実装済み。実測と最終の数値は docs/02 §2.11)

本家(初期)の十字の5つ + キーパーに置き換える(→docs/08 §8.2)。**どれも同時に点けられる**。
同じボタンをもう一度押すと消える。「ラインを上げる・下げる」はやめ、カードの位置で示す。
効き方はスタイルと**同じ語彙**(`lane`・`direct`・`fastTo`・`push` など)で作り、**どれも失うものを持つ**。

| ボタン | 効果(数値は初めの案。実測で詰める) | 失うもの |
|---|---|---|
| **中央突破** | 真ん中へのパス(`in`)×1.5・エリアへ(`box`)×1.2・持ち運び ×1.25 | 外へ開く手(`out`)×0.6・逆サイドへ(`switch`)×0.6。クロスからの好機が減る |
| **左サイド攻撃 / 右サイド攻撃** | その側の選手が受け手に ×1.6、外へ開く手 ×1.4 がそちらを向く、外からのクロス(`box`)×1.3 | 逆サイド ×0.6・真ん中へ ×0.75 |

| **カウンター** | 守るときは隊列を −0.05(深く)。自陣で奪ったら、裏へのボール(`fastTo`)×1.6・縦に速く(`direct`)×1.4 | 遅攻で敵陣に掛かる人数が減る(×0.9)。押し込まれやすい |
| **プレス** | いまのプレスと同じ(敵陣の守備 ×1.12 / 自陣 ×0.97) | スタミナ消費 ×1.12 |
| **キーパー** | GK が高い位置を取る(定位置 +0.05、エリアの端寄り)。裏へのボールの処理(`sweep`)×1.5 | ループシュート(`lob`)×1.5 が入りやすい。GK のスタミナ消費 ×1.5 |

- 組み合わせは掛け算(中央突破と左右を両方点けると、互いに一部を打ち消す)。**出しっぱなしで得をするものは作らない**(実測で上積み +0.2 未満)

### 4.10 スキル → スタイル + バフ

```
 カード ──▶ スキル(1つ・固有の名前)──┬─▶ スタイル(KP にしたときに発動。全体 or 個人)
                                      └─▶ バフ(本人に常時掛かる。決まった場面だけに効く)
```

- **スキルの名前はカードの個性**で、スタイルの名前とは別(例: スキル「ゴールハンター」→
  スタイル「ゴールハンティング」+ バフ「流れの中のシュート ×1.06」)
- **同じスタイルを引くスキルを何種類でも作れる**。バフの中身や強さを変えれば別のスキルになる。
  レア(§4.7)は「スタイルは汎用のまま、スキル名とバフが固有」で表せる
- バフは小さく(おおむね ×1.05〜1.10)、スタイルが本体。KP にしなくてもバフは効く
- 個人スタイルは、KP 本人に**バフと同じ語彙の効果**を(ランクに応じて)上乗せする
